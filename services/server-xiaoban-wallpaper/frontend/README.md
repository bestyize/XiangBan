# 产品网站与管理界面

Vue 3 + TypeScript + Vite，奶白与暖粉色。产品介绍、公开壁纸库与管理员 UI 共用本前端，`/admin` 为登录和后台入口。

执行 `npm ci`、`npm run dev`、`npm run build`。独立锁文件；不跨目录导入其他客户端源码。静态角色 SVG 从桌宠原始绘制导出，保留一份本项目资产。外部封面由浏览器直接加载，不通过本服务中转；Canvas 壁纸只显示封面，不执行下发脚本。

后台通过同源 `/api/admin` 与 Cookie 会话连接，禁止在 localStorage 存管理员密码或会话 Token。所有用户输入用 Vue 文本节点渲染，不用 v-html 渲染外部数据。修改账号后返回登录页；批量导入默认草稿，发布前由服务端验证完整协议。
