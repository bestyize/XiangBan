### Apktool
_这是 Apktool 的代码仓库。网站位于 [apktool.org](https://github.com/iBotPeaches/apktool.org)仓库。_

[![CI](https://github.com/iBotPeaches/Apktool/actions/workflows/build.yml/badge.svg)](https://github.com/iBotPeaches/Apktool/actions/workflows/test.yml)
[![Software License](https://img.shields.io/badge/license-Apache%202.0-brightgreen.svg)](https://github.com/iBotPeaches/Apktool/blob/2062db67b2cdd3de12739105eee43417b52f0316/LICENSE.md)

Apktool 是一款用于逆向分析第三方闭源 Android 二进制应用的工具。它可以将资源解码到接近原始的形式，修改后重新构建，并支持逐步调试 smali 代码。通过类似项目的文件结构以及构建 APK 等重复任务的自动化，它也使处理应用更加方便。

Apktool **并非**为盗版及其他非法用途设计。它可用于本地化、添加功能、增加对自定义平台的支持等正当用途。请公平对待你使用并可能喜欢的应用的作者。
