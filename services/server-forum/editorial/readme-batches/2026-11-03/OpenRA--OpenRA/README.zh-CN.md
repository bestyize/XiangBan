# OpenRA

一款自由、开源的即时战略游戏引擎，支持早期 Westwood 经典游戏。

* 网站：[https://www.openra.net](https://www.openra.net)
* 聊天：[Libera 上的 #openra](ircs://irc.libera.chat:6697/openra)（[网页](https://web.libera.chat/#openra)）或 [Discord](https://discord.openra.net) ![Discord 徽章](https://discordapp.com/api/guilds/153649279762694144/widget.png)
* 仓库：[https://github.com/OpenRA/OpenRA](https://github.com/OpenRA/OpenRA) ![持续集成](https://github.com/OpenRA/OpenRA/workflows/Continuous%20Integration/badge.svg)

请阅读 [Wiki](https://github.com/OpenRA/OpenRA/wiki) 中的[常见问题](https://github.com/OpenRA/OpenRA/wiki/FAQ)，并在 [https://github.com/OpenRA/OpenRA/issues](https://github.com/OpenRA/OpenRA/issues) 报告问题。

欢迎加入[论坛](https://forum.openra.net/)讨论。

## 游玩

随项目分发的模组包括以下游戏的重新演绎：

* Command & Conquer: Red Alert
* Command & Conquer: Tiberian Dawn
* Dune 2000

EA 未认可也不支持本产品。

查看[游戏指南](https://github.com/OpenRA/OpenRA/wiki/Playing-the-game)，了解如何赢得多人对战。

## 参与贡献

* 请阅读 [INSTALL.md](https://github.com/OpenRA/OpenRA/blob/9636b63eaee62fcb60ef2e896e7985bdf2f1ee68/INSTALL.md) 和[编译](https://github.com/OpenRA/OpenRA/wiki/Compiling)，了解如何设置 OpenRA 开发环境。
* 参阅[开发](https://github.com/OpenRA/OpenRA/wiki/Hacking)了解引擎概况（该内容现已非常过时）。
* 阅读并遵守我们的[行为准则](https://github.com/OpenRA/OpenRA/blob/9636b63eaee62fcb60ef2e896e7985bdf2f1ee68/CODE_OF_CONDUCT.md)。
* 要使你的补丁被合并，请遵守[贡献指南](https://github.com/OpenRA/OpenRA/blob/9636b63eaee62fcb60ef2e896e7985bdf2f1ee68/CONTRIBUTING.md)。

## 地图制作

* 由于自定义规则可以大幅改变游戏玩法，我们提供了[地图制作](https://github.com/OpenRA/OpenRA/wiki/Mapping)教程。
* 对于脚本任务，请参阅 [Lua API](https://docs.openra.net/en/release/lua/)。
* 如果想与社区分享地图，请上传至 [OpenRA 资源中心](https://resource.openra.net)。

## 模组制作

* 下载 [OpenRA Mod SDK](https://github.com/OpenRA/OpenRAModSDK) 来开始制作自己的模组。
* 查看[模组制作指南](https://github.com/OpenRA/OpenRA/wiki/Modding-Guide)，创建自己的经典即时战略游戏。
* 可参阅自动生成的 [Trait 文档](https://docs.openra.net/en/latest/release/traits/)，开始使用 YAML 文件。
* 了解如何创建与 OpenRA 兼容的[像素画](https://github.com/OpenRA/OpenRA/wiki/Pixelart)的一些提示。
* 请将完全转换模组上传至[我们的 Mod DB 页面](https://www.moddb.com/games/openra/mods)。

## 支持

* 如果你有多余带宽，可以赞助一台[镜像服务器](https://github.com/OpenRA/OpenRAWebsiteV3/tree/master/packages)。
* 你也可以立即搭建[专用游戏服务器](https://github.com/OpenRA/OpenRA/wiki/Dedicated-Server)。
