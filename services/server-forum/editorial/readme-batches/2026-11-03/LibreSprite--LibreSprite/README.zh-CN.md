## 简介
LibreSprite 是一款用于创建精灵图及其动画的免费开源程序。
* 实时动画预览。
* 洋葱皮显示。
* 同时编辑多个精灵图。
* 使用现成调色板，也可以创建自己的调色板。
* 精灵图由图层和帧组成。
* 平铺绘制模式，适合绘制图案和纹理。
* 填充轮廓、多边形、阴影模式等像素精确工具。
* 精灵图与动画支持多种文件类型。

## 历史
LibreSprite 最初是 [Aseprite](https://www.aseprite.org) 的一个分叉；Aseprite 由 [David Capello](https://github.com/dacap) 开发。Aseprite 曾按照 GNU 通用公共许可证第 2 版分发，但在 [2016 年 8 月 26 日](https://github.com/aseprite/aseprite/commit/5ecc356a41c8e29977f8608d8826489d24f5fa6c)转为专有许可证。

此分叉基于 GPL 第 2 版许可覆盖的[最后一次提交](https://github.com/aseprite/aseprite/commit/03be4aa23db465219962f4c62410f628e7392545)建立，现在独立于 Aseprite 开发。
