## 数据结构

数据结构是在计算机中组织和存储数据的一种特殊方式，使得数据可以高效地被访问和修改。更确切地说，数据结构是数据值的集合，表示数据之间的关系，也包括了作用在数据上的函数或操作。

请记住，每种数据结构都有各自的权衡。选择某种结构的原因比如何实现它更值得关注。

## 如何使用本仓库

**安装全部依赖**

```
npm install
```

**运行 ESLint**

你可以运行它来检查代码质量。

```
npm run lint
```

**运行全部测试**

```
npm test
```

**按名称运行测试**

```
npm test -- 'LinkedList'
```

**故障排除**

如果 lint 或测试失败，尝试删除 `node_modules` 文件夹并重新安装 npm 包：

```
rm -rf ./node_modules
npm i
```

同时请确保使用正确的 Node 版本（`>=16`）。如果使用 [nvm](https://github.com/nvm-sh/nvm) 管理 Node 版本，可在项目根目录运行 `nvm use` 来选取正确版本。

**Playground**

你可以在 `./src/playground/playground.js` 中尝试数据结构和算法，并在 `./src/playground/__test__/playground.test.js` 中编写测试。

然后运行以下命令，检查 Playground 代码是否按预期工作：

```
npm test -- 'playground'
```

*大 O 记法*根据输入规模增长时算法运行时间或空间需求的增长方式对算法分类。下图展示大 O 记法中最常见的算法增长阶。

![大 O 曲线图](https://raw.githubusercontent.com/trekhleb/javascript-algorithms/85293e3e2b88f4d2ce330d956b139cf628aa1e82/assets/big-o-graph.png)

来源： [Big O Cheat Sheet](http://bigocheatsheet.com/).

下表列出一些最常用的大 O 记法，并比较不同输入规模下的性能。

| 大 O 记法 | 类型        | 10 个元素的计算次数 | 100 个元素的计算次数 | 1000 个元素的计算次数  |
| -------------- | ----------- | ---------------------------- | ----------------------------- | ------------------------------- |
| **O(1)**       | 常数        | 1                            | 1                             | 1                               |
| **O(log N)**   | 对数        | 3                            | 6                             | 9                               |
| **O(N)**       | 线性        | 10                           | 100                           | 1000                            |
| **O(N log N)** | n log(n)    | 30                           | 600                           | 9000                            |
| **O(N^2)**     | 平方        | 100                          | 10000                         | 1000000                         |
| **O(2^N)**     | 指数        | 1024                         | 1.26e+29                      | 1.07e+301                       |
| **O(N!)**      | 阶乘        | 3628800                      | 9.3e+157                      | 4.02e+2567                      |
