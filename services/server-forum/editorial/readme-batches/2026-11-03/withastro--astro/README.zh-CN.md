## 安装

安装最新版 Astro 的**推荐**方式是运行以下命令：

```bash
npm create astro@latest
```

也可以运行以下命令**手动**安装 Astro：

```bash
npm install astro
```

需要帮助？请从我们的[入门指南](https://docs.astro.build/en/getting-started/)开始。

想快速查看示例？可以[打开一个入门项目](https://astro.new/)，直接在浏览器中查看。
