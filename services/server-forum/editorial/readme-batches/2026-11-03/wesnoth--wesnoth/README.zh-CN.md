关于
=====

**The Battle for Wesnoth** 是一款高幻想题材的开源回合制战术策略游戏，支持单人和在线或轮流操作的本地多人对战。为夺回韦诺王国的王位而拼死一战，寻找永生的关键，或参与众多其他冒险。

功能
--------

* 多种战役，各有战术挑战、充满情感的故事和多个难度级别。
* 细致的世界观与叙事，包含数百个精灵图、动画和角色。
* 不同阵营拥有许多不同的单位技能和特质。
* 地图编辑器提供多种工具、数百种地形，并支持保存和分享地图。创建自己的场景或战斗，获得近乎无限的重玩空间。
* 高度可修改，支持社区创建的多种地图包、时代设定和完整战役。
* 在线及本地多人游戏，可与朋友、陌生人或 AI 对战。
* 基础游戏设置可调整，快捷键配置选择近乎无限。
* 精心创作的音乐曲目，表现这个充满传说的高幻想世界的时代氛围和宏大感。

安装
----------

Wesnoth 可在 Windows、macOS 和 Linux 上游玩，并可通过以下方式安装：
* [Steam](https://store.steampowered.com/app/599390/Battle_for_Wesnoth/)（全部平台）
* [itch.io](https://wesnoth.itch.io/battle-for-wesnoth)（Windows 和 macOS）
* [macOS App Store](https://apps.apple.com/us/app/the-battle-for-wesnoth/id1450738104)
* [SourceForge](https://sourceforge.net/projects/wesnoth/files/) 上的独立安装程序（Windows 和 macOS）
* [Flatpak](https://flathub.org/apps/details/org.wesnoth.Wesnoth)（Linux）

此外，还有 [iOS](https://apps.apple.com/us/app/battle-for-wesnoth/id575852062) 和 [Android](https://sourceforge.net/projects/wesnoth/files/android/) 移植版。iOS 移植版目前无人维护，基于旧版本（1.14）。Android 移植版仅适用于 1.19（alpha）。

从源代码构建游戏，请参阅 [INSTALL](https://github.com/wesnoth/wesnoth/blob/a50b1574a6916668a7be11ec34c767303ad4c631/INSTALL.md)。

参与贡献
------------

Wesnoth 最需要熟练的 C++ 开发者（C++14 及以上），不过几乎每个人都能帮忙：
* 简单的 C++ 任务。
* 用于内容脚本的 Lua 和 WML。
* 各种外部工具使用的 Python。
* 甚至包括测试游戏并对更新后的战役提供反馈！

此外，Wesnoth 的多种单位动画缺少美术素材；有兴趣帮忙更新现有单位精灵图或创建动画的人，请查看[美术贡献](https://forums.wesnoth.org/viewforum.php?f=9)论坛，并联系现任美术总监。

另见：[CONTRIBUTING](https://github.com/wesnoth/wesnoth/blob/a50b1574a6916668a7be11ec34c767303ad4c631/CONTRIBUTING.md)。

如有任何问题，最好先加入 Wesnoth 的论坛、Discord 或 IRC 并开始提问！
