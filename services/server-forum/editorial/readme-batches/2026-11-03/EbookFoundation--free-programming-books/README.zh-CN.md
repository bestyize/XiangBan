## 简介

此列表最初克隆自 [StackOverflow - 免费编程书籍列表](https://web.archive.org/web/20140606191453/https://stackoverflow.com/questions/194812/list-of-freely-available-programming-books/392926)，Karan Bhangui 和 George Stocker 曾作出贡献。

Victor Felder 将此列表迁移到 GitHub，以便协作更新和维护。它已发展为 [GitHub 上热门的仓库之一](https://octoverse.github.com/)。
