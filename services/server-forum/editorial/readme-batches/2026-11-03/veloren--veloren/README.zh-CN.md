## 欢迎来到 Veloren！

Veloren 是一款以广阔奇幻世界为背景的动作冒险角色扮演游戏，灵感来自 Cube World、The Legend of Zelda: Breath of the Wild、Dwarf Fortress 和 Minecraft 等游戏。

Veloren 正在积极开发，拥有蓬勃发展的玩家社区。

## 开发

欢迎加入我们的 [Discord 服务器](https://veloren.net/discord)或 [Zulip 服务器](https://veloren.net/zulip)，与社区交流。

我们接受多种贡献，不仅限于软件开发者！例如提供反馈的玩家，以及与社区分享作品的艺术家。

也欢迎译者在我们的 Weblate 实例上贡献翻译。

## 获取 Veloren

我们为 Windows、macOS 和 Linux 提供构建版本。可以从我们的网站下载游戏：

<https://veloren.net/download>

由于游戏开发迅速，稳定版很快就会过时，并且可能**与公共服务器不兼容**。

建议使用官方游戏启动器 [Airshipper](https://book.veloren.net/players/airshipper.html)，轻松保持游戏为最新版本。

如果你希望自行编译游戏，请遵循[手册](https://book.veloren.net/contributors/introduction.html)中的说明。

## 常见问题

### **问：**这款游戏采用什么许可证？

**答：****可以免费游玩、修改和分发，永远如此。**
由于这是一个社区项目，我们决定采用 **[GNU 通用公共许可证 v3.0](https://www.gnu.org/licenses/gpl-3.0-standalone.html)**，这意味着它将始终保持自由和开源。

### **问：**支持哪些平台？

**答：**Veloren 可在 Windows、macOS 和 Linux 上的多种 CPU 架构运行。但开发主要针对 x86_64 架构。也为 macOS 和 Linux 提供 ARM64 架构的官方构建版本。其他平台上可能也可以编译游戏。

### **问：**接受捐款吗？

**答：**你可以在我们的 [Open Collective](https://opencollective.com/veloren) 页面为项目提供资金支持。
