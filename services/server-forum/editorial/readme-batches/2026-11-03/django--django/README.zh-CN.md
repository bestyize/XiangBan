# Django

Django 是一个高级 Python Web 框架，提倡快速开发以及简洁、务实的设计。感谢你了解 Django。

所有文档都位于 `docs` 目录中，也可以在线访问 https://docs.djangoproject.com/en/stable/。如果你刚开始使用，我们建议按照以下顺序阅读文档：

* 首先，阅读 `docs/intro/install.txt`，了解 Django 的安装方法。
* 接着，按顺序完成教程（`docs/intro/tutorial01.txt`、`docs/intro/tutorial02.txt` 等）。
* 如果要设置实际部署服务器，请阅读 `docs/howto/deployment/index.txt` 中的说明。
* 接下来可以阅读专题指南（位于 `docs/topics`）；然后查看针对具体问题的 HOWTO 指南（位于 `docs/howto`），并在参考文档（`docs/ref`）中查阅详细信息。
* 参阅 `docs/README`，了解如何构建 HTML 版文档。

文档会严格更新。如果你发现文档有问题，或认为有任何内容需要更清楚地说明，请花 30 秒[提交问题单](https://code.djangoproject.com/newticket)。你可以使用 GitHub 账号登录；如果有 DjangoProject 账号，也可以使用它登录。登录后，View Tickets 旁边会出现 New Ticket 按钮。

获取更多帮助：

* 加入 [Django Discord 社区](https://chat.djangoproject.com)。
* 加入 [Django 论坛](https://forum.djangoproject.com/)社区。

为 Django 贡献：

* 访问 https://docs.djangoproject.com/en/dev/internals/contributing/，了解参与方式。

运行 Django 测试套件：

* 按照 `docs/internals/contributing/writing-code/unit-tests.txt` 中“Unit tests”部分的说明操作；其在线版本位于 https://docs.djangoproject.com/en/dev/internals/contributing/writing-code/unit-tests/#running-the-unit-tests
