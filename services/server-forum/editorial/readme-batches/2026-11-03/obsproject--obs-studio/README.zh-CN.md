## OBS Studio 是什么？

OBS Studio 是一款旨在高效采集、合成、编码、录制和串流视频内容的软件。

它依据 GNU 通用公共许可证第 2 版（或任何后续版本）发布，详情请参阅随附的 [COPYING](https://github.com/obsproject/obs-studio/blob/65c320b46e1af5c7a555161aea6182cdf7a8c524/COPYING) 文件。

## 参与贡献

- 如果你希望资助或赞助项目，可以通过 [Patreon](https://www.patreon.com/obsproject)、[OpenCollective](https://opencollective.com/obsproject) 或 [PayPal](https://www.paypal.me/obsproject) 进行。更多信息请参阅[贡献页面](https://obsproject.com/contribute)。
- 如果你希望为项目贡献代码，请务必阅读编码和提交指南：https://github.com/obsproject/obs-studio/blob/65c320b46e1af5c7a555161aea6182cdf7a8c524/CONTRIBUTING.md
- 项目代码遵循以下代码风格指南：https://github.com/obsproject/obs-studio/blob/65c320b46e1af5c7a555161aea6182cdf7a8c524/CODESTYLE.md
- 开发者与 API 文档位于：https://obsproject.com/docs
- 如果你希望贡献翻译，请勿提交 Pull Request，而应使用 Crowdin。更多信息请阅读：https://obsproject.com/wiki/How-To-Contribute-Translations-For-OBS
- OBS Studio 和相关仓库的贡献者应遵守我们的行为准则，内容见：https://github.com/obsproject/obs-studio/blob/65c320b46e1af5c7a555161aea6182cdf7a8c524/COC.rst
- 其他贡献方式包括在论坛或社区聊天中帮助他人解决问题。请仅就自己充分理解的主题提供支持——错误的建议比没有建议更糟。对于自己不完全了解或理解的内容，请引导对方使用官方帮助或官方渠道。
