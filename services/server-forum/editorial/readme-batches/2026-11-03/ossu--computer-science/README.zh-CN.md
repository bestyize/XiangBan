# 概述

OSSU 课程体系利用在线资料提供**完整的计算机科学教育**。它不只是职业培训或专业发展，而是面向希望全面、扎实掌握所有计算学科基础概念的人，以及有自律、意愿和（最重要的！）良好习惯，能够主要依靠自学完成教育并得到世界各地学习伙伴支持的人。

课程按照计算机科学本科专业的学位要求设计，但不包含通识（非计算机科学）要求，因为假定多数学习者已在计算机科学以外受过教育。课程本身来自世界顶尖机构，常见于哈佛、普林斯顿、MIT 等，并特别按照以下标准选择。

**课程必须**：
- 开放报名
- 定期开展（最好可自主进度学习，否则每年开设多次）
- 教学材料和教学原则整体质量高
- 符合 [CS 2013](https://github.com/ossu/computer-science/blob/33d44a44e3526ede8e862bf1ad50ae5ae7a2f112/CURRICULAR_GUIDELINES.md)《计算机科学本科课程指南》的课程标准

如果没有课程符合上述标准，则用书籍补充课程内容。如果某些课程或书籍不适合该课程体系但质量很高，可放入 [extras/courses](https://github.com/ossu/computer-science/blob/33d44a44e3526ede8e862bf1ad50ae5ae7a2f112/extras/courses.md) 或 [extras/readings](https://github.com/ossu/computer-science/blob/33d44a44e3526ede8e862bf1ad50ae5ae7a2f112/extras/readings.md)。

**组织方式**。课程体系设计如下：
- *计算机科学入门*：让学生尝试计算机科学并判断是否适合自己
- *计算机科学核心*：大致对应本科课程前三年，学习所有专业学生必修的课程
- *计算机科学进阶*：大致对应本科最后一年，根据学生兴趣选择选修课
- *最终项目*：让学生验证、巩固和展示知识的项目，由世界各地的同伴评估

**学习时长**。如果认真规划并每周投入约 20 小时，有可能在约 2 年内完成。学习者可以使用[此电子表格](https://docs.google.com/spreadsheets/d/1y2kMsIg9VaHMVmw35x_aH1hpty3V-ZMuV2jA13P_Cgo/copy)估算结束日期。请复制一份，并在 `Timeline` 工作表中输入开始日期和预计每周学习时数。学习过程中，可在 `Curriculum Data` 表中输入实际课程完成日期，获得更新后的完成时间估计。
  
> **警告：**该表格有助于估算完成课程所需时间，但可能并不总是与课程体系保持同步。请使用 [OSSU CS 网站](https://cs.ossu.dev)或[仓库](https://github.com/ossu/computer-science)查看应学习的课程。

**费用**。全部或几乎全部课程材料均可免费获得，但某些课程可能对作业、测试或项目评分收费。请注意，[Coursera](https://www.coursera.support/s/article/209819033-Apply-for-Financial-Aid-or-a-Scholarship?language=en_US) 和 [edX](https://courses.edx.org/financial-assistance/) 均提供经济援助。

请根据自己的时间和预算决定花费多少；只需记住，成功不能靠购买获得！

**学习过程**。学生可以独自或组队学习，按顺序或不按顺序完成课程。
- 我们建议学习计算机科学核心的所有课程，只有确信已经学过相关内容时才跳过。
- 为简单起见，建议从上到下按顺序学习（尤其是核心课程）。有些学生选择同时学习多门课程，以便每天或每周接触不同内容。常见做法是数学课程与入门课程并行。课程列出的先修要求可帮助判断自己是否准备好学习。
- 进阶计算机科学课程为选修课。选择一个想深入掌握的主题（例如进阶编程），学习该标题下的所有课程。也可以自定义主题；Discord 社区可能会对你的计划提供反馈。

**内容政策**。如果计划公开展示部分课程作业，必须只分享你有权分享的文件。请*遵守每门课程开始时签署的行为准则*！

## 先修要求

- [计算机科学核心](#core-cs)假定学生已学过[高中数学](https://ossu.dev/precollege-math)，包括代数、几何和预备微积分。

## 最终项目

学习的一部分是实践。每门课程的作业和考试旨在帮助你准备用知识解决现实问题。

完成计算机科学核心以及与你相关的进阶部分之后，应找出一个可以用所学知识解决的问题。你可以创造全新的东西，也可以改进自己正在使用且希望更好的工具或程序。

## 恭喜

完成以上课程体系要求后，你将完成相当于完整计算机科学学士学位的学习。恭喜！

接下来做什么？可能性无穷，也可以交叉选择：

- 寻找开发者工作！
- 查看[阅读资料](https://github.com/ossu/computer-science/blob/33d44a44e3526ede8e862bf1ad50ae5ae7a2f112/extras/readings.md)，阅读经典书籍，提升技能并拓展知识。
- 参加本地开发者聚会（例如通过 [meetup.com](https://www.meetup.com/)）。
- 关注软件开发领域的新兴技术：
  + 通过 [Elixir](https://elixir-lang.org/) 探索 **actor 模型**。它是基于久经考验的 Erlang 虚拟机、面向 Web 的新函数式编程语言！
  + 通过 [Rust](https://www.rust-lang.org/) 探索**借用和生命周期**。这门系统语言无需垃圾收集器即可实现内存和线程安全！
  + 通过 [Idris](https://www.idris-lang.org/) 探索**依赖类型系统**。这门受 Haskell 启发的新语言以前所未有的方式支持类型驱动开发。
