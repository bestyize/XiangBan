# Endless Sky

探索其他恒星系。通过贸易、运送乘客或完成任务赚钱。用收入购买更好的飞船，或升级现有飞船的武器和引擎。炸毁海盗船。选择支持内战中的一方。或者离开人类空间，希望找到文化比你自己的文明更发达的友好外星人……

------

Endless Sky 是一款沙盒式太空探索游戏，类似 Elite、Escape Velocity 或 Star Control。你以一艘小型宇宙飞船的船长身份开始游戏，之后可以自行选择要做什么。游戏包含一条主要剧情线和许多支线任务，但你可以选择推进剧情，或独自成为商人、赏金猎人或探险家。

更多信息请参阅[玩家手册](https://github.com/endless-sky/endless-sky/wiki/PlayersManual)，也可在[主页](https://endless-sky.github.io/)查看截图和偶尔发布的博客文章。

## 安装游戏

Endless Sky 的官方发行版可从 [GitHub](https://github.com/endless-sky/endless-sky/releases/latest) 直接下载，也可通过 [Steam](https://store.steampowered.com/app/404410/Endless_Sky/)、[GOG](https://gog.com/game/endless_sky) 和 [Flathub](https://flathub.org/apps/details/io.github.endless_sky.endless_sky) 获取。其他包管理器中也可能包含本游戏，但提供的版本可能不是最新版本。

## 系统要求

Endless Sky 的系统要求很低，大多数系统应该都能够运行。最严格的要求可能是设备至少支持 OpenGL 3。

| 硬件 | 最低 | 推荐 |
|---|----:|----:|
| 内存 | 750 MB | 2 GB |
| 显卡 | OpenGL 2.0* | OpenGL 3.0 |
| 屏幕分辨率 | 1024x768 | 1920x1080 |
| 可用存储空间 | 400 MB | 1.5 GB |

\* OpenGL 2 设备需要[自定义着色器](https://github.com/endless-sky/endless-sky/wiki/CreatingPlugins#shaders)。

| 操作系统 | 最低版本 |
|---|---|
| Linux | 任何现代发行版（相当于 Ubuntu 20.04） |
| MacOS | 10.15 |
| Windows | XP（5.1） |

Endless Sky 可能也可以在其他操作系统上运行，但官方不提供支持。

## 从源代码构建

开发时使用 [CMake](https://cmake.org) 编译项目。通过各自的 CMake 集成，支持大多数流行的 IDE。

完整安装说明请参阅[构建说明](https://github.com/endless-sky/endless-sky/blob/d943c9e5ed07f1edff8951365fc9d095ab3a2c03/docs/readme-developer.md)。

## 参与贡献

作为一款免费开源游戏，Endless Sky 是许多人共同努力的成果。美术作品、故事情节和其他文字内容的贡献最受需要，项目也有一份大致定义的[路线图](https://github.com/endless-sky/endless-sky/wiki/DevelopmentRoadmap)。希望[贡献](https://github.com/endless-sky/endless-sky/blob/d943c9e5ed07f1edff8951365fc9d095ab3a2c03/docs/CONTRIBUTING.md)的人，建议先查看 [Wiki](https://github.com/endless-sky/endless-sky/wiki)，并先在[社区运营的 Discord](https://discord.gg/ZeuASSx) 发帖。偏好 Steam 的用户也可以使用其[讨论区](https://steamcommunity.com/app/404410/discussions/)，或 GitHub 的[讨论区](https://github.com/endless-sky/endless-sky/discussions)。

Endless Sky 的主要讨论和开发区域曾是 [Google Groups](https://groups.google.com/g/endless-sky)，但由于我们无法控制的因素，新用户现已无法访问，因此不应再使用。
