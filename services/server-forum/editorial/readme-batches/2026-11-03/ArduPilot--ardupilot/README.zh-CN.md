ArduPilot 项目将其自动驾驶软件描述为现有开源方案中最先进、功能最全面且最可靠的方案。自 2010 年以来，它由专业工程师、计算机科学家和社区贡献者组成的多元团队开发。
我们的自动驾驶软件几乎可以控制各种载具系统，从常规飞机、四旋翼固定翼、多旋翼和直升机，到地面车、船只、平衡机器人，甚至潜艇。项目不断扩展，以支持新出现的载具类型。

## 如何参与

- ArduPilot 是开源项目，我们鼓励参与和贡献代码：[ArduPilot 代码库贡献指南](https://ardupilot.org/dev/docs/contributing.html)
- 我们有一群活跃的 Beta 测试人员帮助改进代码：[发布流程](https://ardupilot.org/dev/docs/release-procedures.html)
- 可以将期望的改进和错误提交到[问题列表](https://github.com/ArduPilot/ardupilot/issues)。
- 在[支持论坛](https://discuss.ardupilot.org/)帮助其他用户分析日志。
- 改进 Wiki，并在 [Discord #documentation](https://discord.com/channels/ardupilot) 与其他 Wiki 编辑者交流。
- 通过其中一个[沟通渠道](https://ardupilot.org/copter/docs/common-contact-us.html)联系开发者。
