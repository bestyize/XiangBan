# Quantum Mechanical Keyboard 固件

[![当前版本](https://img.shields.io/github/tag/qmk/qmk_firmware.svg)](https://github.com/qmk/qmk_firmware/tags)
[![Discord](https://img.shields.io/discord/440868230475677696.svg)](https://discord.gg/qmk)
[![文档状态](https://img.shields.io/badge/docs-ready-orange.svg)](https://docs.qmk.fm)
[![GitHub 贡献者](https://img.shields.io/github/contributors/qmk/qmk_firmware.svg)](https://github.com/qmk/qmk_firmware/pulse/monthly)
[![GitHub forks](https://img.shields.io/github/forks/qmk/qmk_firmware.svg?style=social&label=Fork)](https://github.com/qmk/qmk_firmware/)

这是基于 [tmk\_keyboard 固件](https://github.com/tmk/tmk_keyboard)的键盘固件，为 Atmel AVR 和 ARM 控制器提供一些实用功能，尤其面向 [OLKB 产品线](https://olkb.com)、[ErgoDox EZ](https://ergodox-ez.com) 键盘及 Clueboard 产品线。

## 文档

* [在 docs.qmk.fm 查看官方文档](https://docs.qmk.fm)

文档由 [VitePress](https://vitepress.dev/) 驱动，也可以离线查看；详见[预览文档](https://docs.qmk.fm/#/contributing?id=previewing-the-documentation)。

你可以 fork 仓库并提交 [pull request](https://github.com/qmk/qmk_firmware/pulls) 来提出修改。

## 维护者

QMK 由 OLKB 的 Jack Humbert 开发和维护，社区成员以及 [Hasu](https://github.com/tmk) 也作出了贡献。OLKB 产品固件由 [Jack Humbert](https://github.com/jackhumbert) 维护，Ergodox EZ 由 [ZSA Technology Labs](https://github.com/zsa) 维护，Clueboard 由 [Zach White](https://github.com/skullydazed) 维护，Atreus 由 [Phil Hagelberg](https://github.com/technomancy) 维护。
