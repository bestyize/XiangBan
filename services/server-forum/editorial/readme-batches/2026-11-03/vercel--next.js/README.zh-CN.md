## 开始使用

全球一些大型企业使用 Next.js。它通过扩展最新的 React 功能，并集成基于 Rust 的强大 JavaScript 工具，帮助你创建全栈 Web 应用，以实现最快的构建。

- 访问 [Learn Next.js](https://nextjs.org/learn) 课程，开始学习 Next.js。
- 访问 [Next.js 展示](https://nextjs.org/showcase)，查看更多使用 Next.js 构建的网站。

## 文档

访问 [https://nextjs.org/docs](https://nextjs.org/docs) 查看完整文档。

## 社区

Next.js 社区位于 [GitHub Discussions](https://github.com/vercel/next.js/discussions)，你可以在那里提问、发表想法并与他人分享项目。

如需与其他社区成员聊天，可以加入 Next.js [Discord](https://nextjs.org/discord) 服务器。

请注意，我们的[行为准则](https://github.com/vercel/next.js/blob/canary/CODE_OF_CONDUCT.md)适用于所有 Next.js 社区渠道。**强烈建议**用户阅读并遵守准则，以避免受到处理。

## 参与贡献

欢迎并十分感谢对 Next.js 的贡献。但在开始之前，请先阅读我们的[贡献指南](https://github.com/vercel/next.js/blob/61e1348fb523473db8cb3a6cfcadf7eefbf27d5f/contributing.md)，以便顺利参与 Next.js 的贡献。

### 适合新手的问题：

我们整理了一份 **[适合新手的问题](https://github.com/vercel/next.js/labels/good%20first%20issue)**列表，其中的错误影响范围相对有限。这是新来者和初学者上手、积累经验并熟悉贡献流程的好地方。

## 安全

如果你认为自己发现了 Next.js 的安全漏洞，我们建议你**_负责任地披露，且不要创建公开 issue_**。

如需参与我们的开源软件漏洞赏金计划，请访问 [https://hackerone.com/vercel](https://hackerone.com/vercel)。
