# Vikunja

> 真正由你掌控的任务管理工具。

如果 Vikunja 对你有帮助，请考虑[支持项目](https://vikunja.io/support/)。你可以[请作者喝杯咖啡](https://www.buymeacoffee.com/kolaente)、[在 GitHub 赞助](https://github.com/sponsors/kolaente)，或购买[贴纸包](https://vikunja.io/stickers)。
如果你希望为自己或团队寻找省心的方案，我们也提供 [Vikunja 托管版本](https://vikunja.cloud/)。
如果你或你的公司需要管理面板、审计日志或时间跟踪，请看看 [Vikunja Pro](https://vikunja.io/pro/)。

> [!NOTE]
> 在 Vikunja 的开发中，我们在代码库的多个部分使用了大语言模型辅助编程工具。
> @tink-bot 所做的大多数贡献都是以这种方式完成的。
