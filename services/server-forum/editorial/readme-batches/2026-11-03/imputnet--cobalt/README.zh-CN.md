### 使用伦理
cobalt 是一款让公开内容下载更方便的工具，**不承担任何责任**。
最终用户需为自己下载的内容，以及如何使用和传播这些内容负责。
cobalt 从不缓存任何内容，它[像一个精巧的代理一样工作](https://github.com/imputnet/cobalt/tree/a636575b09de1fc55d9b8cd98cac88f5f2f16b42/api/src/stream).

cobalt 绝不是盗版工具，也不能用于此类用途。
它只能下载免费且公开可访问的内容。
同样的内容也可以通过任何现代网页浏览器的开发者工具下载。
