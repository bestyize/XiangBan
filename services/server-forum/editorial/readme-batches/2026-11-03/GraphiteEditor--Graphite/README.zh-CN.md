# 用于二维内容创作的程序化工具箱

**Graphite 是一款免费开源的矢量与栅格图形引擎，现已提供 [Alpha 版本](https://editor.graphite.art)。使用完全无损的编辑工作流，将基于图层的合成与基于节点的生成式设计结合起来，发挥创意。**

Graphite 最初是一款矢量编辑器，目前正不断发展为通用的一体化图形工具箱，其构造更像游戏引擎，而非常规创意应用。编辑器工具围绕节点图核心构建，为矢量、栅格及其他内容提供易用的工作流。照片编辑、动态图形、数字绘画、桌面排版和视觉特效合成是[路线图](https://graphite.art/features/#roadmap)中计划增加的能力，目标是让 Graphite 成为用途广泛的内容创作工具。

在[网站](https://graphite.art/),了解更多，订阅[通讯](https://graphite.art/#newsletter),考虑[参与志愿工作](https://graphite.art/volunteer/)或[捐赠](https://graphite.art/donate/),，别忘了给这个仓库一颗 ⭐！

## 支持我们的使命 ❤️

Graphite 完全由社区构建并资助。如果认同我们的**使命**，欢迎通过[捐赠](https://graphite.art/donate/)帮助项目持续发展：

> Graphite 努力打造所有人都能使用的最佳综合艺术与设计工具，释放每一位新晋艺术家和资深专业人士的创造力。
> 
> 当 Graphite 成为行业标准时，这一使命才算成功。一致的产品愿景以及重创新、轻模仿的策略将使这一目标成为可能。
