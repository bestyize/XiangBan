## freeCodeCamp.org 的开源代码库与课程

[freeCodeCamp.org](https://www.freecodecamp.org) 是一个可以免费学习编程的友好社区。它由[捐赠支持的 501(c)(3) 慈善机构](https://www.freecodecamp.org/donate)运营，帮助数百万忙碌的成年人转入科技行业。我们的社区已帮助超过 100,000 人获得第一份开发工作。

我们的全栈 Web 开发和机器学习课程完全免费，可以按照自己的节奏学习。我们提供数千个互动编程挑战，帮助你拓展技能。

### 认证

freeCodeCamp.org 提供多项免费的开发者认证，共同构成[全栈开发者课程](https://www.freecodecamp.org/learn/full-stack-developer-v9/)：

- [响应式网页设计](https://www.freecodecamp.org/learn/responsive-web-design-v9/)
- [JavaScript](https://www.freecodecamp.org/learn/javascript-v9/)
- [前端开发库](https://www.freecodecamp.org/learn/front-end-development-libraries-v9/)
- [Python](https://www.freecodecamp.org/learn/python-v9/)
- [关系数据库](https://www.freecodecamp.org/learn/relational-databases-v9/)
- [后端开发与 API](https://www.freecodecamp.org/learn/back-end-development-and-apis-v9/)

每项认证都需要完成互动课程、工作坊、实验、复习和测验。认证过程中，你需要完成 5 个必修项目才能获得考试资格。通过考试后，即可领取认证。

freeCodeCamp.org 还提供基于国际公认能力等级设计的免费语言认证：

- [开发者 A2 英语（Beta）](https://www.freecodecamp.org/learn/a2-english-for-developers/)
- [开发者 B1 英语（Beta）](https://www.freecodecamp.org/learn/b1-english-for-developers/)
- [A1 职业西班牙语（Beta）](https://www.freecodecamp.org/learn/a1-professional-spanish/)
- [A1 职业中文（Beta）](https://www.freecodecamp.org/learn/a1-professional-chinese/)

这些认证按模块组织，每个模块包含热身、课程、练习、复习页面和测验，帮助你在进入下一模块之前充分掌握内容。你需要完成所有测验，才能获得认证末尾的考试资格。

获得认证后，你可以一直保有它，也可以随时在 LinkedIn 或简历中添加认证链接。潜在雇主或自由职业客户点击链接时，会看到经过验证、属于你的认证。

唯一的例外是发现违反我们的[学术诚信政策](https://www.freecodecamp.org/news/academic-honesty-policy/)。如果我们发现明确的抄袭行为（未经引用便将他人的代码或项目作为自己的成果提交），会撤销相关认证并禁止这些人继续使用平台。

此外，为帮助准备求职面试，freeCodeCamp.org 还提供 The Odin Project（freeCodeCamp Remix）、Coding Interview Prep、Project Euler 和 Rosetta Code。

还提供免费的专业 Foundational C# with Microsoft 认证。

### 学习平台

这些代码正在 [freeCodeCamp.org](https://www.freecodecamp.org) 上实际运行。

我们的社区还包括：

- 一个[论坛](https://forum.freecodecamp.org)，通常可以在数小时内获得编程帮助或项目反馈。
- 一个 [YouTube 频道](https://youtube.com/freecodecamp)，提供 Python、SQL、Android 和多种其他技术的免费课程。
- 一份[技术刊物](https://www.freecodecamp.org/news)，包含数千篇编程教程以及数学和计算机科学文章。
- 一个 [Discord 服务器](https://discord.gg/Z7Fm39aNtZ)，可以与开发者及正在学习编程的人交流。

> #### [在此加入社区](https://www.freecodecamp.org/signin).

### 报告错误和问题

如果你认为发现了错误，请先阅读[如何报告错误](https://forum.freecodecamp.org/t/how-to-report-a-bug/19543)并按照说明操作。

如果你确认这是新错误，且已确认其他人也遇到同样的问题，可以创建新的 GitHub issue。请尽量提供更多信息，以便我们复现错误。

### 报告安全问题与负责任披露

我们感谢对可能影响平台及用户完整性的漏洞进行负责任的披露。

> #### [阅读安全政策并按照这些步骤报告漏洞](https://contribute.freecodecamp.org/#/security).
