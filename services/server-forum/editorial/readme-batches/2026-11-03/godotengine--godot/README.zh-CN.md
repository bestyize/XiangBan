## 跨平台 2D 和 3D 游戏引擎

**[Godot Engine](https://godotengine.org) 是一款功能丰富的跨平台游戏引擎，可通过统一界面制作 2D 和 3D 游戏。** 它提供一套全面的[常用工具](https://godotengine.org/features)，让用户可以专注于制作游戏，无需重复造轮子。游戏可一键导出到多个平台，包括主流桌面平台（Linux、macOS、Windows）、移动平台（Android、iOS）、Web 平台和[游戏主机](https://godotengine.org/consoles)。

## 免费、开源、社区驱动

Godot 完全免费、开源，采用宽松的 [MIT 许可证](https://godotengine.org/license)。没有附加条件或版税。用户的游戏归用户所有，包括引擎代码的每一行。Godot 的开发完全独立，由社区驱动，用户可以参与塑造符合自己期望的引擎。它得到非营利组织 [Godot Foundation](https://godot.foundation/) 的支持。

在 [2014 年 2 月](https://github.com/godotengine/godot/commit/0b806ee0fc9097fa7bda7ac0109191c9c5e0a1ac)开源之前，[Juan Linietsky](https://github.com/reduz) 和 [Ariel Manzur](https://github.com/punto-) 已将 Godot 作为内部引擎开发多年，并用它发布了数款受雇开发的作品。

## 获取引擎

### 下载二进制文件

Godot 编辑器和导出模板的官方二进制文件可从 [Godot 网站](https://godotengine.org/download)下载。

### 从源代码编译

各受支持平台的编译说明请[参阅官方文档](https://docs.godotengine.org/en/latest/engine_details/development/compiling)。

## 社区与贡献

Godot 不只是一款引擎，也是一个不断发展的用户与引擎开发者社区。主要社区渠道列在[社区主页](https://godotengine.org/community)。

联系核心引擎开发者的最佳方式是加入 [Godot 贡献者聊天](https://chat.godotengine.org)。

开始参与项目贡献，请参阅[贡献指南](https://github.com/godotengine/godot/blob/b251066fb5b5654a6cf9c1bb284fac53d20a10d2/CONTRIBUTING.md).
这份文档还包含报告错误的指南。

## 文档与演示

官方文档托管在 [Read the Docs](https://docs.godotengine.org)，由 Godot 社区在独立的 [GitHub 仓库](https://github.com/godotengine/godot-docs)中维护。

也可以从 Godot 编辑器访问[类参考](https://docs.godotengine.org/en/latest/classes/)。

我们还在独立的 [GitHub 仓库](https://github.com/godotengine/godot-demo-projects)以及[资产商店](https://store.godotengine.org/)维护官方演示。

社区还提供许多其他[学习资源](https://docs.godotengine.org/en/latest/community/tutorials.html)，如文字和视频教程、演示等。更多信息请参阅[社区渠道](https://godotengine.org/community)。
