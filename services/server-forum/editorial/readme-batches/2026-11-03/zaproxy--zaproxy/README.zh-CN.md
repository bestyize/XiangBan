Checkmarx 的 Zed Attack Proxy（ZAP）是一款广泛使用的 Web 应用扫描器。项目称其为全球使用最广泛的 Web 应用扫描器。它免费且开源，是一个由社区驱动、任何人都可以参与贡献的 GitHub Top 1000 项目。

它可以帮助你在开发和测试 Web 应用时自动查找安全漏洞。对经验丰富的渗透测试人员而言，它也是进行手动安全测试的工具。
