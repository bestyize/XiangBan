## 开始使用

开始使用 Docmost，请参阅我们的[文档](https://docmost.com/docs)或试用[云端版本](https://docmost.com/pricing)。

## 功能

- 实时协作
- 图表（Draw.io、Excalidraw 和 Mermaid）
- 空间
- 权限管理
- 用户组
- 评论
- 页面历史
- 搜索
- 文件附件
- 嵌入内容（Airtable、Loom、Miro 等）
- 翻译（10 多种语言）

### 许可证

Docmost 核心采用开源的 AGPL 3.0 许可证。  
企业版功能采用企业许可证（Enterprise Edition）。

以下目录中的所有文件均采用 `packages/ee/License` 中定义的 Docmost 企业许可证。
  - apps/server/src/ee
  - apps/client/src/ee
  - packages/ee
