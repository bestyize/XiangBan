## 功能

Excalidraw 编辑器（npm 包）支持：

- 💯&nbsp;免费且开源。
- 🎨&nbsp;无限画布白板。
- ✍️&nbsp;手绘风格。
- 🌓&nbsp;深色模式。
- 🏗️&nbsp;可自定义。
- 📷&nbsp;支持图片。
- 😀&nbsp;支持形状库。
- 🌐&nbsp;支持本地化（i18n）。
- 🖼️&nbsp;导出为 PNG、SVG 或复制到剪贴板。
- 💾&nbsp;开放格式——将绘图导出为 `.excalidraw` JSON 文件。
- ⚒️&nbsp;丰富的工具——矩形、圆形、菱形、箭头、线条、自由绘制、橡皮擦等。
- ➡️&nbsp;箭头绑定和带标签的箭头。
- 🔙&nbsp;撤销 / 重做。
- 🔍&nbsp;支持缩放和平移。

## Excalidraw.com

托管在 [excalidraw.com](https://excalidraw.com) 的应用是使用 Excalidraw 所能构建内容的一个简单展示。它的[源代码](https://github.com/excalidraw/excalidraw/tree/master/excalidraw-app)也是本仓库的一部分，应用具有以下功能：

- 📡&nbsp;支持 PWA（可离线使用）。
- 🤼&nbsp;实时协作。
- 🔒&nbsp;端到端加密。
- 💾&nbsp;本地优先（自动保存到浏览器）。
- 🔗&nbsp;可分享链接（导出为只读链接并分享给他人）。

未来我们会将这些功能作为可直接使用的插件加入 npm 包。

## 快速开始

**注意：** 以下说明适用于在你自己的应用中集成 Excalidraw 时安装其 [npm 包](https://www.npmjs.com/package/@excalidraw/excalidraw)。如需在本地运行本仓库进行开发，请参阅[开发指南](https://docs.excalidraw.com/docs/introduction/development)。

使用 `npm` 或 `yarn` 安装该包。

```bash
npm install react react-dom @excalidraw/excalidraw
# or
yarn add react react-dom @excalidraw/excalidraw
```

更多详情请参阅[文档](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/installation)！
