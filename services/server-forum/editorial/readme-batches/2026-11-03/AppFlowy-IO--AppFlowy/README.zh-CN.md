## 我们为什么要构建它？

近年来，Notion 因其外观和功能成为我们最喜欢的项目与知识管理工具。我们的团队每天都在使用它，并订阅了付费方案。不过，我们认为 Notion 也有局限，包括数据安全性不足和移动设备兼容性欠佳。同样，其他协作式工作管理工具也有各自的限制。

我们在使用这些工具时遇到的局限，以及过去在协作生产力工具方面的经验，让我们坚信此类工具未来的能力存在一个天花板。我们认为，这些工具在某个阶段可能难以横向扩展，不得不优先满足部分客户的需求，而这些需求与其他客户不同。尽管决策者希望拥有一个工作场所操作系统，在如此分散的市场中也很难找到适合所有人的方案。

当客户不断变化的核心需求得不到满足时，他们要么更换工具，要么在内部从头构建。这样一来，他们要么面对另一个天花板，要么花费高昂代价吸取经验。构建可靠、易用的协作工具需要大量资源和专业知识，更不用说速度和原生体验。个人用户也可能面临同样的问题。

所有这些限制促成了我们的使命：让任何人都能创建适合自己需求的应用。

- 对个人用户，我们希望提供 Notion 的功能、数据安全性和跨平台原生体验。
- 对企业和技术爱好者，AppFlowy 致力于提供构建模块和协作基础设施服务，让你自行创建应用。你还可以 100% 控制自己的数据。你可以按照自己的方式设计和修改 AppFlowy；它采用 Flutter 和 Rust 编写的单一代码库，支持多个平台并兼顾长期可维护性。

我们决定坚持以下三个基本价值来实现这一使命：

- 数据隐私优先
- 可靠的原生体验
- 社区驱动的可扩展性

我们并不声称在功能和设计上超越 Notion，至少目前如此。此外，我们当前的重点也不是增加更多功能。相反，我们希望培育一个社区，让构建复杂工作管理工具的知识与基础组件更加普及，并通过多用途构建模块工具箱，帮助个人和企业自行创造出色的作品。
