我们不接受 pull request。项目完全由核心团队开发。

## 范围

draw.io 是图表和白板应用，不是 SVG 编辑器。SVG 导出用于嵌入网页，并非用于在其他工具中编辑。

请注意，此版本的 draw.io 目前不支持实时协同编辑。

对于任何 draw.io 产品中有关编辑器的问题，可以从此处的问题跟踪器和讨论区开始查找。

## 运行

本仓库是 draw.io 的测试版本，用于评估和试用。用于生产部署的付费生产版本另行提供。

运行测试版本的方式：

- Fork 本仓库并[发布到 GitHub Pages](https://help.github.com/categories/github-pages-basics/)，获得不带集成功能的[编辑器](https://jgraph.github.io/drawio/src/main/webapp/index.html)
- 使用 [Docker 镜像](https://github.com/jgraph/docker-drawio)
- 使用[发布页面](https://github.com/jgraph/draw.io/releases)中打包的 .war 文件

桌面应用请下载 [draw.io Desktop](https://get.diagrams.net)。
