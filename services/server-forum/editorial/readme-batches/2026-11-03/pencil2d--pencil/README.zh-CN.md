# Pencil2D Animation

**Pencil2D** 是适用于 Windows、macOS、Linux 和 FreeBSD 的免费开源动画与绘画软件，可同时使用位图和矢量图形创作传统手绘动画（卡通）。

Pencil2D 是一个由社区推动、完全由志愿者开发的项目，我们一直期待更多人加入！贡献方式有很多，因此无论背景如何都可以帮忙。详情请参阅下方[参与贡献](#参与贡献)部分。

别忘了访问我们的官方网站：<https://www.pencil2d.org/>

### 每夜构建版

每夜构建版是包含最新修复和功能的前沿版本。它们不如正式发布版稳定，但很适合用来测试最新功能并帮助我们发现错误。

[下载每夜构建版](https://www.pencil2d.org/download/nightly/)

## 使用 Pencil2D

Pencil2D 包含一份快速参考，帮助你熟悉可用工具和功能。可以通过主菜单访问：帮助 > 快速参考指南。

我们建议你访问[用户手册][user-man]，阅读面向新手的快速指南，然后动手玩一玩这个程序——很有趣！

[user-man]: https://www.pencil2d.org/doc/user-manual.html

熟悉基本操作后，可以看看 Pencil 开发者和用户提供的这些[教程][pencil-tutorials]。其中一些资源可能涉及 Pencil2D 的旧版本，但基本概念仍然相同。

[pencil-tutorials]: https://www.pencil2d.org/doc/tutorials.html

如果遇到困难或有其他问题，我们有许多乐于助人的社区用户。请查看网站上的[常见问题][p2d-faq]，或访问[讨论论坛][p2d-discussion]提出新问题。

[p2d-faq]: https://www.pencil2d.org/doc/faq.html
[p2d-discussion]: https://discuss.pencil2d.org/c/support/5

## 参与贡献

有兴趣为 Pencil2D 作贡献吗？帮忙的方式有很多。你可以查看有哪些问题需要处理、阅读开发者指南，或参与翻译，让更多人能够使用 Pencil2D。

* [问题跟踪器](https://github.com/pencil2d/pencil/issues) - 报告错误或提出功能需求。
* [开发者指南](https://dev.pencil2d.org/) - 学习如何自行编译 Pencil2D。
* [Transifex](https://www.transifex.com/pencil2d/) - 你也可以帮助翻译 Pencil2D。
* [文档贡献](https://www.pencil2d.org/doc/CONTRIBUTING) - 参与文档编写。
