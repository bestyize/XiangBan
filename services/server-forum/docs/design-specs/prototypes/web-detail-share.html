PC 端网页 · 居中双栏分享弹窗 左栏实时卡片预览，右栏一键复制链接 / 图片 / 推荐语

手机 H5 · 与手机 App 一致 单行横滑轨 + 沉浸卡片

双端设计要点与组件抽象

手机 H5 1:1 对齐手机 App

移动端浏览器（< 768px）直接采用手机 App 同一套底部面板：单行上下文预览卡 + 单行可横滑图标轨 + 通栏「取消」；「分享卡片」采用同款全屏暗色磨砂舞台与底部三图标栏。去掉了浏览器里冗余的「浏览器打开」，并在不支持 Web Share API 时自动隐藏「系统分享」。

PC 端一步到位双栏弹窗（716px）

取代旧版 420px 窄海报弹窗与静默复制链接。左栏固定所见即所得卡片预览（纯白 / 暖纸笺 / 墨夜 + 摘录 / 二维码开关），右栏集中处理 PC 高频操作：复制链接、直接复制卡片图片粘贴进微信/飞书、下载 PNG、复制推荐语 / 全文与问问小伴，零二级弹窗跳转。

面板纯中性 + 分享图保留主题色

PC 右栏操作区、H5 底部抽屉与手机 App 分享面板均采用纯黑白灰中性色阶（复制完成显示勾选和文字，主态删除用语义红）；主题色只克制用于分享图内的品牌徽标与分享图标记，保证导出的分享图仍有清晰的小伴品牌辨识度。

单组件复用（DetailShareDialog.vue）

建议在 services/server-forum/web 抽成独立共享组件：外部详情页（帖子 / 作品 / 开源 / 日报 / 内容包）仅传 SharePayload（title / excerpt / url / badge / author / cover / canDelete）与回调，按视口自动切换 PC 双栏弹窗或 H5 底部抽屉，彻底替代旧 PosterDialog。
