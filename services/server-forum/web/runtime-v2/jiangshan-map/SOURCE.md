# 江山时序 · Jiangshan Atlas

原作 DeanChensj。 [项目源码](https://github.com/DeanChensj/jiangshan-map) · [完整在线地图](https://deanchen.me/jiangshan-map/)

小伴版基于上游提交 `6d9c6fdd84b41520d3421eecedf9be7b0b6e6310`，以 GPL-3.0 分发。包内是可直接编辑的 HTML、CSS、JavaScript 和地图数据，完整许可证见 `LICENSE.txt`。 [小伴打包脚本](https://github.com/bestyize/XiangBan/blob/main/services/server-forum/web/scripts/build-jiangshan-map-pack.py)

政权轮廓参考 [historical-basemaps](https://github.com/aourednik/historical-basemaps)，由原作者对照史料调整。地形阴影来自上游以 [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) 公版高程数据制作的图层。历史疆界为示意。小伴版覆盖公元前 403 年至 1948 年，剔除了独立授权的郡州府边界和现代省界，也移除了网页统计脚本与古琴音频。
