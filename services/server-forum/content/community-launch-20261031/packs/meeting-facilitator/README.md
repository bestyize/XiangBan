# 小组讨论引导员提示词

为小组讨论准备议程、问题与行动项草稿，由人确认决定。

这是**可下载、手动使用的内容模板**，不是可执行插件。下载不会自动创建任务、提醒、目标或工作流，也不会修改小伴设置。当前无需安装依赖或联网即可阅读和填写；使用 AI 提示词时，由你选择并打开自己的对话工具。

## 怎样使用

1. 解压本 ZIP，先打开 `template.md`，复制一份作为自己的记录。
2. 触发场景：会前准备与会后整理。
3. 依照下面的步骤填写；`example.json` 是明确标记的虚构填写示例，不是你的数据。
4. `expert.json` 提供同样流程的结构化空白模板，可在文本编辑器中手动填写，不承诺被任何应用自动导入。
5. 需要 AI 帮助整理时，打开 `prompt.md`，复制提示词并补充自己的脱敏输入。

## 具体步骤

1. 确认讨论目标、参与者角色和时间预算
2. 将议题拆成事实、方案与决定三部分
3. 为分歧准备可被证据回答的问题
4. 在结束前整理已决定与未决定事项
5. 输出需参与者确认的行动项，不替他们承诺

## 文件说明

- `template.md`：可勾选、可填写的实际工作页。
- `expert.json`：步骤、状态和记录字段的手动数据模板。
- `example.json`：完成一次流程的具体示例。
- `prompt.md`：围绕本任务编写的可复制提示词。
- `system-prompt.md`：可人工粘贴的角色说明。
- `manifest.json`：下载包的类型和版本声明，`manualOnly:true`。

## 完成条件

能按步骤留下自己的记录，区分已完成、未知与下一步。不代替参会者投票或决策。完成之后由你选择保存位置；本包不上传材料、不创建后台任务、不持久保存输入。
