# 证据与断言核对技能

针对用户提供的材料逐项标记支持、矛盾与未知，不编造来源。

这是**可下载、手动使用的内容模板**，不是可执行插件。下载不会自动创建任务、提醒、目标或工作流，也不会修改小伴设置。当前无需安装依赖或联网即可阅读和填写；使用 AI 提示词时，由你选择并打开自己的对话工具。

## 怎样使用

1. 解压本 ZIP，先打开 `template.md`，复制一份作为自己的记录。
2. 触发场景：给出待核实文本与可读来源。
3. 依照下面的步骤填写；`example.json` 是明确标记的虚构填写示例，不是你的数据。
4. `skill.json` 提供同样流程的结构化空白模板，可在文本编辑器中手动填写，不承诺被任何应用自动导入。
5. 需要 AI 帮助整理时，打开 `prompt.md`，复制提示词并补充自己的脱敏输入。 `SKILL.md` 是可供兼容工具人工登记的技能说明；本包不运行安装器。

## 具体步骤

1. 把待审文本拆成可验证的单独断言
2. 只从用户提供且实际可读的材料中收集对应证据
3. 记录材料位置、日期与证据是否直接支持
4. 将断言分类为支持、部分支持、矛盾或无法判断
5. 给出最小修改建议，并保留未解决问题

## 文件说明

- `template.md`：可勾选、可填写的实际工作页。
- `skill.json`：步骤、状态和记录字段的手动数据模板。
- `example.json`：完成一次流程的具体示例。
- `prompt.md`：围绕本任务编写的可复制提示词。
- `SKILL.md`：含 name/description 的技能说明。
- `manifest.json`：下载包的类型和版本声明，`manualOnly:true`。

## 完成条件

能按步骤留下自己的记录，区分已完成、未知与下一步。不得伪造引文或假装浏览。完成之后由你选择保存位置；本包不上传材料、不创建后台任务、不持久保存输入。
