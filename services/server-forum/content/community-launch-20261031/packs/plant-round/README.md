# 绿植巡看清单

用观察而非固定浇水天数管理五个常见检查点，附盆栽记录表。

这是**可下载、手动使用的内容模板**，不是可执行插件。下载不会自动创建任务、提醒、目标或工作流，也不会修改小伴设置。当前无需安装依赖或联网即可阅读和填写；使用 AI 提示词时，由你选择并打开自己的对话工具。

## 怎样使用

1. 解压本 ZIP，先打开 `template.md`，复制一份作为自己的记录。
2. 触发场景：每次巡看绿植时。
3. 依照下面的步骤填写；`example.json` 是明确标记的虚构填写示例，不是你的数据。
4. `reminder.json` 提供同样流程的结构化空白模板，可在文本编辑器中手动填写，不承诺被任何应用自动导入。
5. 需要 AI 帮助整理时，打开 `prompt.md`，复制提示词并补充自己的脱敏输入。

## 具体步骤

1. 给每盆植物写名称与摆放位置
2. 查看土表、叶片和盆底，记录实际观察
3. 先确认该植物自己的照料要求，再决定是否处理
4. 处理后写下做了什么，不用统一浇水量
5. 在自己的日历中安排下次查看，季节变化时重新评估

## 文件说明

- `template.md`：可勾选、可填写的实际工作页。
- `reminder.json`：步骤、状态和记录字段的手动数据模板。
- `example.json`：完成一次流程的具体示例。
- `prompt.md`：围绕本任务编写的可复制提示词。

- `manifest.json`：下载包的类型和版本声明，`manualOnly:true`。

## 完成条件

能按步骤留下自己的记录，区分已完成、未知与下一步。观察记录模板。完成之后由你选择保存位置；本包不上传材料、不创建后台任务、不持久保存输入。
