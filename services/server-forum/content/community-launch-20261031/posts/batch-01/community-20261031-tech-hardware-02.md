“AI 语音硬件”不一定在板子上运行完整大模型。麦克风采集、语音识别、对话推理和语音播放，可能分布在设备、本地电脑与远端服务，入门时先画清数据流。

以 ESP32 生态项目为例，先核对开发板具体型号、麦克风与功放接线，再查看项目支持的板型和固件配置。ESP-IDF 官方入门说明是工具链基础；项目 README 则决定具体依赖与兼容要求，不能混用不同年代的烧录教程。

第一阶段只验证供电和串口日志，第二阶段验证网络连接，第三阶段验证录音和播放，最后才接入对话链路。这样听不到声音时，能区分硬件、网络和模型服务的问题。

不要在公开视频、截图或论坛日志中暴露 Wi-Fi 密码、设备令牌和服务密钥。若声音会发送到远端，使用前说明发送对象；“设备在家里”不代表音频一定留在本地。

小智 ESP32 是可查阅的开源项目入口，但选购零件前仍需核对当前支持板型与许可证。先把最小链路跑通，再考虑屏幕、外壳和更多传感器，可以少走不少重复拆装的弯路。

资料：[ESP-IDF 官方入门](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/get-started/index.html)；[小智 ESP32 官方仓库](https://github.com/78/xiaozhi-esp32)。
