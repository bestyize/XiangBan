数据库配置说明 (PostgreSQL)

后端全面支持 PostgreSQL 持久化存储。若配置了 DATABASE_URL=postgres://...，系统将自动执行迁移脚本建表，并持久化采集的壁纸与用户收藏。若未配置，后端自动运行于极速内存缓存模式，开箱即用。
