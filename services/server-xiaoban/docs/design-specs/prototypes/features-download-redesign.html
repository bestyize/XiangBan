DESIGN AUDIT

现行版痛点诊断与重设计对照

基于 `ProductFeatures.vue`、`ProductDownload.vue` 与 `ProductDownloads.vue` 现行源码逐项梳理问题，彻底告别浅绿偏旧配色，转向克制高级的现代中性色体系（并支持顶部一键切换「暖白·墨黑 / 暖纸·珊瑚 / 晴白·冰蓝」）。

一、功能页 `/features` 改版要点

现行版痛点
✕
首屏右侧空洞，且锚点漏项仅有左对齐大字和 3 个胶囊，页面实际有 5 个功能章节，导航却漏掉了 `04 AI 插件` 和 `05 游玩空间`。
✕
截图套 12px 实心绿粗边框`border: 12px solid #e7eee4` 让不同长宽比的实机截图显得生硬廉价，缺乏首页的展台层次与图注。
✕
连续五段完全重复的呆板 Z 字布局视觉节奏平淡冗长，要点列表是浏览器默认黑圆点，读起来像纯 Markdown 文档。
✕
底部收口仓促、缺少页脚只有一条扁平的 CTA 色块，缺少导航闭环。
新版改进方案
✓
分栏 Hero + 五大能力速览 Bento + 吸顶 5 锚点条首屏即见产品全景，补齐全部 5 个模块跳转，滚动时吸顶指示当前阅读章节。
✓
升级为「柔灰展台 + 精致窗口框 + 状态胶囊 + 图注」统一克制的中性展台画板与精致窗口顶栏，为 `02 创作` 补充示例需求条，呈现“输入 → 成果”叙事。
✓
节奏张弛有度：双栏 → 宽幅全景 Bento → 双卡收束`03 个性桌面` 改为全景大图 + 3 张特性微卡；`04 AI 插件` 与 `05 游玩空间` 合为高密度对称双卡，消除滚动疲劳。
✓
结构化图标特性条 + 完整页尾用白底细框微卡替代表单黑圆点，补齐与首页一致的 Closing Banner 和页脚。
