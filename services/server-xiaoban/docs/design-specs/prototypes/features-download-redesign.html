GETTING STARTED

装好之后，3 步释放双端全部能力

01

登录即用，或免登录接自有模型

登录相伴统一账号即可在双端共享小伴 AI 额度；如果你有 OpenAI / Anthropic 等第三方 API，在桌面独立设置窗或手机模型配置里直接添加，密钥仅存本机。

02

电脑开启控屏、画布与活桌面

在工作区派发自主任务、按全局快捷键用超级小伴截图标注、在设计画布导出 .pptx / .fig，再把 3D 龙鱼特效、实时股票组件和 7 只桌宠请上屏幕。

装上 Android 版，随身造作品与遥控电脑

出门用端侧离线语音通话聊灵感、在手机本地造 3D 游戏或遥控家里电视空调；电脑上跑着长任务时，还能在手机实时看进度并远程审批权限。
