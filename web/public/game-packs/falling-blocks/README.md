# 俄罗斯方块资源包

这是一个独立的单人下落方块游戏包。游戏页面不导入下班了么的 React 组件，不读取账号、不调用网站 API，也不访问网站的本地存储。

## 包结构

- \`manifest.json\`：包编号、版本、显示名称、入口文件和运行协议版本
- \`index.html\`：独立入口
- \`game.css\`、\`game.js\`：全部游戏界面与规则

## 操作

- 电脑：方向键移动和旋转，空格快速下落，P 暂停，Esc 返回
- 手机：点按屏幕下方的操作按钮
- 消行、计分、速度升级、重新开始均在本包内运行

## 添加另一款游戏

为新游戏创建一个独立目录和清单，在 \`catalog.json\` 的 \`games\` 中增加包编号。运行器按编号读取清单并在受限 iframe 中打开入口，不需要在网站组件里编写游戏规则。
