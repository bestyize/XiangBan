# 趣味测试

入口位于首页「玩一局」与「登录 / 注册」之间。`/tests` 为合集，
`/tests/:quizId` 为答题页，`/tests/:quizId/report` 为报告页。
测试模块按需加载，位于 SessionProvider 外；朋友打开分享链接时无需注册或完成引导。

## 题目和方法

- **MBTI 风格探索**：40 题，四组偏好各 10 题，正反向各 5 题；五档符合程度。
  一部分题目改写自公共领域 IPIP 条目，每题以 `source` 标明，其余情境题及全部报告为原创。
  四组偏好为 E/I、S/N、T/F、J/P。这组题目未经心理测量验证，不是官方 MBTI、IPIP 的正式量表或 16Personalities 测试。
- 单题贡献为 `(答案 - 3) × 方向`，每维范围 -20 到 20。正向对应 E、N、T、J。
  0 分以 X 表示未确定；绝对值 ≤ 4 时提示接近平衡。16 种确定类型和含 X 的结果都有报告。
  柱状图按本次得分归一化，S/N 显示方向作相应转换；百分比不是概率、准确率或人群排名。
- **M班TI（版本 2）**：20 道原创职场情境题，每题四个选项；五种风格各出现 16 次，选项位置轮换。
  每个选项给一个风格计 1 次，按选择次数展示配方。同分并列，不任意指定冠军。
  这是娱乐画像，不是工作表现或心理健康评估。
- **精神小动物（版本 1）**：12 道原创生活情境题，围绕相处距离、生活步速和新鲜感，
  每组各 4 题。八种小动物拥有独立的插画、名片、相处建议和充电文案。
- **下班第二人格（版本 1）**：12 道原创下班情境题，围绕充电空间、晚间节奏和快乐入口，
  每组各 4 题。八种生活角色拥有独立插画与报告；“第二人格”只作生活状态的趣味比喻。
- 两项新测试每题四个选项，贡献为 -2、-1、1、2，位置轮换；每维范围 -8 到 8。
  三个维度的正负组合对应八个主要结果，任一维为 0 时保留多面结果，不强行归类。
  百分比为 `50 + 得分 / 8 × 50`，绝对值 ≤ 2 时提示两边接近。题目、文案与 SVG 插画均为原创。

调研来源（2026-10-04）：

- [IPIP 使用许可：公共领域，可用于商业和非商业用途](https://ipip.ori.org/newPermission.htm)
- [IPIP Big Five 原始条目与键值](https://ipip.ori.org/newBigFive5broadKey.htm)
- [Myers & Briggs Foundation 四组偏好说明](https://www.myersbriggs.org/my-mbti-personality-type/myers-briggs-overview/)
- [16Personalities 交互参考](https://www.16personalities.com/en/personality-test)：参考进度、等级选择与答题后报告流程，未复制题目、插画、结果文案。

未采用 OEJTS 题目：其当前公开版本为 CC BY-NC-SA，不适合直接混入可能商业化的网站。

## 进度与分享

- `xb_quiz_<id>` 仅保存当前浏览器的答案、题号和完成时间；题库版本或答案结构不兼容时弃用旧进度。
  浏览器清理数据后会失去进度，禁止存储的环境沿用项目的内存回退。
- 单题显式下一步，支持上一题、题号回看及完成后的修改；提交前检查所有答案。
- 分享链接的 fragment 只携带题库版本和汇总分（性格四维、职场五类、生活三维）；不带逐题答案、用户 ID、邮箱或昵称。
  fragment 不进入 HTTP 请求。无效、截断、版本不支持的分享不回退成当前用户的报告。
- M班TI 的 25 题旧版分享继续以版本 1 的题库和分母解读，页面标明旧版；
  新测试采用版本 2 的 20 题，旧版答题进度不复用，以免答案错配。
- 海报使用本地 Canvas 和现有 `qrcode` 依赖，含结果二维码；不上传图片。
  支持 Web Share、原有 App bridge、PNG 下载、微信长按和复制链接回退；关闭页面会释放对象 URL。
- 结果可由用户自行修改分享链接；这是自我探索内容，不用于证明身份、认证或任何高风险决策。

## 扩展

在独立文件增加题目和报告文案，扩充 `QuizId` 与 `catalog.ts`，并在 `scoring.ts`
登记计分、聚合分校验及报告构造。三维生活类测试可直接提供 `persona` 定义，
复用 `persona.ts` 的题目构造和报告计分；`art.ts` 保存固定 SVG 插画与配色。
集合页、答题器、进度和分享复用现有组件。
修改已有题目的数量、顺序或计分时必须提升版本，避免旧答案和旧分享错配。

## 验证

`npm run test` 覆盖所有 16 个性格端点、两项生活测试各 8 个主要结果、平衡与接近平衡、
反向条目、职场并列画像、不完整答案、分享聚合数据校验、20 题均衡曝光、25 题旧版分享和进度兼容。
`npm run build` 与 `npm run lint` 检查类型、构建及代码。

浏览器回归应包括：320 / 390 像素答题、固定底部导航与安全区、刷新续答、回看修改、
完成新增两套测试及 20 题 M班TI、无账号分享访问、中立与并列报告、PNG 海报、无效链接，以及桌面集合页。
移动 Safari / 微信 / App 的原生保存和分享需要在相应真机环境验证。
