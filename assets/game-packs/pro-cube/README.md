# 3D全阶魔方 · Pro Cube Simulator

3~9阶全系真实质感磁力魔方游戏包。

- 引擎：Three.js + Web Audio API 机械磁力定位音效合成
- 特色：3~9 任意阶数切换，3D 射线拾取任意层切层旋转，多层深度控制，3 种表面工艺（亮面、磨砂、碳纤维），随机打乱与智能还原
- 运行：支持自包含离线运行，适配桌面端与触屏操作

## 图标

`icon.webp` 用内置 imagegen 生成，尺寸为 256 × 256，供桌面与 Android 的游戏包共用。
