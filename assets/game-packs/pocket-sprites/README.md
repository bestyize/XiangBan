# 口袋精灵

小伴内置的竖屏三消游戏。交换相邻精灵，连成三个或更多同色精灵。每关有独立的步数和目标，消除形成的特殊精灵可以帮助清理冰块和蜂蜜。

游戏使用运行时协议 2。Android 构建从桌面资源副本打包。调整后同步到 `client/xiaoban-desktop/public/game-packs/pocket-sprites/`，在仓库根目录运行 `node client/xiaoban-desktop/scripts/check-game-assets.mjs` 校验资源。

在仓库根目录运行 `python tools/preview-pocket-sprites.py`，然后访问 [本地预览](http://127.0.0.1:1473/assets/game-packs/pocket-sprites/index.html)。

关卡数据位于 `levels.mjs`。棋盘按各关 `size`（8 或 9）的行优先索引表示，`.` 表示空洞，`#` 表示可用格，`i` 表示单层冰，`I` 表示双层冰，`h` 表示蜂蜜。固定开局的关卡以颜色数字标出初始精灵，其余关卡由引擎填盘。颜色 0 至 5 依次为红鸟、黄星、绿芽、蓝水母、紫狐、云羊。

共 20 关。第 1–3 关介绍交换、收集与四连火箭。第 4–6 关加入花盆形棋盘、紫狐和单层冰。第 7–9 关练习在切角和沙漏棋盘清冰，并用 T 形消除生成炸弹。第 10–12 关加入双窗棋盘、云羊和蜂蜜。第 13–15 关介绍五连彩虹，并在花坛棋盘同时清理冰块和蜂蜜。第 16–18 关加入双层冰和火箭组合，第 18 关让六种精灵同场。第 19 关回到收集玩法，第 20 关综合单层冰、双层冰和蜂蜜。障碍目标按完全清除的格数计算。

运行 `node tools/check-pocket-sprites-levels.mjs` 可检查关卡结构、教学交换和自动试玩。关卡平衡仍需真机试玩确认。

## 1.4.1 离线语音奖励（当前版本）

复用方块爆破的 Nice、Good、Great、Wonderful 四句离线 MP3，复制进本包 `assets/voice-*.mp3`，不跨包引用或联网。音色来源与方块爆破一致：Kokoro-82M v1.0 的 af_bella / af_sky 混合音色。

普通三连不报彩；单次高能合成或一次清除至少六格为 Nice，范围高能或二连消为 Good，虹彩鸟/特殊组合/三连消为 Great，四连及以上或通关为 Wonderful。每次交换结算只选最高一档，低档奖励有 2.4 秒冷却，当前语音未结束时不叠加、不积压旧奖励；通关可替换旧奖励。暂停、切界面、后台和总静音立即停止语音；播音期间进一步压低背景乐。语音分级、冷却与异常降级检查：`node tools/check-pocket-sprites-rewards.mjs`。

## 1.4 高能外观与棋盘密度

横向、纵向、爆炸高能精灵使用 `assets/power-sprites.png` 的三个独立轮廓：左右展开的横翼、上下延伸的纵羽、向四周展开的爆花；虹彩鸟继续使用独立图像。前三者右下角的原精灵标记保留颜色归属，匹配与收集规则不变。素材为内置 imagegen 原创生成，3 列 1 行、透明背景，提示词重点为软陶质感和横/纵/放射状轮廓，而非普通精灵叠加光带。

多数非固定教学关扩展为 9×9，保留 8×8 教学开局及第 4 关。棋子按九列屏宽限制尺寸，不再把小棋盘自动放大铺满屏幕。旧版星级保留，旧几何规则下未结束的局重开。关卡仍保持 20～30 步及精灵收集目标，障碍总数保持原有设计。

## 1.3 空间利用与方向特效

运行页仅按系统安全区留顶边，标题复用右上宿主胶囊左侧区域，局部预留胶囊实际宽高；不再让整个页面退到胶囊底部。目标/步数压缩为紧凑 HUD，暂停与提示移到底部。棋盘缩小外边距与边框，长方形关卡优先满宽，并根据可用高度缩放；所有棋子格仍保持正方形。375×800 与 320×568 验证控件不与胶囊相交、目标不溢出。

## 1.2 目标驱动难度

1.2.1 混音与反馈：音乐基础增益从 0.28 调至 0.10，消除/高能期间压至 0.022，再平滑回升。高能合成后增加 440ms 独立放大、聚光环、能力文字及提示音，再进行掉落；减少动态模式只保留文字与声音。横竖特效光束及棋子能量带加粗。浏览器验证音乐压低、生成动画与清理，以及目标布局。

每关保持 20～30 步，改由精灵收集种类、数量及障碍组合决定难度，取代 1.1 的减半步数方案。所有关卡都有精灵收集目标，每关最多三个目标；多目标在窄屏自动换行。第 5 关为 24 步收集紫狐 55、红鸟 45；第 6 关为 25 步收集水母 50、红鸟 40、清冰 12；第 20 关为 30 步收集云羊 35、清冰 16、清蜂蜜 8。详细目标以 `levels.mjs` 为准。

32 个固定种子的策略验证全部关卡均有通关样本，后期 15/18/20 关仍为挑战；模拟策略可查看未来补充结果，其达成率不代表真人难度。星级保留，旧规则下未结束的局重开，避免沿用旧目标进度。

## 1.1 调整（历史，步数方案已被 1.2 替代）

四连生成横/纵能量精灵，T/L 五连生成范围精灵，直线五连生成虹彩鸟；两个特殊精灵交换触发组合。消除、收集、下落及连锁采用分阶段动效，减少动态偏好会跳过装饰动画。

背景乐 `assets/garden-skip.mp3`（《花园小步舞》，110 BPM，约 69.82 秒）为本地原创程序编曲，无第三方采样。生成来源 `tools/compose-pocket-sprites.py`，具体时长及循环点见 `assets/music.json`。因 ElevenLabs 凭据未配置，采用离线合成的拨弦、木琴、贝斯、木块和沙锤，不是外部模型生成录音。首次操作解锁播放，暂停/后台停止推进，静音覆盖全部声音，暂停菜单可单独关闭背景乐。重复切关不叠加音乐源。

Android 官方运行页在就绪后使用透明系统栏和浅色图标；网页保留真实安全区及胶囊避让。手机安装验收以当前调试 APK 为准。
