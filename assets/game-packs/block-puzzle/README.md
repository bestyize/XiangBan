# 方块爆破（小伴内置游戏）

游戏 ID：`block-puzzle`（保留旧「消失高手」ID，避免入口与历史记录失效）。版本 2.0.1。纯 HTML/CSS/JavaScript，桌面和 Android 的内置游戏包共享同一套规则与资源，离线可玩，不依赖外部网络。

## 规则与交互

- 8×8 棋盘，每组 3 个方块；三块用完再刷新，不能旋转或重叠，满行/列同时消除。
- 27 种形状包含斜线三格。生成器参考棋盘可放位置；只要有形状能放下，新手牌至少包含一个可放置形状，不保证每组必然能全部放完。
- 每放一格 +1 分；单行/列 +10、双行列 +20、三条 +60，之后每条额外 +40；连续消除按 1 + 0.5×(连击数−1) 倍计消除基础分；全清额外 +300。
- 连续 1–2 次不消除仍保留连击，连续 3 次不消除重置。无任何剩余方块可放时结算。
- 触摸/鼠标拖放，或选中方块后点击棋盘；键盘 1–3 选块、方向键、Enter 放置。预览显示落点以及将被清除的行列。
- 粉色立体块、紫色结算、消除粒子、Web Audio 合成音效、可关闭声音、支持时遵循设备震动能力与系统减少动画设置。
- 自动保存当前棋局、最高纪录与声音开关。优先使用本地存储，支持宿主协议 2 `xb.storage`；只保存数值和形状 ID，无外部调用。

## 打包约定

基准资源：`assets/game-packs/block-puzzle/`；桌面随包资源：`client/xiaoban-desktop/public/game-packs/block-puzzle/`。除 README、桌面私有 `theme.css` 与入口页去掉共享 CSS/脚本及分享按钮外，其余文件须逐字一致；`candy.css` 在共享主题之后加载，保证主题覆写一致。

规则单元检查：`node tools/check-block-puzzle.mjs`。内置资源只读校验：`node client/xiaoban-desktop/scripts/check-game-assets.mjs`。Android 构建会按项目已有规则从桌面随包资源同步官方游戏，不需另开菜单 ID。

## 手机全屏与游戏图标

Android 对方块爆破单独隐藏状态栏，保留原生宿主胶囊退出与系统手势导航。顶部按 `--xb-builtin-top` 避让胶囊，底部按手势安全区自适应，棋盘始终为 8×8 正方形。触屏不出现通用绿色焦点框。独立 `icon.webp` 是 256×256 方形糖果方块图标，移动端精选游戏卡片直接使用该图标；横幅 `cover.svg` 继续用于横版场景。
