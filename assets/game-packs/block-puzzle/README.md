# 方块爆破（小伴内置游戏）

游戏 ID：`block-puzzle`（保留旧「消失高手」ID，避免入口与历史记录失效）。版本 2.1.2。纯 HTML/CSS/JavaScript，桌面和 Android 的内置游戏包共享同一套规则与资源，离线可玩，不依赖外部网络。

## 规则与交互

- 8×8 棋盘，每组 3 个方块；三块用完再刷新，不能旋转或重叠，满行/列同时消除。
- 27 种形状包含斜线三格。发牌使用最多三步的顺序与落点搜索，优先选可完成消除且有生存空间的三块组合；控制组数与搜索宽度，防止在手机上明显卡顿。
- 每放一格 +1 分；单行/列 +10、双行列 +20、三条 +60，之后每条额外 +40；连续消除按 1 + 0.5×(连击数−1) 倍计消除基础分；全清额外 +300。
- 连续 1–2 次不消除仍保留连击，连续 3 次不消除重置。无任何剩余方块可放时结算。
- 触摸/鼠标拖放，或选中方块后点击棋盘；键盘 1–3 选块、方向键、Enter 放置。预览显示落点以及将被清除的行列。
- 粉色立体块、紫色结算、消除粒子、Web Audio 合成音效、可关闭声音、支持时遵循设备震动能力与系统减少动画设置。
- 默认进入空棋盘，只恢复最高纪录、声音与已解锁主题；未结束的上局保存在单独归档，设置菜单可选「继续上局」。优先使用本地存储，支持宿主协议 2 `xb.storage`；只保存数值和形状 ID，无外部调用。

## 打包约定

四句童声风格的报彩使用 [Kokoro-82M v1.0](https://huggingface.co/hexgrad/Kokoro-82M) 的 af_sky 音色离线生成，分别是 Nice、Good、Great 和 Wonderful。游戏包内置单声道 MP3。

基准资源：`assets/game-packs/block-puzzle/`；桌面随包资源：`client/xiaoban-desktop/public/game-packs/block-puzzle/`。除 README、桌面私有 `theme.css` 与入口页去掉共享 CSS/脚本及分享按钮外，其余文件须逐字一致；`candy.css` 在共享主题之后加载，保证主题覆写一致。

规则单元检查：`node tools/check-block-puzzle.mjs`。内置资源只读校验：`node client/xiaoban-desktop/scripts/check-game-assets.mjs`。Android 构建会按项目已有规则从桌面随包资源同步官方游戏，不需另开菜单 ID。

## 手机全屏与游戏图标

Android 对方块爆破使用透明系统状态栏，将游戏及紫色结算背景延伸到状态栏后方，保留系统时间、电量与原生宿主胶囊、手势导航。宿主接收 `game.result` / `game.start` 后切换状态栏图标明暗，仅对官方 `block-puzzle` 生效。顶部按 `--xb-builtin-top` 避让状态栏及胶囊，右侧菜单距屏幕安全边缘至少 16dp，底部按手势安全区自适应，棋盘始终为 8×8 正方形。触屏不出现通用绿色焦点框。独立 `icon.webp` 是 256×256 方形糖果方块图标，移动端精选游戏卡片直接使用该图标；横幅 `cover.svg` 继续用于横版场景。

## 2.1.0：激励、难度和特效

- 入门阶段前 24 组维持友好发牌，之后连续插值缓慢过渡至第 320 组，选择概率只是引导参数，并非声明的玩家真实通关率。
- 低空位棋盘、连续消除和消除中断前的状态有小幅恢复加成；不强迫每次消除，不保证玩家任意放置都存活。
- 行列清除按方向扫光，交叉消除同时叠加水平和垂直光束；多行、多列及 Combo ×3、×5、×8 触发升级的文字、碎片、冲击波与多音音阶，普通落子保持轻量。
- 仅当棋盘完全清空时触发 PERFECT：额外奖励 300 分、撒落粒子，并循环切换粉红、琥珀、薄荷、紫罗兰、天空蓝五套棋盘与方块主题。五套主题分别定义六种方块颜色及离场动作；主题还会独立保存在 `xiaoban.block-puzzle.theme.v1` 中，结束、重开、旧存档失效后依然继承。
- 消除后得分按缓动滚动、连击允许两步无消除缓冲；按被消除格子原来的颜色生成飞出砖块，蓝色主题偏向浮起翻转，其他主题有旋转、爆散或漂浮的退场方式；大额消除或布局奖励额外显示菱形计分反馈。
- 不消除也可能获得独立的布局奖励：每把某行/列推进至只缺一格奖励 8 分（单次最多 16 分）；每连续三次有效放置但没有消除奖励 5 分。这些奖励不计入 Combo 或消除行列数，也不延长连击宽限。游戏结束有短暂延迟以便看到最后一次爆破，系统要求减少动态效果时禁用大部分动画。
- 定向测试 `node tools/check-block-puzzle.mjs`、`node tools/check-block-puzzle-feedback.mjs`；Android 和桌面真机的动画耗时与声音仍需实际验收。

## 2.1.1：默认新局

启动永远显示空白 8×8 棋盘，避免上次的残局被误认为预设关卡。已有未结束棋局先归档到 `xiaoban.block-puzzle.resume.v1`，用户可从游戏设置主动选择「继续上局」；自动更新后旧 v2 存档可读，不立即覆盖。最高分、音效和主题独立恢复；结束的棋局不会自动恢复成遮挡屏幕的结算弹窗。宿主存储异步恢复后也不会悄悄替换玩家正在操作的棋盘。

## 2.1.2：顶部沉浸式安全区修复

Android 不再绘制挡在 WebView 前面的粉色状态栏底色，状态栏在普通棋盘上显示深色系统图标，在紫色结算页上显示浅色图标。结算层与设置层统一避让宿主提供的实时安全区；只影响内置 `block-puzzle`，其他作品保持原状。专项防回归检查：`node tools/check-block-puzzle-insets.mjs`。
