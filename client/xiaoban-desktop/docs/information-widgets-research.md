# 新闻与 A 股桌面组件调研

调研日期：2026-10-12。本次只调研资讯组件，未上线数据接入，也未购买 API。

## 建议先做什么

优先做「A 股行情」和「新闻简报」两类组件。行情组件提供「三大指数」「自选股」两种视图；避免把桌面做成交易终端。

| 组件 | 首版展示与交互 | 建议更新策略 |
| --- | --- | --- |
| 三大指数 | 上证指数、深证成指、创业板指；点位、涨跌额、涨跌幅、行情时间 | 盘中每 30–60 秒刷新，最终频率服从供应商套餐 |
| 自选股 | 搜索名称/代码；增删、排序；展示 3–6 行，更多内容滚动 | 与指数共用请求缓存，按证券代码去重 |
| 新闻简报 | 展示 3–5 条标题、来源、发布时间；科技/财经/综合；点击打开原文 | 每 10–15 分钟更新；不自动滚动，不弹通知 |

三大指数代码：`000001.SH`（上证指数）、`399001.SZ`（深证成指）、`399006.SZ`（创业板指）。个股和指数必须分别记录证券类型与市场，不能只用六位数字识别；例如上证指数和股票平安银行都含 `000001`。

## 数据源比较

| 数据源 | 已核实能力 | 接入判断 |
| --- | --- | --- |
| 36 氪官方 RSS | 官方订阅中心公布综合、文章和快讯 RSS，面向 RSS 阅读器 | 新闻首版候选；保留来源和原文链接。可访问 RSS 不等同于获得全内容商业转载权 |
| 聚合数据新闻头条 / 财经新闻 | 提供分类新闻与财经新闻 API，需要申请接口 | 需要更广的综合新闻覆盖时评估；先核实套餐、调用次数、内容展示许可 |
| Tushare `rt_k` | A 股实时日线，包含最新价、昨收和行情时间；单独开通 A 股日线 RT 权限 | 自选股候选；可由最新价和昨收计算涨跌额、涨跌幅 |
| Tushare `rt_idx_k` | 交易所指数实时日线，支持单个/多个指数代码，返回行情时间；单独开权限 | 三大指数候选；指数和股票接口分别核实权限与频率 |
| AKShare | 文档包含从东方财富取得沪深京 A 股实时行情的 Python 接口 | 可用于开发验证。它是数据访问库，不能据此承诺上游稳定性或商业展示授权；不默认塞进桌面安装包 |

没有已验证的账号、Token 或供应商套餐，因此不能确定实际延迟、可用频率、商业分发权限或报价。文档中的「实时」不是端到端延迟承诺；本次没有做付费账号的 live 行情测试。

此前看过的聚合数据「股票查询」接口，其具体接口描述写的是美股、港股，不能据页面的泛化功能介绍就选为 A 股数据源。

## 实现建议

- 数据接入使用独立 provider，统一输出 `symbol / exchange / instrumentType / name / price / previousClose / quoteTime / receivedAt / source / status`；不要让 Vue 组件依赖供应商原始字段。
- 默认中国市场红涨绿跌，同时提供配色选项和正负号；昨收为零或数据缺失时显示 `—`，不伪造涨跌幅。
- 按 `Asia/Shanghai` 判断交易时段。A 股交易日与法定工作日不同：周末调休上班不代表开市，需使用交易所交易日历；午休、节假日、盘后停止高频轮询。
- 区分行情时间和客户端收到数据的时间，显示「休市」「延迟」「更新失败」状态。失败时保留最后一次成功数据并标记陈旧，不显示假数据。
- 指数及相同自选代码合并请求，隐藏组件/锁屏时暂停刷新，网络错误指数退避。新闻按 URL/GUID 去重，限制响应体和缓存条数。
- 若用开发者共享 API Token，放在服务端，由服务器缓存并向客户端提供统一接口；若采用用户自带 Token，使用原生安全存储，不进入 Vue localStorage 或公开资源包。本次不扩展后端。
- 新闻只渲染纯文本标题与来源，不直接执行 RSS HTML；链接仅允许 HTTP/HTTPS，由原生受控命令打开。

## 后续接入前需要明确

1. 行情采用开发者统一供应，还是用户自带 Token？小规模试用可先用自带 Token，普遍用户使用则更适合统一供应。
2. 向供应商核实股票、指数权限、调用频率、更新时间、面向终端用户展示的授权及费用。
3. 用三个指数和不同市场的个股验证价格、昨收、时间戳、停牌状态，再实现分时走势；首版无需 K 线和交易操作。
