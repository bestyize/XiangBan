## 产品方向

**把今天，倒成喜欢的颜色。** 将抽象倒水题变成一间口袋饮品店：分杯解谜是核心，风味收藏承担成长，快乐小票承接分享。

暂定名「倒杯快乐」同时表达操作和情绪；「这杯快乐，我调的」是分享文案。英文 POUR JOY 仅作为视觉标识。设计避免宣称真实疗效、用户排名或未经验证的传播效果。

## 玩法演进提案

1. **核心局**：同色相接、空杯中转，容量四层。保留无倒计时与自由撤销。目标步数作为可选挑战，不阻止主线通关。
2. **前 12 关**：分组教学，依次熟悉选杯、连续层倒入、借空杯与提前规划；每组最后一关解锁一枚招牌贴纸。正式关卡数量与数值待制作，此稿使用现有规则中的 3 道固定题。
3. **中期章回**：每章一种新机制，例如完成指定口味后解封的封签杯，或要求装出指定杯型的订单关。先保持信息透明，不用纯随机局面制造死局。
4. **日常回访**：同日同题的「今日特调」，可选少步挑战。正式实现需要版本化种子、可解性校验与进度持久化。本稿只有固定同题 URL，没有真实每日系统。
5. **传播闭环**：完成一杯 → 小票体现饮品与本人步数 → 保存图片或复制同题链接 → 接收者打开相同题。小票中的“100% 好心情”是情绪文案，不是用户统计；不使用虚构击败比例、排行榜或伪二维码。

删去页面两侧讲解、重复标语与常驻说明；只保留关卡、步数、完成进度、必要提示和操作。设计说明收进页脚入口。液体改用高饱和草莓粉、青柠绿、芒果黄、葡萄紫，增大玻璃杯、强化杯口高光和弧面反射，并加入台面承托、立体彩色工具键与橙色主按钮。小店、手帐、小票同步精简文案与提色；新增 `arcade.css` 承载该视觉版本。

## 视觉与动效

- V2 品牌：暖奶油 `#fff2dc`、珊瑚橙 `#ef563d`；液体为草莓粉 `#ff527a`、青柠绿 `#73ca38`、芒果黄 `#ffbe22`、葡萄紫 `#a66bf0`。
- 玻璃杯、贴纸饮品、店面、图标均由本地 CSS / SVG 绘制，便于缩放与后续维护，未复制竞品美术。
- 选杯抬起并倾斜；可倒目标绿色描边；倒入约 680 ms，期间锁定操作；完整单色杯盖章。减弱动态偏好下跳过动效。
- 每层提供「莓 / 茶 / 芒 / 芋」标识和可访问名称，不单靠颜色判断。支持原生键盘按钮、数字 1–6 选杯、Esc 取消、Ctrl/Cmd+Z 撤销。
- 音效默认关闭，经点击才创建 Web Audio；没有远程音频、图片或字体依赖。
- Android 顶部胶囊为示意，真正接入时用宿主能力与实际安全区域；不新增游戏退出按钮。游戏内页面切换使用浏览器历史。
- 手机与桌面均以调饮画面为主体；设计评审说明收进页脚，桌面外侧仅作背景留白。

## 实现边界与验证

样稿只在内存保存当前关卡、撤销栈与已获得贴纸；刷新重置。灵感对当前局面进行有界搜索，找不到解法时提示撤销，不自动伪造操作。试题来自原游戏的固定关卡。

已完成 JavaScript 语法检查；三题均重放求解路径通过（7 / 9 / 12 步），并核对非法倒入、容量限制和原始棋盘不被修改。浏览器核对了倒入、撤销、灵感、12 步通关、真实小票与 PNG 下载。手机 390px 布局与桌面设计页已目视检查。

没有接入真实账号存档、宿主协议、每日关卡服务或社交排名；上述限制仅指此目录的设计原型；正式游戏资源现已另行实现，在线 Sites 链接仍是设计稿，不是安装包。
