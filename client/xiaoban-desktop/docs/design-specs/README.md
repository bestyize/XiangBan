## 维护约定

- 改动对应交互时，同时更新本目录的专项规范和 HTML；保持文件名稳定，便于代码与讨论引用。
- 模块专项规范与对应设计稿优先定义该模块的形态；全局文档中的历史视觉参考不覆盖已确认的专项交互。
- 设计演示与正式实现存在差异时，在专项规范中写清，例如演示数据、系统权限、尺寸缩放和平台支持。
- 验证状态写明范围；浏览器原型通过不代表 Windows/macOS 原生截图已经验收。

额度获取入口：设计稿以可选 `creditPurchaseUrl` 属性表示由服务端配置的额度购买链接。正式实现由 server-ai 后台产品配置的 `credit_purchase_url` 下发，客户端点击后通过系统浏览器打开，可接在线支付页面；未配置时按钮禁用并提示“暂未开放”。预览使用 `https://example.com/credits` 作为占位，点击只显示演示反馈，不打开外部页面、不发起支付；已实现服务端配置与客户端打开链接；支付页面由后续配置的外部服务提供，未部署服务端改动。

模型检测：每个模型行右侧提供“检测”，对该行模型发送单条用户消息 `hi`，无需先切换当前模型，也不写入正式聊天记录。显示检测中、成功与失败状态，结果保留在对应模型行，悬停查看测试消息、回复、耗时或错误；失败后可重试。预览页的“检测演示”控制成功 / 失败场景，所有结果均为模拟，本次没有调用真实模型。正式检测已接入网关 Responses 请求：只发送单条 `hi`、无工具、无聊天记录，实际收到有效文本才判为成功；45 秒模型请求总超时，同一时间只允许一个检测。回复摘要最多保留 512 字符，检测可能消耗少量额度。

毛玻璃材质：提案以统一的白色内容面为主，取消额度区和底栏的大面积灰底，仅在窄标题栏及交互状态保留轻灰，靠留白组织金额、明细、兑换条和模型列表，减弱背景透色，系统蓝仅用于选中标记和主要操作，辅以分层半透明表面，通过 `backdrop-filter` 展示背景模糊与柔和高光；保留无边框按钮和输入框，兑换码输入框采用更高不透明度的白色表面以便辨识，支持深色。背景色带仅用于观察材质透光，不属于产品窗口内容。浏览器只能模糊页面中的背景；桌面独立窗口已接入 macOS UnderWindowBackground 原生材质；Windows 使用 Mica（可用性由系统决定），内容保留高不透明度底色。主题和强调色仍跟随全局设置，原型演示使用蓝色。Windows 原生效果尚未实机验收。

新版布局（设计评审）：额度数字与明细左右对齐，兑换入口合为细条；检测为每行右侧的无边框文字操作，主按钮为单一系统蓝。模型区和底部操作使用同一内容背景，仅底部保留内缩细线。预览数量、宽度和检测结果演示收纳到窗口外的“预览选项”，不属于产品界面。已确认的单页布局、无搜索框、无边框按钮 / 输入框及可配置额度链接均保留。

配置窗口统一风格与窗口操作见 [配置窗口风格](configuration-surfaces.md)。同一[本机在线预览](http://127.0.0.1:1420/docs/design-specs/prototypes/ai-model-settings.html)已加入第三方模型配置与完整设置页，分栏窗的窗口控件位于左栏顶部，预览操作均为本地模拟。

设置页重设计（2026-10-31）：三组单色导航、底部账号、白色内容面与浅灰设置组，窗口控件固定在左栏顶部；深色模式增强正文、辅助文字和控件对比度。沿用[原在线预览](http://127.0.0.1:1420/docs/design-specs/prototypes/ai-model-settings.html)，默认展示新版设置，支持所有分类与明暗切换；前端代码已更新，本轮未重新打包原生应用。

设置侧栏细化：浅色背景跟随主页面的 `--ui-tint` 次要主题色；一级菜单使用无底色线性图标。账号区仅展示状态，不跳转、不响应点击；无头像时显示主题色 Sparkles 图标，替代猫脸占位图。沿用[原在线预览](http://127.0.0.1:1420/docs/design-specs/prototypes/ai-model-settings.html)。

模型配置 UI 升级：协议菜单保持单行，模型展开设置采用平整布局，蓝色选中态仅作用于标题行；第三方配置采用主题色连接侧栏、25px 标题、浅灰模型列表与主题色默认行；小伴 AI 统一标题、额度明细、兑换条和模型选择样式，保持同页布局及逐模型检测。沿用[原在线预览](http://127.0.0.1:1420/docs/design-specs/prototypes/ai-model-settings.html)，切换「小伴 AI · 新版 / 第三方模型 · 新版」查看，初版提案另保留为参考；代码已更新，尚未重新打包。

模型页精修：统一紧凑标题、添加入口和展开设置对齐，移除“思考摘要”控件；沿用[原在线预览](http://127.0.0.1:1420/docs/design-specs/prototypes/ai-model-settings.html)中的「第三方模型 · 新版」。

参考风格调整与小伴 AI 结构重排（2026-10-31）：配置页统一为轻主题色画布与白色分组卡片，设置页收小分类标题并移除侧栏重复标题。小伴 AI 将账户身份放在页头，余额、额度明细、兑换与获取额度合并为一张卡片，模型另设独立滚动列表，确认操作固定在底部。保留无描边控件、单页布局、模型检测与键盘选择；深色使用独立高对比表面。沿用[原在线预览](http://127.0.0.1:1420/docs/design-specs/prototypes/ai-model-settings.html)，默认查看「小伴 AI · 新版」。本轮更新了实际组件代码，通过类型检查及 63 项相关测试，核对了 360px 窄窗口、明暗与长列表；尚未重新打包原生应用。

小伴 AI 配置窗口默认宽度与最小宽度调整为 360px，高度仍为 620px；窗口尺寸单独记忆，避免继承第三方配置页的宽度。[原在线预览](http://127.0.0.1:1420/docs/design-specs/prototypes/ai-model-settings.html)同步默认显示 360px，仍可手动调整尺寸。
