改了什么
  • 问题是重心：问题 14.5px 加粗；顶部只有一个「小伴想问你」小标签和右上角的「跳过 Esc」。
  • 选项改成整行列表：灰底圆角行，序号徽标 1–9，悬停或方向键选中时变成主题色浅底并出现回车提示。选项再长也不会把按钮挤成不齐的一排。
  • 键盘优先：按 1–9 直接选，↑↓ 移动，回车确认，Esc 跳过；输入框聚焦时数字键照常打字，不触发选择。
  • 自己回答并进列表末尾：一行输入框，右侧圆形发送钮，有内容才亮。原来的「回答」按钮和独立一行去掉。
  • 去掉「切换模型」：它在这张卡里几乎用不上（回答前运行中是禁用的），模型切换在输入框右下角已有入口。
  • 回答后留痕（新增）：卡片收成一行「问题 → 你的选择」或「已跳过」，回看对话时知道当时怎么决定的；现在只剩一行「向你提问」工具记录。
  • 配色：全部走主题色令牌，6 套主题（红/绿/蓝/紫/琥珀/石墨）下自动跟随，可在右侧属性里切换预览。
