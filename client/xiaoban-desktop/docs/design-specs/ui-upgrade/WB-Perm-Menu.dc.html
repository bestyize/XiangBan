改了什么
  • 去掉两段说明文字：每个选项只剩图标 + 名称（32px 一行）；说明放进悬停提示，键盘聚焦同样显示，也作为无障碍描述。
  • 去掉图标底块：原来每个选项前有 28px 的图标方块，改成 14px 线性图标。
  • 勾选标记靠右，当前项底色浅一档；「完全信任」保持红色，一眼能认出是高风险模式。
  • 设置入口缩成一行：「权限与沙箱设置…」28px，字号 12px。
  • 触发按钮不变：位置、大小、红色警示都沿用，只是菜单变小。
  • 配色：走主题色令牌，6 套主题自动跟随；红色只用于「完全信任」。
