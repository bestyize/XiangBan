# 小伴桌面应用皮肤系统（设计提案）

状态：第一版已开始实现；下文包含长期设计，实际支持范围见「第一版实际格式」。范围为小伴桌面自身的外观；与桌面壁纸、桌宠、桌面特效和小组件分开。此文定义第一版建议，数值上限与格式字段需在实现前以样例包和实机测试确认，不是现有协议。

## 目标与体验

用户在「装扮 → 皮肤」浏览、预览、应用、导入、导出和删除皮肤。预览应同时展示新建任务、聊天和侧栏，可切换明暗、窄窗口与动效状态；预览不会修改当前皮肤，点击「应用」后才生效。默认外观始终可用，删除当前皮肤前提示会切回默认。导入只安装不自动应用；失败保留当前皮肤并提示原因。相同 ID 和版本但内容不同时不得静默覆盖，提供取消或另存为副本；更新流程另行设计。

「设置 → 外观」保留系统 / 浅色 / 深色、主题色、减少动画及关闭场景互动等全局偏好，并显示当前皮肤及「管理皮肤」入口。皮肤应用后默认使用它的配色；选择独立主题色时只覆盖强调色，不替换背景图。切回默认皮肤时恢复应用皮肤前的主题色。用户的浅深色选择始终优先：皮肤只提供一种模式时，在另一模式使用内置安全配色与静态降级，不能把浅色文字直接套到深色场景。系统减少动态效果时关闭自动运动，保留非运动的状态反馈；用户关闭互动时不注册互动热区。

一期场景在整个主窗口持续显示，聊天和审批保留各自的内容面；互动仅在新建任务页启用，切换页面时暂停场景动画。设置及其他原生独立窗口只同步可用的浅深色和强调色，不显示主场景；悬浮球、桌面伙伴和桌面壁纸不随应用皮肤更换。窗口外框、导航、输入框、提示、审批和权限语义保持原有实现。场景无法加载时自动回退内置外观并提供重新选择入口。

## 第一版实际格式

Agent 已接入 `skin_list`、`skin_read_format`、`skin_create`、`skin_apply`、`skin_export`。运行时格式与完整 JSON 示例由 `skin_read_format` 随程序提供，以下长期设计不是创作依据。简单背景场景可传 `id/name/background_image`，素材来源为 `generated:<生图编号>` 或工作区相对栅格图片路径；工具自动缩放、转为真实 WebP，并生成配置和预览。多图层作品在工作区子目录准备完整包内容后传 `source_dir`，不能与图片创建参数混用。原生用同一导入解析器检查并安装，工作区保存 `skin-<id>.zip` 供交付；不同内容不覆盖，重复执行相同内容复用结果。创建不会改变当前皮肤，明确要求应用时才切换；不必让用户提供样例包。

装扮页目前支持本地安装与删除、应用与恢复默认、导出已导入的包；内置「春江花月夜」「江南烟雨」「海边列车」，其中「春江花月夜」可点击花灯。侧栏与各页面共用场景，新建任务页右侧不叠加白色蒙层，其他页面保留淡色内容底层；场景互动仅在新建任务页启用。皮肤配色、独立窗口场景、动画偏好设置和创作编辑器暂未实现。静态概念稿与真实应用的可见性和帧率仍需桌面实机验收。

ZIP 根目录必须包含 `manifest.json`、`scene.json`、`theme.json` 和 `preview.webp`，加 `assets/` 内实际使用的图片；上面的 manifest 示例可用，`theme.json` 目前必须是 JSON 对象，可写 `{}`，其配色暂不生效。仅接受 PNG、JPEG、WebP 静态图，动图导入后只使用首帧。`scene.json` 的 `layers` 必须包含 1–20 项，每项有小写字母 / 数字 / 连字符组成的 `id`，`assets/` 内的 `image`，0–10 的整数 `depth`，以及 `center`、`top-left`、`top-right`、`bottom-left`、`bottom-right` 之一的 `anchor`。设置 `interactive: true` 并声明 click 互动后，图层作为固定尺寸的交互物件显示；普通图层覆盖整个场景，按锚点裁切。非交互图层可声明 idle 动作。

`interactions` 最多 20 项，目标必须是已有图层；`trigger` 支持 `idle`、`hover`、`click`，`action` 支持 `sway`、`glow`，`label` 为无障碍名称。click 需要目标图层设置 `interactive: true`；触发效果只作用于场景，不操作应用数据。正式支持情况以当前渲染器为准：暂没有逐帧、换图、粒子、自由坐标和场景编辑器。导入包及解压合计均不超过 32 MiB、单文件不超过 4 MiB、最多 60 个 ZIP 条目，图片最大 4096×4096，已转换图层数据总量不超过 16 MiB；不接受外链、可执行脚本、未声明文件及同 ID 覆盖。最多安装 20 套。所有限制由原生端校验，素材仅作为图片显示。

## 空间、层次和交互

主窗口的场景使用同一个覆盖侧栏和内容区的坐标空间：远景、侧栏 / 主内容装饰、中景、前景粒子依次叠放，侧栏及内容在其上各有可读性底层。画面跨过边界，但侧栏和内容仍是独立的真实 UI。图片按各自锚点和适配规则定位，不以整张截图代替界面；窗口缩放及侧栏收起时共享同一坐标变换，允许边缘裁切，不允许拉伸变形。主输入区、侧栏导航及底部账号为保留区域；图层可在其背后，粒子不得遮住操作和文字。

默认装饰层不拦截指针。交互物件使用显式热区并位于内容控件之后，控件永远优先；热区不能穿过标题栏控件、导航、输入框或其他可操作 UI。互动目标需可见焦点、名称和键盘操作；没有足够空间容纳时隐藏该物件和热区。静态预览或暂停时保持可读，不自动发声；一期不支持音频。输入中、窗口失焦、不可见或最小化时暂停非必要动画；系统减少动态效果时使用静止画面。加载失败时局部降级，不影响输入或审批。

一期内置动作建议：`sway`（轻摆）、`glow`（明暗变化）、`swap`（替换预备图片）、`frame_sequence`（有限帧动画）、`particles`（有界粒子）。触发器为 `idle`、`hover`、`click`，焦点和 Enter / Space 等价于 hover / click。状态变化仅限本场景，不触发导航、文件、网络或应用命令。动画停止与资源释放应覆盖切换皮肤、离开页面和关闭窗口；同一互动的重复触发采用重置或忽略策略，由配置明确。

## 资源包与兼容性

建议沿用现有小伴资源包的 ZIP 和 `manifest.json` 入口，新增独立 kind `application-skin`；不可把已有特效 / 壁纸格式当成可执行皮肤。以下为格式草案，不是可直接导入的现有资源包：

```text
skin.zip
├── manifest.json
├── theme.json
├── scene.json
├── preview.webp
└── assets/
    ├── landscape.webp
    ├── sidebar.webp
    └── lantern.webp
```

```json
{
  "schemaVersion": 1,
  "kind": "application-skin",
  "id": "spring-river",
  "name": "春江花月夜",
  "version": "1.0.0",
  "author": "示例作者",
  "minAppVersion": "3.0.0",
  "preview": "preview.webp",
  "theme": "theme.json",
  "scene": "scene.json"
}
```

`minAppVersion` 仅为示例，正式值应由实际首个兼容版本决定。主题文件提供完整的浅色 / 深色语义色令牌，不允许覆盖危险状态含义；场景文件列出图片、分层、规范化锚点、适配规则、有限动效及热区。每个引用必须指向包内已声明素材。示意：

```json
{
  "canvas": { "width": 1440, "height": 900, "fit": "cover" },
  "layers": [
    { "id": "river", "image": "assets/landscape.webp", "depth": 0, "anchor": "center" },
    { "id": "bank", "image": "assets/sidebar.webp", "depth": 1, "anchor": "bottom-left" },
    { "id": "lantern", "image": "assets/lantern.webp", "depth": 2, "anchor": "bottom-right", "interactive": true }
  ],
  "interactions": [
    { "target": "lantern", "trigger": "click", "action": "glow", "label": "点亮花灯", "repeat": "restart" }
  ]
}
```

这是结构示意，不代表字段已冻结。正式规范须定义坐标、缩放裁切、绘制顺序、热区尺寸、重叠处理、主题令牌清单、默认值、错误与未知字段处理；不支持的 schema 或必需能力须明确拒绝，不能悄悄改变行为。分离静态预览图与运行时素材；作者需有权使用导入的素材。

一期只接受声明式 JSON 与经过解码验证的 PNG / JPEG / WebP，禁止 HTML、CSS、JS、SVG 脚本、外链、字体与音视频。原生端校验 ZIP 条目路径、重复项、符号链接、实际内容、解压后大小、图片尺寸 / 像素以及引用关系，拒绝路径穿越、压缩炸弹和未声明文件；不要信任扩展名或 manifest 的尺寸。建议初始预算为压缩包及解压后各不超过 32 MiB、最多 60 个文件、单张图片不超过 8 MiB / 4096×4096，并另设像素总量、图层和粒子上限；这些是待实测的提议，不是现有能力。现有资源包解析器单文件上限为 4 MiB；如采用 8 MiB，需按皮肤 kind 单独调整并测试，不能误称现已支持。先解压到临时目录、全部校验后原子安装；失败或取消清理临时文件，不影响已安装版本。预览和正式显示使用相同的受限解析器，不加载皮肤提供的可执行内容。导出只打包该皮肤及其素材，不包含聊天、账户或其他用户数据。

## 与现有工程的边界

- `src/ui/appearance.ts` 负责系统 / 明暗模式、六套主题色及同步：在其语义令牌之上增加皮肤配色解析，不破坏既有设置与回退。
- 主窗口 `src/ui/ControlShell.vue` 与 `src/ui/pages/NewTaskPage.vue` 承载共享场景和新建任务页内容；具体定位以实现前核对 DOM / 窗口层级为准，避免把背景放进仅覆盖右侧的容器。
- `src/ui/components/settings/AppearanceSettings.vue` 提供当前皮肤和全局偏好；装扮页增加「应用皮肤」分类，浏览和导入流程复用现有交互习惯。
- `src-tauri/src/resource_packs.rs` 已处理资源包，扩展 kind 前先核对现有限额与格式；皮肤素材解析和运行边界独立校验，不能直接复用可执行 HTML 特效的能力。
- 主题状态需经原生持久化并跨窗口同步；同步消息携带皮肤标识 / 配色偏好，不携带任意路径或脚本。资源解析需限定安装目录；渲染端只取得经过校验的素材。

## 分期与验收

1. **验证原型**：以一套跨侧栏和新建任务页的示例皮肤验证布局、明暗、缩放与清晰度；无导入、无自定义脚本。
2. **基础皮肤包**：装扮页预览 / 应用 / 导入 / 导出 / 删除、主题同步和安全校验；静态资源完整后启用少量有界动画及互动。
3. **创作工具**：提供图层定位、素材替换、预览及打包；素材作者可以仅编辑 JSON 使用同一格式。市场分发、复杂逻辑与自定义脚本均不在一期。

验收覆盖：明暗 / 跟随系统，主题色覆盖及恢复；侧栏展开 / 收起、窄窗口与缩放；聊天与审批操作可见且可点击；键盘与减少动态效果；失焦 / 最小化 / 切换的暂停和恢复；缺失或损坏素材的回退；恶意 ZIP / 超限 / 未知版本拒绝；导入取消、重复、删除与重启后的持久化；多窗口同步；Windows 与 macOS 原生实机检查。性能预算（帧率、内存及静止功耗）通过目标低配机器基线测量确定，不能将设计稿或浏览器预览视为实机验收。
