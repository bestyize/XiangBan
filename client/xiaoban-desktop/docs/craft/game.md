## 游戏创作手册（质量要求）

上面的规范决定游戏能不能运行，下面这些决定它好不好玩、好不好看。目标是一款打开就想多玩几局的小游戏，而不是能跑起来的技术演示。

### 1. 完整的流程

每款游戏都要有这四个状态，并且能在其中顺畅切换：
- **开始屏**：游戏名、一句话玩法、操作提示（键盘和鼠标/触摸各一行）、明显的开始按钮；按空格或回车也能开始。
- **游戏中**：HUD 只放必要信息（分数、最佳、关卡或生命），放在不挡视线的角落，字号清楚。
- **暂停**：按 P 或点暂停按钮暂停（Esc 留给宿主）；窗口失焦或 `visibilitychange` 时自动暂停。
- **结束屏**：本局分数、最佳纪录（刷新纪录时要有庆祝）、“再来一局”按钮，按 R 或回车直接重开。重开不刷新页面，所有状态从一个 `reset()` 里恢复。

不要用 `alert()`、`confirm()` 提示，全部画在游戏界面里。

### 2. 手感：反馈要及时、夸张一点

手感决定一半的乐趣：
- 输入当帧响应。移动可以加很短的加速和减速，但不要有可感知的延迟。
- 每个有意义的事件都给反馈，至少叠两种：
  - 命中、得分：物体缩放弹跳（1 → 1.2 → 1，配 easeOutBack）、闪白一帧、溅出 6–12 个粒子、分数飘字上浮淡出。
  - 受伤、失败：短暂屏幕震动（2–6px，150ms 内衰减）、红色闪烁、慢动作 200ms。
  - 连击、升级：数字放大、颜色变化、音调随连击升高。
- 所有位置和尺寸变化都用缓动（easeOutCubic、easeOutBack），不要线性瞬移。
- 音效用 WebAudio 振荡器现场合成（短促的方波、三角波，加音量包络），在玩家第一次点击或按键后再创建 AudioContext；界面上提供静音开关，音量适中。

### 3. 循环与清晰度

- 用 `requestAnimationFrame` 驱动，所有运动乘以时间步长 dt（秒），并把 dt 限制在 1/30 以内，防止卡顿后物体穿墙。速度不能和帧率挂钩。
- 逻辑更新和绘制分开写；物理、碰撞需要稳定时用固定步长累加。
- canvas 按 `devicePixelRatio` 放大绘制，保证高分屏不糊；监听 resize，重新计算布局。
- 玩法区域保持固定比例，多出来的空间用背景补齐，不要拉伸变形。

### 4. 视觉

- 选定一种美术风格贯穿全部元素：扁平几何、像素、水墨、霓虹、纸艺、手绘等。cover.svg 也用同一风格。
- 调色板 4–6 色：背景低饱和、偏暗或偏淡；玩家和可交互物高对比、最醒目；危险物用一致的警示色。玩家要一眼分清“我、目标、危险”。
- 画出层次：背景（渐变或缓慢视差）→ 场景物 → 角色 → 特效 → HUD。背景可以有细微的动态（漂浮颗粒、缓慢云层），但不能抢戏。
- 形状要有质感：圆角、渐变、柔和阴影、高光描边，不要只是纯色方块配默认字体。`shadowBlur` 很耗性能，只在少量元素上用。
- 文字用与风格匹配的字体栈；HUD 里会变化的数字用等宽字体或按固定宽度右对齐绘制，避免跳动。

### 5. 难度与公平

- 前 20–30 秒宽松，让新玩家先体会到成功；之后逐步加速或加密，并设上限，不要无限加速到无法操作。
- 随机生成要保证有解：不生成必死布局，出生点附近留安全区，新障碍出现前有预告。
- 失败要让玩家觉得“是我失误”：碰撞判定可以比画面小一点，宽容一点。
- 加一个让人想再来一局的理由：最佳纪录、连击、星级评价、解锁新皮肤或新模式（需要存档时按规范使用 game.save）。

### 6. 操作

- 键盘：方向键和 WASD 都支持，空格作为主操作。
- 鼠标和触摸要有等价方案（点击、拖动、滑动），并且在开始屏里写明。
- 按钮和可点区域足够大，有 hover 和按下状态。

### 7. 代码组织

按职责拆分文件，例如 `game.js`（状态和规则）、`render.js`（绘制）、`input.js`（输入）、`audio.js`（音效）、`fx.js`（粒子和缓动），用一个全局命名空间对象连接，避免满地的全局变量。常量（速度、颜色、尺寸）集中在文件顶部，方便调参。

### 8. 要避开的问题

- 没有开始屏或结束屏，打开就开始，死了就卡住，或者只能刷新页面重开。
- 纯色方块加默认字体，没有任何动效和反馈。
- 速度随帧率变化，高刷新率屏幕上快得离谱。
- 大面积紫蓝渐变、满屏霓虹光晕、emoji 充当角色。
- 操作说明只写在代码注释里，玩家根本看不到。

### 9. 安装前自查

逐条过一遍，有不满足的先改草稿：
1. 开始、游戏中、暂停、结束、重开五个流程都能走通，重开后没有残留状态。
2. 得分、失败、升级都有至少两种反馈（视觉加声音或动效）。
3. 运动乘了 dt，canvas 处理了 devicePixelRatio 和窗口缩放。
4. 键盘和鼠标/触摸都能完整玩一局，开始屏写清了操作。
5. 配色统一、主角和危险一眼可辨，cover.svg 和游戏风格一致。
6. 前 30 秒新手能活下来，难度有上限，随机局面都有解。
