# MBTI 性格测评

协议 2 / schema 3 的离线应用包。48 道原创日常情境题，固定规则计分；16 类完整基础内容、四维倾向解读和情境建议全部随包提供，不调用大模型或网络服务。

## 界面（1.3.0）

按手机端 `mbti-native.html` 第四版实现：珊瑚橙红、暖白、墨灰与紧凑排版；首页暖色透明 WebP 为 768 × 512、约 63 KiB。答题选中即存档，点击下一题才前进，支持改选、上一题、跳过和补答。48 题与原计分规则不变。

结果使用六个可切换章节，四维解读可展开、优势与盲点可切换，情境建议保留真实作答依据。一周行动勾选仅在当前页面会话内保留。结果的类型、分数、角色和日期均来自实际存档；分享继续使用已有真实海报和系统导出。

页面与报告章节接入浏览器历史；无进度的旧答题历史回到首页。固定顶栏局部避让宿主胶囊，滚动内容位于顶栏下方；不复制系统状态栏或新增退出按钮。明暗模式跟随宿主主题，无宿主时跟随系统。

## 报告组合

- `rules.js` 保持原有题序、A/B 反转和等权计分：E/I、S/N、T/F、J/P 各 12 题，交错排列。每侧百分比按该维度已答题计算；未答题不计分，持平时保留原来的 E/S/T/J 字母约定，并在维度段落展示“两侧相近”。
- `profiles.js` 为 16 类分别提供角色名、分组、总体介绍、三条优势、三条工作建议、三条盲点、关系分析与三条成长建议。角色图来自已审阅的原创图鉴，NT 紫、NF 绿、SJ 蓝、SP 金黄。
- `report.js` 根据多数侧比例选择文字：50% 为平衡，51–58% 为灵活，59–74% 为较清楚，75–100% 为更鲜明；本维度少于 6 题时不做强弱归类。这是文案分支规则，不增加额外心理测量分数。
- 八组情境使用明确的题目 ID，每组 3 题：恢复精力、工作交流、接收信息、学习复盘、处理分歧、回应反馈、闲暇计划、项目推进。至少有 2 个有效答案，且同一侧占已答题的 2/3 以上才生成对应建议。报告可展开查看采用了哪些真实选择，不显示虚构的人群排名或匹配率。
- 成长行动优先选取与总体类型不同、但情境回答明确的建议，再按支持该建议的答案数量排序；不足三条时用该类型的成长建议补齐。相同答案会得到相同报告；同类型、同总分的不同答题组合也可以得到不同情境建议。

## 页面与资源

`index.html` 依次加载 `rules.js`、`profiles.js`、`report.js`、`report-view.js` 与 `game.js`。报告有六章：倾向、优势与盲点、工作、人际关系、成长、尾声；章节导航、四维图表、工作表格及情境依据均使用实际结果。

`assets/characters.png` 是 16 角色图鉴，报告按类型显示对应形象。`game.css` / `theme.css` 保留测题页面，`report.css` 提供报告布局。入口只引用包内文件。Android 构建同步本包并注入 `builtin-runtime.js`；桌面使用已有运行时适配器。独立浏览器可答题，当前页面会话内保留结果。

`share.js` 根据实际结果在本地绘制 PNG 海报，使用该人格的角色和主题色，并带测试日期与指向测评入口的二维码。桌面通过系统文件对话框保存；Android 10 及以上保存到相册，旧版本通过系统文件对话框保存，并支持通过系统分享面板发送图片或结果链接；网页支持下载、系统分享或复制链接。系统分享面板的可用目标由设备和应用决定。

结果链接由 `share.html` 展示类型、四维倾向和对应的基础报告章节。链接中只包含类型、四维比例、各维作答数和测试时间，不包含原始答案；情境答案分析仅留在本机。网页部署需包含同步后的 `builtin-games/mbti/` 静态资源；本地计算和海报生成不依赖大模型。

## 存档兼容

新存档 `version:2`，当前进度仍为 `{current,answers,mode}`。完成结果包含 `{type,percentages,totals,completedAt,answers}`，保留该次 48 位答案快照。恢复时从快照重新计算分数，报告读取这一快照，不读取之后重新开始的进度。

兼容旧 `version:1`：旧进度可以继续答题；只有汇总分数的历史结果继续展示类型内容和四维解读，不凭空补造情境答案。重新测评后会获得完整的情境分析。测试日期沿用实际完成时间，重新查看不改变日期。新存档仍远小于 32 KiB。

## 验证

在桌面子项目执行 `npx vitest run src/games/mbti-report.test.ts`。覆盖 16 类报告、相同类型/分数下的不同情境建议、选项反转、强弱分档、持平与缺答、存档迁移、完成测题和重开结果。

本目录与 `assets/game-packs/mbti/` 保持相同，作为客户端运行包与构建基准副本。原型设计与生成素材记录位于手机设计目录的 `app-plaza-assets/mbti-design-notes.md`。
