# MBTI 性格测评

小伴官方作品，使用游戏运行时协议 1 的离线 HTML 工具，适配手机竖屏与桌面窗口。48 道日常情境题、16 种类型解读以及工作方式和盲点建议全部原创；不是 MBTI 品牌的官方量表或授权测评，不用于心理诊断、能力评价或人员筛选。倾向不是标签，情境与状态会改变选择。本作品不收集任何数据，不读取账号、不请求网络、不做统计；答案与最近一次结果仅由小伴宿主保存在这台设备上，不使用 localStorage、cookie 或 IndexedDB。独立打开也可完成测评，但刷新后不保留数据，首页会提示这一限制。

## 交互与计分

- 约 10 分钟，E/I、S/N、T/F、J/P 各 12 题，四个维度交错排列；每个维度的 A/B 方向逐题反转，各有 6 题以第一侧为 A。题序与选项顺序固定，方便恢复进度。
- 每题两个选项，选中计对应侧 1 分，权重相同。每侧百分比为本维度该侧得分除以已答题数，四舍五入到整数；另一侧取补数，合计 100%。百分比不是能力高低，也不是诊断概率。
- 多数侧决定字母；持平时暂取 E/S/T/J 侧，结果页明确标注“两侧持平”并解释归类约定。任一维度完全未答不生成类型，先补答；未答题不计分。每个维度只答少量题时，结果仍只是初步参考。
- 点选后短暂高亮并自动前进；“上一题”可查看和修改答案，“跳过”不会清除已有答案。跳过的题在末尾集中提供补答入口，也可查看已答结果（每个维度至少答 1 题）。
- 触控、鼠标均可走完所有流程；所有按钮至少 44×44px。有键盘时用 1/2 选择，←/→ 翻题，→ 遇未答题等同跳过。Esc 交给与现有官方游戏相同的 `desktop-host.js` 处理。
- 答题或结果页可返回首页，继续进度或打开上次结果。“重新开始”“再测一次”仅重置当前进度，保留上次结果，直至新测评完成后替换。

## 文件与宿主

`index.html` 使用普通脚本，按顺序加载 `rules.js`（题目、纯计分函数及存档校验）、`profiles.js`（原创解读）、`game.js`（界面、输入及握手）。`game.css` 负责布局，`theme.css` 负责纸张配色，`cover.svg` 是 640×360 的纯 SVG 封面。`desktop-host.js` 与 merge-2048 的副本相同，在 head 中以相同方式引入。

顶层同步监听 `host.init`，校验父窗口来源、`xiaban.game-host` 通道、协议 1 与 URL 的 `hostNonce`，回复 `game.ready` 后再发送 `game.save`。存档结构为 `{version:1, progress:{current,answers,mode}|null, lastResult:{type,percentages,totals,completedAt}|null}`；`current` 为从 0 开始的题号，答案为 0/1/null，百分比固定按 E/S/T/J 侧保存，完成时间为 ISO 字符串。每次作答、翻题、跳过和重开立即保存，完成时保存最近结果并清空当前进度；大小远低于 32 KiB。重复初始化不覆盖当前会话，延迟握手不覆盖已开始作答的进度。宿主安全边距与设备安全区共同参与布局。

两处 `mbti/`（本目录与 `assets/game-packs/mbti/`）内容完全相同。本次只提供作品，未登记任何客户端目录列表。现有 `check-game-assets.mjs` 按已登记的九个游戏检查，不覆盖 MBTI；`check-builtin-assets.mjs` 校验内置壁纸，不覆盖本作品。

可用 `python3 -m http.server 1424 --bind 127.0.0.1 --directory client/xiaoban-desktop/public/game-packs/mbti` 在仓库根启动预览，打开 `http://127.0.0.1:1424/index.html`。宿主内的跨启动存档依赖小伴的协议实现；独立页面仅在当前打开期间保留状态。
