# 消失高手

独立的 8×8 方块消除网页游戏。游戏资源在本目录，清新主题使用上级目录的 `fresh-theme.css`，结算分享使用上级目录的 `result-share.js` 和 `result-share.css`；部署时须同时保留这三个共享文件。普通 `defer` 脚本在宿主的 `sandbox="allow-scripts"` iframe 中运行，不依赖 ES modules、外部服务或浏览器存储。

画面使用浅色背景、白色面板和鲜艳纯色方块，正文统一为深色，辅助文字保持清楚；边框和阴影克制，突出棋盘和待放置方块。`fresh-theme.css` 在 `game.css` 后、`result-share.css` 前加载，通过 body 的 `fresh-game` 类和 `data-game="block-puzzle"` 属性启用对应皮肤。

## 玩法

- 拖动下方任意一个方块到棋盘，或先选方块再点棋盘。点到的位置是方块包围盒的左上格。
- 方块不能旋转、越界或重叠。红色预览表示不可放；亮色预览表示可以放。触屏拖动时方块上移到手指上方，避免手指遮挡落点。
- 填满的行和列同时消除，包括交叉的行列。每放置一格得 1 分；每消除一条得 10 分；一次消除多条再奖励 `5 × 条数 × (条数 − 1)` 分。例如一格补齐交叉的行与列得 31 分。
- 每组随机生成三个方块，三个全部用完才补充新的一组。剩余方块都无处可放时本局结束，随机补充后也会检查是否可继续。
- 棋盘共 25 种形状。没有倒计时，支持重新开始。本次最高分仅在该页面生命周期内保留。

## 操作与适配

- 手机：拖动，或选方块后点棋盘。竖屏与短横屏自动调整棋盘尺寸。
- 键盘：Tab 可到方块和棋盘，1–3 选方块；方向键移动落点；回车或空格放置；Esc 返回广场。
- 结束后结果层聚焦到再来一局按钮，防止键盘进入遮挡后的棋盘。尊重减少动态效果的系统设置。
- 无处放置时，结算弹窗同时提供“分享战绩”和“再来一局”；分享不影响重新开始。分享按钮使用版本 1 的 `game.share` 消息交给宿主，独立打开时进入公开战绩分享页。

## 宿主协议

协议版本 1。读取 URL 的 `hostNonce`，仅接受父窗口发来的匹配 nonce 的 `xiaban.game-host / host.init`。游戏响应 `xiaban.game-pack / game.ready`、`game.start`、`game.progress`、`game.result`、`game.exit`，均携带同一个 nonce。重复初始化只回复 ready，不重复开始对局。

每次有效放置发送 `{ score, lines }`，其中 lines 是累计消除的行和列数量。对局结束发送 result；重开发送新的 start。宿主可保存成绩，游戏包自身不访问账户信息、存储或网站 API。独立打开时，退出按钮跳转 `/games`。

## 规则验证

`rules.js` 以 `globalThis.XiabanBlockPuzzle` 暴露纯规则。`client/xiaban-web/src/games/block-puzzle/rules.test.ts` 用 Node VM 执行实际发布脚本，验证放置、越界、重叠、同时消行列、计分、三块补充和结束条件。
