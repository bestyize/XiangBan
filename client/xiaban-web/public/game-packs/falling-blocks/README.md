# 俄罗斯方块资源包

这是一个独立的单人下落方块游戏包。游戏页面不导入下班啦的 React 组件，不读取账号、不调用网站 API，也不访问网站的本地存储。

## 包结构

- \`manifest.json\`：包编号、版本、显示名称、入口文件和运行协议版本
- \`index.html\`：独立入口
- \`game.css\`、\`game.js\`：全部游戏界面与规则

## 操作

- 电脑：方向键移动和旋转，空格快速下落，P 暂停，Esc 返回
- 手机：点按屏幕下方的操作按钮
- 页面采用紧凑顶部信息栏，暂停位于右上角；10×20 棋盘按剩余宽高自动放大，保持正方形格子。小屏手机保留至少 44px 的操作按钮，独立入口和网站内嵌使用同一布局。
- 视觉采用与小伴贪吃蛇一致的浅绿、奶油白基调，方块为鲜艳纯色圆角几何块，落点用轮廓提示；棋盘按屏幕像素密度绘制，避免放大模糊。
- 消行、计分、速度升级、重新开始均在本包内运行

## 添加另一款游戏

为新游戏创建一个独立目录和清单，在 \`catalog.json\` 的 \`games\` 中增加包编号。运行器按编号读取清单并在受限 iframe 中打开入口，不需要在网站组件里编写游戏规则。
