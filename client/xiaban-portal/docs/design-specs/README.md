# 小伴产品门户设计稿

## 小伴桌面独立下载页

平台顺序已合入门户 `/desktop` 页面。首屏平台选项按 Windows、macOS 的顺序展示，推荐项由访问设备决定。

「龙鱼巡游」案例已合入「让桌面活起来」展台。点击整条案例可打开小伴社区微观展厅的展品详情。[龙鱼展品](https://chat.xiangban.xyz/?tab=gallery&exhibit=arowana)

在仓库根目录运行 `npm --prefix client/xiaban-portal run dev` 后打开预览。[设计稿源文件](prototypes/desktop-download-order.html) · [浏览器预览](http://127.0.0.1:5179/docs/design-specs/prototypes/desktop-download-order.html) · [案例预览](http://127.0.0.1:5179/docs/design-specs/prototypes/desktop-download-order.html#desktop-case)
