# 小伴桌面 --- 桌面端 UI 改造规范 V1.0

> 各模块的设计文档与可交互原型统一从 [设计规范目录](docs/design-specs/README.md) 进入。超级小伴悬浮按钮和截图工具以 [专项设计规范](docs/design-specs/super-assistant.md) 及对应 HTML 为准。

## 设计定位

将「小伴桌面」打造为：

> 暖杏奶油 × 日落珊瑚 × 轻治愈

风格关键词：

-   温暖
-   简洁
-   精致
-   治愈
-   桌面原生感
-   高级但不冰冷

核心原则：

**软件界面保持克制，壁纸内容负责视觉冲击。**

不要把宣传图中的云朵、花瓣、猫咪和夕阳背景全部搬入实际 UI。

# 五、页面设计

## 首页

布局：

1.  搜索框
2.  精选 Banner
3.  分类入口
4.  今日推荐
5.  热门壁纸
6.  最新内容

Banner：

-   高度 180\~320px
-   比例约 3.5:1
-   文案放左侧
-   不遮挡壁纸主体

壁纸卡片：

-   桌面端自动适配 3\~6 列
-   图片保持比例
-   Hover 显示收藏、预览

------------------------------------------------------------------------

## 发现页

结构：

顶部：

-   分类 Tabs
-   筛选条件
-   排序

内容：

-   壁纸 Grid
-   最小宽度 190px
-   最大宽度 300px
-   间距 16px

支持：

-   懒加载
-   Hover 状态
-   虚拟列表

------------------------------------------------------------------------

## 壁纸详情页

采用：

左侧：

-   大图预览

右侧：

-   名称
-   标签
-   分辨率
-   收藏
-   下载
-   设置壁纸

右侧面板：

300\~340px

原则：

壁纸是绝对主角。

------------------------------------------------------------------------

## 桌面组件页

采用：

左侧：

组件分类

右侧：

组件预览网格

组件显示：

-   实际尺寸
-   添加按钮
-   配置入口

------------------------------------------------------------------------

## 个人中心

布局：

左：

-   用户信息
-   收藏
-   下载
-   设置

右：

-   桌面组件展示

减少装饰，提高功能密度。

# 六、交互规范

状态：

-   Default
-   Hover
-   Pressed
-   Disabled
-   Loading

动画：

-   普通交互：120\~180ms
-   页面动画：180\~240ms

要求：

-   支持键盘焦点
-   支持鼠标
-   支持触控板
-   支持窗口缩放

------------------------------------------------------------------------

# 七、禁止事项

禁止：

-   大面积蓝紫色
-   玻璃拟态
-   过度阴影
-   每个页面放猫咪装饰
-   使用宣传图作为背景
-   修改用户壁纸颜色
-   为 UI 改造重构业务架构

------------------------------------------------------------------------

# 八、AI代码改造执行要求

1.  先分析现有工程结构。
2.  保留业务逻辑。
3.  建立统一 Theme Token。
4.  修改基础组件。
5.  修改页面布局。
6.  完善交互状态。
7.  静态检查。

不要：

-   修改 CI
-   修改构建流程
-   增加无关依赖
-   运行耗时完整发布流程

------------------------------------------------------------------------

# 九、最终目标

打造一款：

> 像 macOS 原生应用一样精致， 像治愈系壁纸社区一样温暖，
> 又拥有"小伴"陪伴感的桌面壁纸软件。
