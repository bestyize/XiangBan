# 桌面特效包格式

桌面特效是铺在整个桌面上的一层粒子（雨、雪、枫叶、繁星等）。每种特效是一个 JSON 文件，叫“特效包”。特效包只描述数据：有几层粒子、每层多少个、多大、怎么运动、长什么样。里面不能写代码，应用读到后会逐项检查并限制数值范围，再交给统一的引擎绘制。

内置的七个特效包在 `public/effects/`（雨、雪、萤火虫、花瓣、枫叶、流星、繁星），编译进程序。自己的特效包放进用户数据目录的 `effects/` 文件夹（控制台“桌面特效”页的“打开特效文件夹”会打开它，首次打开时里面有一份示例），改完点“重新载入”即可，不用重启。

加载规则：

- 只读 `.json` 文件；文件名以 `_` 或 `.` 开头的会被跳过（想暂时停用一个特效包，给文件名加个下划线前缀）。
- 单个文件不超过 64 KB，最多加载 40 个自定义特效包。
- 特效包的 `id` 不能和内置的重名，也不能和其他自定义特效包重名；重名的文件会被忽略。
- 有问题的文件不会影响别的：控制台会列出“文件名：原因”。

示例见 [effect-pack-example.json](effect-pack-example.json)。

## 顶层

| 字段 | 说明 |
| --- | --- |
| `schemaVersion` | 必须是 `1` |
| `id` | 小写字母、数字、`-`、`_`，不超过 48 个字符，不能以 `-`、`_` 开头 |
| `name` | 显示名，最多 24 个字 |
| `description` | 一句话说明，最多 80 个字（可省略） |
| `sky` | 2 到 4 个十六进制颜色，用作控制台预览卡片的背景渐变（可省略） |
| `layers` | 粒子层数组，1 到 6 层，画的时候靠前的先画 |

所有层的 `count` 加起来不能超过 3000。

## 粒子层

每层是一类粒子。下表里的“范围”写成一个数，或 `[最小, 最大]`。

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `count` | 0 | 密度为 1、屏幕 1920×1080 时的粒子数，上限 1500。屏幕小就按面积成比例减少 |
| `shape` | 必填 | 形状，见下 |
| `colors` | 必填 | 1 到 24 个颜色，每个粒子随机取一个。写成 `"#rrggbb"`（也支持 `#rgb`），或 `["#上部/中心色", "#下部/外圈色"]` |
| `size` | `[10, 20]` | 大小，像素（按 1080 高的屏幕算，屏幕更高会等比放大，最多 1.8 倍） |
| `speed` | 0 | 沿 `direction` 前进的速度，像素每秒 |
| `direction` | 90 | 前进方向，度数：0 向右，90 向下，180 向左，270 向上 |
| `alpha` | `[0.5, 1]` | 不透明度 |
| `wind` | 0 | 受公共阵风的影响，像素每秒。阵风对所有层是同一阵缓慢变化的风 |
| `sway` | 无 | 左右摇摆：`{"amplitude": 范围, "frequency": 范围}`，摇摆速度的幅度（像素每秒）和每秒几次 |
| `wander` | 无 | 慢慢游荡（萤火虫）：同样的 `amplitude` 和 `frequency`，向各个方向 |
| `spin` | 0 | 自转，弧度每秒，负数反向 |
| `pendulum` | 0 | 随摇摆倾斜的幅度（弧度），像树叶一样荡着往下落 |
| `scatter` | 1 | 起始角度：0 全部朝上，1 随机朝向 |
| `flip` | 无 | 翻面：`{"rate": 范围, "min": 0.05 到 1}`，粒子的宽度在 `min` 和 1 之间来回变，像花瓣翻转 |
| `twinkle` | 无 | 闪烁：`{"rate": 范围, "depth": 0 到 1}` |
| `burst` | 无 | 见下，用于流星这类“隔一会儿出现一次”的粒子 |

每个粒子有一个随机的“远近”：远的小、慢、淡，近的大、快、亮。`size`、`speed`、`alpha` 的范围就是按远近从小到大取值，所以一层里会有层次感。想要更明显的前后层，就分成两层写。

## 形状

| `kind` | 说明 |
| --- | --- |
| `circle` | 实心圆点 |
| `glow` | 柔和的光斑。`core`（0 到 0.9）是中心一个小亮点占光斑半径的比例；颜色的第一个值是中心色，第二个值是外圈色 |
| `streak` | 沿前进方向的一条线，带渐隐的尾巴（雨丝、流星）。`length` 长度范围、`width` 粗细范围、`head` 为 0 到 8，大于 0 时头部有光晕并且尾巴有辉光 |
| `path` | 自定义 SVG 路径（枫叶、花瓣、雪花、星芒） |

`path` 的字段：

- `d`：SVG 路径数据，坐标画在 `-1` 到 `1` 的方框里（中心是原点，y 向下），会按粒子大小缩放。只允许路径命令（`M L H V C S Q T A Z`）、数字和分隔符，最长 6000 个字符。
- `style`：`fill`（默认，用两个颜色上下渐变填充）、`stroke`（只描线，用第一个颜色）或 `both`。
- `lineWidth`：描线粗细，同样按 `-1` 到 `1` 的方框算，默认 0.08。
- `vein`：可选的叶脉，`{"d": 路径, "color": "#颜色", "alpha": 0 到 1, "width": 粗细}`，画在填充之上。

## 隔一会儿出现一次（burst）

写了 `burst` 的层，粒子不会一直在屏幕上，而是每个粒子循环：出现、沿 `direction` 走一段、淡出、休息、换个位置再出现。

| 字段 | 说明 |
| --- | --- |
| `duration` | 一次划过用多少秒 |
| `rest` | 两次之间休息多少秒 |
| `x`、`y` | 出现位置，屏幕宽高的比例（0 是左/上边，1 是右/下边，可以超出一些，表示从屏幕外进来） |
| `travel` | 一次走多远，像素 |

## 用户在控制台里能调的

每个特效有三个滑块，保存在设置里并且各自记住：

- **密度**：倍数 0.2 到 2.5，乘到 `count` 上。
- **速度**：倍数 0.25 到 3，所有运动（包括摇摆、翻转、闪烁）一起变快或变慢。
- **大小**：倍数 0.5 到 2，乘到 `size`（和 `streak` 的长度、粗细）上。

## 引擎的行为

- 粒子的位置是循环的：从屏幕一边出去，从另一边进来，中间留出和粒子一样宽的边，所以大叶子不会在边缘“弹”出来。
- 改密度只增减粒子，已有的不会重置位置。
- 切换另一个特效，或者特效包文件的内容变了，才会重新开始。
- 全局的“暂停桌面动画”和 30/60 帧设置对特效同样有效。
- 游戏空间打开期间特效隐藏，退出后恢复。
