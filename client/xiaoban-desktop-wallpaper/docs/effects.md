# 桌面特效包格式

桌面特效是铺在整个桌面上的一层粒子（雨、雪、枫叶、繁星等）。每种特效是一个 JSON 文件，叫“特效包”。特效包只描述数据：有几层粒子、每层多少个、多大、怎么运动、长什么样。里面不能写代码，应用读到后会逐项检查并限制数值范围，再交给统一的引擎绘制。

内置的十二个特效包在 `public/effects/`（雨、雪、萤火虫、花瓣、枫叶、流星、繁星、庄周梦蝶、孔明灯、烟花、极光、银河），编译进程序。自己的特效包放进用户数据目录的 `effects/` 文件夹（控制台“桌面特效”页的“打开特效文件夹”会打开它，首次打开时里面有一份示例），改完点“重新载入”即可，不用重启。

加载规则：

- 只读 `.json` 文件；文件名以 `_` 或 `.` 开头的会被跳过（想暂时停用一个特效包，给文件名加个下划线前缀）。
- 单个文件不超过 64 KB，最多加载 40 个自定义特效包。
- 特效包的 `id` 不能和内置的重名，也不能和其他自定义特效包重名；重名的文件会被忽略。
- 有问题的文件不会影响别的：控制台会列出“文件名：原因”。

示例见 [effect-pack-example.json](effect-pack-example.json)。

## 顶层

| 字段 | 说明 |
| --- | --- |
| `schemaVersion` | 必须是 `1` |
| `id` | 小写字母、数字、`-`、`_`，不超过 48 个字符，不能以 `-`、`_` 开头 |
| `name` | 显示名，最多 24 个字 |
| `description` | 一句话说明，最多 80 个字（可省略） |
| `sky` | 2 到 4 个十六进制颜色，用作控制台预览卡片的背景渐变（可省略） |
| `layers` | 粒子层数组，1 到 6 层，画的时候靠前的先画 |

所有层的 `count` 加起来不能超过 3000。

## 粒子层

每层是一类粒子。下表里的“范围”写成一个数，或 `[最小, 最大]`。

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `count` | 0 | 密度为 1、屏幕 1920×1080 时的粒子数，上限 1500。屏幕小就按面积成比例减少 |
| `shape` | 必填 | 形状，见下 |
| `colors` | 必填 | 1 到 24 个颜色，每个粒子随机取一个。写成 `"#rrggbb"`（也支持 `#rgb`），或 `["#上部/中心色", "#下部/外圈色"]` |
| `size` | `[10, 20]` | 大小，像素（按 1080 高的屏幕算，屏幕更高会等比放大，最多 1.8 倍） |
| `speed` | 0 | 沿 `direction` 前进的速度，像素每秒 |
| `direction` | 90 | 前进方向，度数：0 向右，90 向下，180 向左，270 向上 |
| `alpha` | `[0.5, 1]` | 不透明度 |
| `wind` | 0 | 受公共阵风的影响，像素每秒。阵风对所有层是同一阵缓慢变化的风 |
| `sway` | 无 | 左右摇摆：`{"amplitude": 范围, "frequency": 范围}`，摇摆速度的幅度（像素每秒）和每秒几次 |
| `wander` | 无 | 慢慢游荡（萤火虫）：同样的 `amplitude` 和 `frequency`，向各个方向 |
| `spin` | 0 | 自转，弧度每秒，负数反向 |
| `pendulum` | 0 | 随摇摆倾斜的幅度（弧度），像树叶一样荡着往下落 |
| `scatter` | 1 | 起始角度：0 全部朝上，1 随机朝向 |
| `flip` | 无 | 翻面：`{"rate": 范围, "min": 0.05 到 1}`，粒子的宽度在 `min` 和 1 之间来回变，像花瓣翻转 |
| `twinkle` | 无 | 闪烁：`{"rate": 范围, "depth": 0 到 1}` |
| `burst` | 无 | 见下，用于流星、烟花、涟漪这类“隔一会儿出现一次”的粒子 |
| `band` | 无 | 见下，让粒子聚在横过屏幕的一条带里（银河、极光），不和 `burst` 同用 |
| `blend` | `normal` | `add` 时重叠的光会叠加变亮，适合光斑、烟花、极光 |
| `orient` | `fixed` | `motion` 时粒子转向自己前进的方向（路径要画成头朝右，比如锦鲤），此时 `pendulum` 变成左右摆尾；`fixed` 按 `spin`、`scatter` 转 |

每个粒子有一个随机的“远近”：远的小、慢、淡，近的大、快、亮。`size`、`speed`、`alpha` 的范围就是按远近从小到大取值，所以一层里会有层次感。想要更明显的前后层，就分成两层写。

## 形状

| `kind` | 说明 |
| --- | --- |
| `circle` | 实心圆点 |
| `glow` | 柔和的光斑。`core`（0 到 0.9）是中心一个小亮点占光斑半径的比例；`aspect`（0.1 到 4，默认 1）是高宽比，小于 1 时压扁成沿粒子角度的椭圆（星云）；颜色的第一个值是中心色，第二个值是外圈色 |
| `streak` | 沿前进方向的一条线，带渐隐的尾巴（雨丝、流星）。`length` 长度范围、`width` 粗细范围、`head` 为 0 到 8，大于 0 时头部有光晕并且尾巴有辉光 |
| `path` | 自定义 SVG 路径（枫叶、花瓣、雪花、星芒、蝴蝶、孔明灯、锦鲤） |
| `ring` | 圆环轮廓（涟漪）。`width` 粗细范围（像素），`aspect`（0.1 到 1）是高宽比，压扁后像从侧面看到的水面；外面还有一圈宽而淡的光边。第一个颜色画淡光边，第二个画清晰的环 |
| `beam` | 一道竖长的柔光，靠下端最亮（极光的光幕）。`size` 是宽度，`length` 是长度范围（像素），`focus`（0 到 0.9）是最亮处离中心向下有多远。第一个颜色是上部的光，第二个是下端亮处 |

`path` 的字段：

- `d`：SVG 路径数据，坐标画在 `-1` 到 `1` 的方框里（中心是原点，y 向下），会按粒子大小缩放。只允许路径命令（`M L H V C S Q T A Z`）、数字和分隔符，最长 6000 个字符。
- `style`：`fill`（默认，用两个颜色上下渐变填充）、`stroke`（只描线，用第一个颜色）或 `both`。
- `lineWidth`：描线粗细，同样按 `-1` 到 `1` 的方框算，默认 0.08。
- `vein`：可选的叶脉，`{"d": 路径, "color": "#颜色", "alpha": 0 到 1, "width": 粗细}`，画在填充之上。
- `halo`：可选的背光，`{"scale": 1 到 6, "y": -1 到 1, "color": "#颜色", "alpha": 0 到 1}`，在形状背后画一团柔光（孔明灯的火光）。`scale` 是光的半径、`y` 是光心的上下位置，都按 `-1` 到 `1` 的方框算。

## 隔一会儿出现一次（burst）

写了 `burst` 的层，粒子不会一直在屏幕上，而是每个粒子循环：出现、沿 `direction` 走一段、淡出、休息、换个位置再出现。

| 字段 | 说明 |
| --- | --- |
| `duration` | 一次划过用多少秒 |
| `rest` | 两次之间休息多少秒 |
| `x`、`y` | 出现位置，屏幕宽高的比例（0 是左/上边，1 是右/下边，可以超出一些，表示从屏幕外进来） |
| `travel` | 一次走多远，像素（可以是 0，原地出现，比如涟漪） |
| `group` | 1 到 200，默认 1。大于 1 时这么多个粒子算一组：同一个起点、同一时间、同一种颜色（一朵烟花的火花、一处涟漪的几圈）。改密度时整组增减，`count` 最好写成 `group` 的倍数 |
| `spread` | 0 到 360 度，组内粒子的方向在 `direction` 基础上均匀散开，360 就是向四面八方炸开 |
| `stagger` | 秒，组内粒子一个接一个出现的间隔（一圈接一圈的涟漪） |
| `launch` | 秒的范围，可省略。写了就先让组里第一个粒子从屏幕底边升到起点（烟花升空），到了再炸开 |
| `gravity` | 像素每秒²，向下拉（负数向上），火花会划出下垂的弧线 |
| `ease` | `linear`（默认，匀速）或 `out`（开始快、越走越慢，像炸开的火花） |
| `fade` | `in-out`（默认，淡入再淡出）或 `out`（一出现就亮，慢慢消失） |
| `grow` | 从开始到结束的大小倍数，如 `[0.06, 1]` 让涟漪由小变大 |
| `fill` | 0 到 1，默认 0。0 时一组粒子落在一个圈上；1 时像一个从正面看的火花球，边缘密、中间也填满（牡丹、菊花礼花） |
| `flatten` | 范围，0.05 到 1，默认 `[1, 1]`。把一组的图案压扁到这个高度比例，每次随机倾斜（斜着看到的光环） |
| `flash` | 秒，0 到 2。炸开处闪一下白光，外圈是这组的颜色 |
| `mix` | 0 到 1。组里这个比例的粒子改用调色板里的下一个颜色（双色礼花） |

成组的粒子每次重新出现都会换一套随机图案。`streak` 粒子在成组爆发里会随速度缩短尾巴：越飞越慢的火花尾巴越短，被重力加速下落时又拉长。

## 带状分布（band）

写了 `band` 的层，粒子不再铺满全屏，而是聚在一条横过屏幕的带里，沿着带前进并循环。前进速度取 `speed`、`direction` 和 `wind` 在带方向上的分量；`sway`、`wander` 只让粒子在原位附近晃动，不会离开带。

| 字段 | 说明 |
| --- | --- |
| `angle` | -90 到 90 度，带相对水平方向转多少（负数是左低右高） |
| `offset` | 带的中线离屏幕中心多远，按屏幕高度算，负数在上方 |
| `width` | 带有多厚，按屏幕高度算 |
| `falloff` | `gauss`（默认，越靠中线越密）或 `even`（均匀） |
| `wave` | 中线的起伏：`{"amplitude": 按屏幕高度算的幅度, "count": 整条带上有几个波, "speed": 每秒移动几个波}` |

粒子的角度会加上带的角度，所以压扁的光斑会顺着带的方向。

## 用户在控制台里能调的

每个特效有三个滑块，保存在设置里并且各自记住：

- **密度**：倍数 0.2 到 2.5，乘到 `count` 上。
- **速度**：倍数 0.25 到 3，所有运动（包括摇摆、翻转、闪烁）一起变快或变慢。
- **大小**：倍数 0.5 到 2，乘到 `size`（和 `streak` 的长度、粗细）上。

## 引擎的行为

- 粒子的位置是循环的：从屏幕一边出去，从另一边进来，中间留出和粒子一样宽的边，所以大叶子不会在边缘“弹”出来。
- 改密度只增减粒子，已有的不会重置位置。
- 切换另一个特效，或者特效包文件的内容变了，才会重新开始。
- 全局的“暂停桌面动画”和 30/60 帧设置对特效同样有效。
- 游戏空间打开期间特效隐藏，退出后恢复。
