本版以用户提供的 1448×1086 设计稿为唯一视觉基准。旧求签、成长花朵、自定义 HTML 组件、玻璃/纸张/透明主题系统已退出运行时，组件库仅提供以下八类。

| --- | --- | --- |
| 时钟 | 596×306 | 本机时间、日期、农历 |
| 天气 | 326×306 | 城市配置、实时天气、当日高低温、US AQI 空气质量 |
| 待办 | 352×306 | 新增/编辑/完成/删除、日期时间、重复与到点提醒 |

| 电子木鱼 | 390×332 | 敲击、声音开关持久化、本地累计 |
| 月历 | 500×286 | 周日开头，翻月、选择日期、回到本月 |
| 纪念日 | 790×286 | 一次性、年度重复、正计时 |

## 材质与构图

暖白卡片采用 `#f8f5f0` 到 `#f1eee8` 的轻微渐变，细白描边、35px 圆角、暖灰双层柔影与细颗粒。正文接近 `#202122`，次要文字使用中性灰，交互强调为暖木色。股票例外，使用炭黑底、白色主数字、上涨珊瑚红/下跌柔绿走势。避免旧版玻璃模糊底、蓝绿色配色和装饰性书法标题。

时钟右侧保留日出山峦，纪念日右侧保留湖景，木鱼使用稿中木纹素材，并独立渲染可敲击的槌。装饰通过 `assets/design-reference.png` 的 CSS 裁切窗口复用，不将图中的文字、数字或按钮作为可交互界面；动态信息全部由 Vue 渲染。

组件库采用设计稿原有的三行不等宽拼排，基准画布 1314×967，按容器宽度等比缩放。添加操作只在悬停、键盘焦点或触屏窄屏下显现。设置集中在弹窗，不在卡片中堆放配置项。默认暖白材质固定，不再提供旧主题选择。

新组件的默认大小按屏幕分辨率换算：以 1440×900 桌面上 50% 为基准，按显示器逻辑尺寸的短边比例放大或缩小（2560×1440 约 80%，3840×2160 约 120%），并限制在 50%–150% 的滑杆范围内。此前固定 50%，在高分屏上显得过小。计算在原生端按实际显示器进行，浏览器预览按 `window.screen` 估算。已有组件不重算，仍用各自保存的缩放值。

## 数据与替换

布局 schema 升为 2。原生首次遇到 V1 布局时，将其重命名为带时间戳的 `.bak`，不恢复任何旧实例；浏览器使用独立的 `xiaoban.widgets.v2`。旧 HTML 渲染器、导入/创建命令和模型创作工具均已移除，旧资源包导入会明确提示不支持。新组件允许多实例，保留显示/隐藏、等比缩放、多屏拖动和位置保存。

天气/股票展示位可以含标明为示例的展示数据；真实桌面不伪造天气、空气质量或股价。行情显示来源和数据时间，网络失败呈现错误状态。待办/日程的到点提醒复用原生关怀调度与气泡，不依赖桌面 WebView 定时器；应用须保持运行，并开启关怀提醒总开关，遵循勿扰、锁屏和游戏设置。支持一次性、每天、周一至周五、每周，持久化去重；重复事项完成只影响当天。设置页可管理过去和未来日程。空气质量使用 Open-Meteo/CAMS 模型数据，明确标注 US AQI 标准、来源与数据时间；失败不影响天气显示。自选批量报价使用东方财富，曲线优先腾讯财经、失败回退东方财富；不以请求时间冒充交易时间。木鱼快速连击合并顺序保存，写入失败保留错误反馈。

## 本轮验证

针对组件运行 Vitest，使用 `vue-tsc --noEmit` 检查类型。已实测空气质量、自选报价及腾讯曲线接口能返回有效数据；Windows/macOS 原生运行及截图视觉检查仍需对应环境验证。

## 小伴 AI 设置组件内容

`widget_add` 和 `widget_update` 的 `content` 参数让 AI 直接填组件里的内容，不必让用户去组件上手动输入：待办（`notes`：条目、完成状态、日期时间、提醒、重复）、纪念日（`countdown`：标题、日期、倒数或已过去、每年重复）、今日日程（`reminders`）、股票（`stocks`：自选代码，沪市 `1.600519`、深市 `0.000001`、港股 `116.00700`）。`items` 默认整体替换，`append=true` 追加；改某一条前先 `widget_list`，它会列出每条的 id，替换时带上 id。逻辑在 `src-tauri/src/chat/widget_content.rs`，同样的长度和格式限制在这里先检查并给出中文提示，最终仍由布局保存时的校验兜底。`widget_add` 的 `content` 有误时不会创建组件。
