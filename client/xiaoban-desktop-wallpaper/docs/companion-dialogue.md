# 伙伴点击对话

桌面伙伴点击后立即做动作，短时间连续点击合并为一次搭话；拖拽不会触发搭话。聊天输入框上方的伙伴复用同一套回复卡片和宿主对话服务。主动悬停问候保持原有开关和频控，用户主动点击不消耗主动问候额度。

## 本地与模型回复

`src/companion-dialogue/corpus.json` 包含 21 类、336 条独立短句，按初见、重逢、连续点击、时段、周末、心情和对话分支组织。每类短句按温柔、活泼、安静、俏皮四种语气交错排列。宠物类型决定基础语气，困倦状态使用安静语气；每个实例分别记录互动进度和近期短句，最近使用的语料会避让。快捷选项可以连续接话，无模型也能使用。

点击先返回本地回复，再尝试当前已选模型。只发送这只伙伴自己的近期互动，以及其专属会话的最近少量文字，不读取其他伙伴的聊天，也不读取屏幕或运行工具。使用当前配置的协议、推理偏好和登录凭据；失败、超时、回复格式异常时保留本地回复。全应用最多一个在途请求，模型请求间隔至少 6 秒，气泡最多等待模型 18 秒。旧请求不会覆盖新的互动或已经关闭的卡片。

卡片默认 12 秒收起；鼠标停留和键盘聚焦时暂停收起。点击正文或“接着聊”才进入正式聊天。

## 会话归属

首次“接着聊”才创建正式会话，侧栏按需出现“伙伴”逻辑分组，不对应真实文件夹。以伙伴实例 ID 为身份，同款的两只伙伴各有默认会话；修改昵称仍延续同一会话。以后“接着聊”复用该伙伴最近的会话，只补入尚未交接的气泡互动。删除正式会话后下次重新创建；移除桌面伙伴不删除历史会话。

优先在超级小伴打开。超级小伴未启用、打开失败、存在未发送草稿或正在执行其他会话时，改为在主聊天页打开，保留已有草稿及运行状态。会话采用默认询问权限；点击气泡本身不运行 Agent 工具，也不会自动发送一条新的模型任务。

互动进度及每只伙伴最多 16 条近期气泡消息保存在本机 `config/companion-dialogue.json`，最多保留 32 个近期伙伴的短期互动。完整正式聊天仍使用已有会话存储；通用主动感知模块保持匿名事件计数，不保存这些聊天内容。文件损坏时不覆盖原文件。
