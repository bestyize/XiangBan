# 资料库设计规范

最终设计稿：「小伴桌面 UI 升级设计稿」画布「④ 资料库」一行（我的文档 / 云文档 / 收藏 / 记忆四张画板）。资料库只回答一件事：**我交给小伴的、和小伴留给我的东西都在哪**。聊天记录留在侧栏，工作区文件留在各自的工作区，壁纸、组件、游戏留在「装扮」「游玩」。

页面顶部四个 Tab，各带数量；右侧一个搜索框（⌘K）同时搜四个 Tab，Tab 上的数量随搜索变化，便于在别的 Tab 里发现结果。每个 Tab 自己的主按钮放在搜索框右边。上次停在哪个 Tab，下次打开还在那里。

## 我的文档

- **导入**：「导入文档」选文件，「导入文件夹」保留原来的层级，也可以把文件直接拖进列表（单个不超过 50MB，更大的用按钮选择）。资料库存的是**副本**（数据目录 `data-library/files/<id>/<原文件名>`），原文件移走或删除不影响；最大 200MB。
- **文件夹**：左侧文件夹树，最多 6 层。「全部文档」「未分组」是视图，其余是文件夹，数量包含子文件夹。悬停可改名、删除；删除文件夹不删内容，内容移到上一级。新建时放在当前打开的文件夹里，同名文件夹合并。把文件拖到左侧的文件夹即可移动，详情面板里也能选「文件夹」移动。
- **列表**：面包屑在上，进入文件夹后先列子文件夹，再列直接放在这里的文件；搜索时在全部文件夹里找，并注明所在位置。可按类型筛选，按最近或名称排序。
- **小伴能否参考**：导入后在后台逐份读取文字（PDF、Word、Excel、PowerPoint 用对话附件同一套解析，文本直接读）。状态：小伴可参考 / 正在读取 / 读不出文字（扫描件、加密或损坏）/ 暂不支持 / 文件太大（文档超过 10MB、图片超过 3MB 时提问带不上）。应用退出时没读完的，下次打开资料库接着读。
- **详情**：内容开头（读出的前 280 字）、文件夹、标签（最多 8 个）、原文件位置。「用这份资料提问」把文件作为附件放进新建任务的输入框（不自动发送）；「在访达中显示」；删除只删副本。

## 云文档

- 只保存链接。「添加链接」弹窗：粘贴链接后立即识别平台（飞书 / Lark、腾讯文档、百度网盘、石墨、语雀、WPS，其余为网页）和类型（文档、表格、多维表格、知识库、文件夹…），可填标题、选放到哪个文件夹。百度网盘链接里的提取码（`pwd=`）一起保存，卡片上可单独复制。只识别真正的域名，`feishu.cn.example.com` 之类的仿冒地址算作网页。
- 弹窗里有「连接账号」一节：连接后小伴才能读内容，凭证由小伴账号服务保管。各平台目前都是「即将支持」，卡片统一标「仅保存链接」。
- 卡片：平台、标题、类型、所在文件夹与添加日期；可改名、复制链接、在浏览器打开、移除（只移除链接）。

## 收藏

- 来源：主窗口回答下的 ☆「存到资料库」、超级小伴卡片回答下的「存到资料库」。同一会话里同一段回答只存一份。
- 卡片显示类型、时间、标题、正文（最多 5 行）、来自哪个会话（主窗口 / 超级小伴）。「回到对话」打开原会话（会话已删除时提示），「接着问」把这段内容带进新建任务，可复制、取消收藏。文件、图片、截图分类已预留，目前收藏的都是回答。

## 记忆

记忆有三种来源，全部来自小伴已有的机制，这里只是让用户看得见、改得了：

| 分组 | 是什么 | 用户能做 |
| --- | --- | --- |
| 等你确认 | 任务复盘后总结出的候选经验，确认前不会被用到 | 记住 / 改一下（改完即记住）/ 不用记 |
| 小伴的笔记 | 小伴在对话里用 `memory_write` 记下的笔记，每次对话都会放进提示里；「写一条」也写到这里 | 修改、忘掉 |
| 做事经验 | 已确认的经验，小伴做事时按需检索 | 修改、忘掉 |
| 长期目标 | 各对话里定下的目标及进度 | 打开对话 |

右侧「让小伴记住我」开关：关闭后不放笔记进提示、不提供记笔记工具、经验检索返回空；已有记忆保留，重新打开即恢复（数据目录 `chat/memory-paused` 标记）。「清空全部记忆」删除所有笔记和经验，目标属于各自的对话，不清空。记忆只保存在本机。

- 页面：`src/ui/pages/LibraryPage.vue`、`src/ui/library/`。
- 测试：`data_library.rs`、`libs/agent-learning`、`libs/agent-kernel` 的记忆单测，`src/ui/library/library.test.ts`，以及聊天页、超级小伴、新建任务里收藏和附件交接的用例。
