# 超级小伴悬浮助手与截图工具设计规范

更新日期：2026-10-23。此规范适用于“超级小伴（小伴语音助手）”，其设置入口进入超级小伴专属设置页。

## 设计参考

- 当前形态以「小伴桌面 UI 升级设计稿」画布中的「④ 超级小伴」三张画板为准（见下一节）。
- [悬浮按钮交互稿](prototypes/assistant-floating-tools.html)：旧版横排工具形态，已被方案四取代，仅作历史参考。
- [截图工具交互稿](prototypes/assistant-capture-overlay.html)：定义截图蒙层、选区和标注工具栏。

HTML 是可交互的视觉与行为参考，使用模拟桌面和对话。正式界面由 Vue/TypeScript 与 Tauri 实现，不在运行时加载这些文件。

## 方案四：小球 → 胶囊 → 卡片

最终设计稿：「小伴桌面 UI 升级设计稿」画布第三行「④ 超级小伴」（小球状态与菜单、胶囊快问、卡片多轮对话三张画板）。视觉与控制台统一：毛玻璃面（浅色 `rgba(255,255,255,.9)`，深色 `rgba(42,43,48,.9)`）、细描边、轻阴影。原生窗口透明且在边缘裁切，阴影只用近距离的两层（不超过 16 px），并给内容留出左右 16 px、底部 20 px 的边距；强调色跟随控制台主题色（`--ui-btn / --ui-soft / --ui-ink / --ui-dot`），深浅色跟随应用外观设置。主题色由控制台经宿主 `set_accent` 保存并随 `settings-changed` 广播，Windows 上不共享页面存储的悬浮窗也能跟随。小球和胶囊左侧的语音按钮都是品牌标志：主题色圆底上的白色 Sparkles（与控制台「小伴 AI」前、应用图标同一图形，主体星形实心以便小尺寸辨认），实现见 `src/assistant/Orb.vue`。圆底跟随主题色（应用图标固定为小伴红）。动效：

| 状态 | 动效 |
| --- | --- |
| 待机 / 等待确认 | 4 秒轻呼吸 |
| 聆听 | 标志变为四根白色声波条，随麦克风音量起伏 |
| 思考 / 文字回答 | 主星轻摆，两颗小星依次闪烁 |
| 语音播放 | 慢节奏声波条，读完变回标志 |
| 出错 | 圆底转灰 |

动效用 CSS 实现，暂停显示时停止，遵循系统“减少动态效果”。

三种形态各管一件事：

| 形态 | 作用 | 尺寸 |
| --- | --- | --- |
| 小球 | 常驻桌面，显示小伴当前状态 | 44 px（窗口 72 px） |
| 胶囊 | 快问：打字、语音、截图、附件 | 宽 448 px，单行高 52 px，输入最多长到 4 行 |
| 胶囊 + 卡片 | 看回答、多轮对话、处理确认 | 卡片正文最高 340 px，内部滚动 |

### 小球状态

标志动效之外，用外圈与角标表达状态：

| 状态 | 表现 |
| --- | --- |
| 空闲 | 标志慢呼吸 |
| 思考 / 生成中 | 外圈主题色进度环旋转 |
| 等你确认（审批或提问） | 琥珀色「!」角标，出现时轻跳一次 |
| 答完未读 | 主题色小圆点 |
| 出错 | 圆底转灰 + 红色角标 |

后台完成、需要处理或失败时，小球朝屏幕内侧冒出一行提示（「已完成 · 查看」「需要你处理 · 去处理」）。提示画在舞台窗口内（见下文），不改窗口大小。完成提示 3 秒后淡出、保留未读点；等待和出错提示一直保留到打开。拖动小球前先收回提示。右键小球打开超级小伴设置。

### 胶囊

从左到右：品牌标志按钮（点击语音）、输入框（Enter 发送，Shift+Enter 换行，自动长高至 4 行）、＋（选择文件，也可拖入或粘贴）、截图提问、发送 / 停止。发送键只做一件事：有内容时为主题色渐变发送，生成中为灰底实心方块停止，空闲无内容时为灰色不可用。

没有卡片时，胶囊上方显示快捷动作「继续「当前会话」」或「继续「最近的另一个会话」」；截图只保留胶囊上的按钮一个入口。

### 卡片

- 头部：会话标题（点开切换最近 6 个会话，底部有「在主窗口查看全部」「超级小伴设置…」）、新对话、在主窗口继续、固定、收成小球。会话列表在卡片内取代对话区显示，卡片随之长高、窗口跟着适配，不做浮在卡片外的下拉菜单——卡片的毛玻璃自成图层，下拉会被下面的胶囊盖住，也会超出按内容定高的原生窗口。点标题、点列表外或按 Esc 收起列表，对话及其滚动位置原样恢复。
- 正文显示当前会话的全部轮次（提问、回答、错误），自动滚到最新。最后一条回答下常驻「复制」「重新生成」，更早的回答在悬停时于右上角浮出复制。
- 生成中正文保持固定高度、在内部滚动，原生窗口不随流式文字抖动；空闲时按内容高度显示，最高 340 px。原生窗口上限 600 px。
- 审批提供「拒绝」「本次会话都允许」「允许这一次」；提问支持按 1–9 快捷选择或直接输入，可跳过。

### 展开与收起

- 展开入口：点小球、提示气泡、全局快捷键。光标自动进入输入框。
- 展开时，后台有未读回答或有待处理事项则直接显示卡片；否则只显示胶囊和快捷动作。
- 收起：Esc（输入框有字时先清空，再按一次收起）、卡片头部「–」、再次按快捷键。
- 点到窗口外自动收起，但仅在空闲、没有草稿、没有附件，且没有在截图、选文件、录音或拖动时生效；点了「固定」也不收起。
- 生成中可以收起，回答在后台继续，小球显示进度环，完成后冒泡提示。
- 收起后草稿与附件保留，下次展开原样还在；只有「新对话」会清空它们。

正式实现：`src/assistant/AssistantApp.vue`、`src/assistant/assistant-store.ts`、`src-tauri/src/float_assistant.rs`。暂未实现（设计稿 P1/P2）：小球右键菜单、贴边吸附、卡片头部的模型名、回答下的「插入到原应用」「存到资料库」、划词唤起。

### 语音（第一期）

- 按住唤起快捷键（≥ 350 ms）说话，松开立即识别并发送；按住期间不按停顿自动发送。短按仍是唤起 / 收起。从小球状态按住时，先展开胶囊再开始录音。
- 朗读跟着回答走：回答一边生成一边按句合成播放，第一句写出来就开始读；朗读期间麦克风保持开启，开口即打断，同时停止朗读和当前生成。
- 句尾静音判停 0.6 秒，识别后合并等待 0.3 秒。唤起时默认等待输入，不自动开麦（可在设置改为「直接开始听」）。
- 底层能力见 [语音引擎方案](voice-engine.md)。

## 悬浮球与输入条的转化：固定舞台

小球、胶囊和卡片同在一个**大小固定的透明窗口（舞台）**里：宽 480、高 600 逻辑像素（屏幕更小时按可用区域缩小，卡片正文最高随之变矮）。透明部分沿用鼠标命中区域穿透到下面的应用。小球与胶囊互相切换时原生窗口**不隐藏、不移动、不改大小**，变化全部在页面里一次画完：

- **展开**：胶囊的毛玻璃底从小球的圆盘长成胶囊，品牌标志的副本同时从小球移到胶囊左侧的语音按钮（44 → 32 px）。两个替身在起点与小球、在终点与真实胶囊完全重合，所以替换看不出来；随后胶囊上的文字与按钮淡入、卡片升起。约 300 ms。
- **收起**：反向播放，卡片先淡出；结束时替身消失、小球在同一帧直接出现（不淡入，否则中间会空一下，看起来像闪烁）。收起后只有胶囊被拖动过时才检查是否需要重新摆放窗口；系统报告的窗口位置差一两个像素不算，避免每次收起都淡出淡入。
- **中途反向**：正在展开时收起（或反之），动画从当前位置掉头，不重来、不排队。
- **兜底**：WebView 在窗口被遮挡时可能暂停动画，形变最迟在应有时长后 250 ms 收尾，不会卡在半途。系统开启“减少动态效果”时直接切换。

舞台的摆放（`stage_for_ball`）：小球占舞台靠屏幕边缘的那个角，胶囊从小球向屏幕内侧展开，胶囊中线与小球中线对齐（差不超过 2 px）；舞台限制在小球所在屏幕的可用区域内，避让 Dock / 任务栏；靠近屏幕顶部时舞台顶到可用区域上沿，小球在舞台里的位置随之上移。舞台始终包含整个小球。没有小球时（快捷键呼出、关闭了悬浮球），舞台底边放在胶囊的默认位置或上次拖到的位置，胶囊淡入淡出；收起后窗口在淡出 220 ms 后才隐藏或移到小球处。

只有以下情况需要移动窗口，此时页面先把小球淡出约 90 ms，窗口移好、页面按新布局画好后再淡入（`reanchor`，宿主最多等 300 ms）：拖动小球松手后舞台需要换方向或换屏幕；胶囊被拖到别处再收起，小球回到胶囊所在处后需要重新摆放；在设置里重置位置。

完成提示画在舞台内、小球朝屏幕中间的一侧，不再临时加宽窗口。

## 鼠标停留展开

鼠标在小球上停住约 280 ms（6 px 内的抖动不算移动）才展开，只是经过不会展开。这样展开的胶囊是“看一眼”：**不抢键盘焦点、不开麦克风、光标不进输入框**；鼠标离开超级小伴所有可见部分 600 ms 后自动收起。在里面点击或按键即转为正常打开（取得焦点），之后按点别处收起的规则处理。拖动小球时、或胶囊刚收起而鼠标仍停在小球上时不会展开，需要鼠标先离开小球。鼠标是否在可见部分上由宿主的命中检测线程告知页面（`assistant-hover`），因为窗口放行鼠标后页面收不到离开事件。设置 → 超级小伴「鼠标停留时展开」可关闭，默认开启；关闭悬浮球时不可用。

实现：`src-tauri/src/float_assistant.rs`（舞台几何、展开与收起）、`float_assistant/reanchor.rs`、`assistant_hit_test.rs`（`assistant-hover`）、`src/assistant/morph.ts`（替身几何、停留判断）、`AssistantApp.vue`。舞台几何、替身对齐、中途反向、停留判断和自动收起都有测试；原生窗口在多屏、Retina、贴边和 macOS 屏幕顶部附近的拖动仍需 Windows / macOS 实机确认。

## 语音开关同步

超级小伴设置页、声音设置页和悬浮助手使用同一个持久化语音识别开关。宿主保存后立即广播 `asr-state`，各窗口同步开启状态与引擎状态。关闭时立即释放麦克风，丢弃尚未完成的识别结果，取消语音自动发送，保留输入草稿；旧下载或加载回调不得把开关重新打开。开启开关只启用语音能力，不因跨窗口广播自动录音；按现有呼出偏好或点击生命球开始聆听。

## 会话延续与选中文字复制

助手记住最后使用的助手会话，关闭、收起、长时间未使用或重新启动应用均不主动新建。会话编号保存在助手窗口自己的本机存储，消息历史仍由宿主管理；完整聊天页另选会话不改变助手使用的会话。记录指向已删除的会话时清除失效指针，下一次提问再创建；列表加载失败时保留记录，提示重试。

点击“新对话”才主动切换：停止旧轮次、停止朗读与录音，创建新的会话并将其设为后续默认，清空旧草稿和附件。卡片标题处可切回最近的其他会话，切换同样停止朗读与录音，但保留草稿。旧会话保留在历史中；创建失败时保留原会话与草稿。恢复历史会话沿用其权限模式，新建会话使用助手既有的完全信任模式。

悬浮助手回复卡片和完整聊天页的消息区支持选中文字后右键打开“复制”，只写入选中部分。无选中文本时不弹出菜单；点击其他位置或按 Esc 收起，复制失败可重试。此自定义菜单不恢复 Reload、Inspect Element 等浏览器菜单，也不影响现有整条回复复制按钮。菜单出现在助手窗口内时参与精确鼠标命中。

## 截图工具视觉：彩虹粉

截图窗口沿用此前彩虹生命球的配色，取消旧版墨绿主题；截图内容本身不应用滤镜，不改变导出的画面颜色。高彩度只用于操作反馈，避免影响用户判断冻结画面。

- 选区外蒙层：中性深梅灰 `#21182680`，清晰区透明；选区边框：彩虹粉 `#F26BAA`，角点保持白色，边缘为粉色。
- 工具栏与调色盘：暖白 `#FFFDFD`；普通按钮中性灰，悬停浅粉 `#FFF0F6`，选中背景 `#FFE4F0`、文字 `#C6337E`。
- 「完成」主要按钮采用较深莓粉 `#CF307B`，确保白字的对比度；焦点轮廓 `#F26BAA`。
- 默认标注色为彩虹粉 `#F26BAA`；调色盘顺序固定为彩虹粉、彩虹黄 `#FFE47A`、天空蓝 `#55BEEB`、白色 `#FFFFFF`、深灰 `#37323B`。用户切换后，后续标注使用选中的颜色。
- 顶部提示、像素尺寸浮层与工具提示保持深色中性背景配浅色文字；不做大面积渐变或霓虹发光。
- 设计稿的模拟桌面仍允许带植物绿色，以测试不同背景上的选区辨识度；真实截图和导出结果不受主题色影响。

## 截图蒙层与选区

用户点击截图后，先隐藏助手并冻结桌面画面，再显示截图编辑窗口。每个显示器显示各自的冻结画面，当前选区限定在单块屏幕内。

- 未框选时整屏压暗，顶部显示框选提示与 Esc / Enter 快捷键说明。
- 拖动任意方向框选；选区内保持画面清晰，外侧使用半透明深色蒙层，边缘使用细亮线。
- 选区左上方显示真实截图像素尺寸，靠近屏幕顶部时移至选区内，避免被裁切。
- 拖动选区移动，拖动四角或四边调整尺寸，选区受屏幕边界约束。
- 工具栏靠近选区下方并右对齐；下方空间不足时向上避让，保证操作按钮可见。

## 截图工具栏

| 操作 | 行为 |
| --- | --- |
| 调整选区 | 移动或调整选区；双击选区完成 |
| 矩形 / 箭头 / 画笔 | 在选区内拖动添加标注 |
| 文字 | 点击选区输入，Enter 确认，Shift+Enter 换行；输入法组词时不触发完成 |
| 马赛克 | 用连续笔刷对冻结画面做像素化遮盖 |
| 撤销 | 撤销最后一条标注，支持 Cmd/Ctrl+Z |
| 重新选择 | 清空选区和标注，重新框选 |
| 取消 | 关闭全部截图窗口，回到助手并保留草稿 |
| 完成 | 合成选区和标注，加入当前对话的待发送附件 |

矩形、箭头、画笔、文字提供颜色和线宽选择；马赛克与选区调整不展示该面板。文字编辑时 Esc 先取消当前文字，其他状态 Esc 取消整次截图。工具栏保持紧凑，颜色面板按需出现。

## 正式实现与演示差异

| 项目 | HTML 设计稿 | 客户端 |
| --- | --- | --- |
| 桌面内容 | Canvas 绘制的模拟桌面 | 用户主动截图时冻结真实桌面 |
| 初始选区 | 预设选区，便于直接审阅工具栏 | 初始不选区，等待用户框选 |
| 系统权限 | 无需权限 | macOS 按需申请屏幕录制权限 |
| 图片输出 | PNG 演示预览 | JPEG，最长边不超过 2048 px，限制 3 MiB |
| 完成后的界面 | 模拟输入框和大图预览 | 回填原助手草稿，不自动发送 |
| 支持环境 | 普通现代桌面浏览器 | 原生截图支持 Windows / macOS |

实现位置：

- `src/capture/`：独立截图场景、样式、选区几何与标注导出。
- `src-tauri/src/assistant_capture.rs`、`assistant_capture_windows.rs`：系统桌面快照与权限处理；Windows 用 GDI/WIC 在进程内截图并编码，不启动 PowerShell；macOS 使用系统截图命令并清理临时文件。
- `src-tauri/src/capture_editor.rs`：截图窗口、会话结果、取消及关闭清理；窗口仅允许截图所需命令。
- `src-tauri/src/float_assistant.rs`：隐藏助手、启动截图、恢复原对话。

截图与助手相关前端测试、类型检查按各次变更针对性运行；鼠标区域另有几何和透明留白拖动回归用例。Windows 原生快照链路已在本机实测，macOS 缺权限时先请求系统授权，失败后打开授权设置，用户返回时自动重试一次；拒绝授权不循环弹窗，切换会话或关闭助手会取消待重试操作。macOS 权限实机、完整选区操作和鼠标穿透仍需对应平台验证。
