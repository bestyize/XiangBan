# 超级小伴悬浮助手与截图工具设计规范

更新日期：2026-10-20。此规范适用于“超级小伴（小伴语音助手）”，其设置入口进入超级小伴专属设置页。

## 设计参考

- [悬浮按钮交互稿](prototypes/assistant-floating-tools.html)：采用最终确认的横排工具形态。
- [截图工具交互稿](prototypes/assistant-capture-overlay.html)：定义截图蒙层、选区和标注工具栏。

HTML 是可交互的视觉与行为参考，使用模拟桌面和对话。正式界面由 Vue/TypeScript 与 Tauri 实现，不在运行时加载这些文件。

## 月白 / 夜银与彩虹生命球

最终视觉参考：[对话框与停止按钮](prototypes/assistant-conversation.html)、[生命球配色与动效](prototypes/assistant-living-orb.html)。原横排工具稿保留入口行为参考，当前配色和生命球以这两份新稿为准。外观沿用应用的跟随系统 / 浅色 / 深色设置。

- 月白：回复面 `#FFFFFF`，输入面 `#FEFFFF → #F3F6F9 → #EAF0F5`，文字 `#414851`，细银灰边缘与轻阴影。
- 夜银：中性深灰回复面 `#292C31`，输入面 `#3E4147 → #35383E → #2F3238`，文字 `#DFE3E9`；避免原蓝紫底色。
- 生命球统一使用高饱和彩虹：金黄 `#FFE47A`、玫粉 `#F26BAA`、天蓝 `#55BEEB`、翡翠绿 `#43D6A2`，以浅紫 `#AF8DE2` 衔接。颜色在球内柔和交融，无人脸、无向外扩散的光晕和圆环。
- 输入框球体约 29 px，收起球体约 32 px。收起时固定使用待机 UI，不随后台会话的思考、回答或朗读切换动效；保留点击展开和拖动。
- 输入区域聚焦只显示文字光标，不出现矩形焦点框；工具按钮保留键盘焦点提示。输入框高度 64 px。

| 状态 | 动效与行为 |
| --- | --- |
| 待机 / 等待确认 | 5 秒轻呼吸，球内缓慢流动 |
| 聆听 | 1.35 秒明显呼吸，缩放 0.88～1.08 |
| 思考 | 2.5 秒旋转，内部色彩加快流动 |
| 文字回答 / 语音播放 | 同一套 3 秒形变，横向约 0.909～1.084，纵向约 0.916～1.098 |

思考、流式文字生成、语音合成及播放期间，右侧主按钮为小实心方块，提示“停止回复”。浅色停止按钮使用 `#E6EBEF / #778491`，深色使用 `#484E56 / #B1BBC7`，避免黑白强反差。点击同时停止当前生成和朗读，清理语音自动发送与自动续听，保留已生成的回复及下一句草稿；收到延迟完成回调也不重新朗读。取消生成的状态随宿主取消事件确认，语音状态立即退出。无任务时有草稿显示发送，否则显示加号。

正式生命球改用 CSS 动效，暂停显示时停止动画，遵循系统“减少动态效果”。HTML 的模型文字和语音播放仍为模拟，正式客户端接入真实生成和 TTS；Windows/macOS 显示效果需实机确认。

## 悬浮输入框与横排工具

上方回复卡片与下方输入框分离，输入框左侧保留生命球。右侧仅保留一个主按钮：有可发送内容时发送，任务进行时停止，空闲时展开工具；悬停仍可打开工具列表。工具层紧贴输入框右侧的主按钮上方，呈横排展示。

从左到右的顺序固定为：

| 顺序 | 操作 | 行为 |
| --- | --- | --- |
| 1 | 去超级小伴设置页 | 打开语音助手专属设置 |
| 2 | 收起小伴 | 收起胶囊，按偏好回到悬浮球或隐藏 |
| 3 | 新会话 | 停止旧轮次与朗读，开启并记住新的助手会话 |
| 4 | 去聊天详情页 | 将当前会话带入完整聊天页，采用对话气泡图标 |
| 5 | 选择图片 | 打开本地图片选择器，加入待发送附件 |
| 6 | 截图 | 进入独立截图流程，采用区域截取图标 |

交互要求：

- 鼠标悬停约 220 ms 展开，移出约 400 ms 收起，允许穿过按钮与浮层之间的间隙。
- 点击主按钮或通过键盘也可进入工具列表；提供焦点样式、图标说明和可访问名称，Esc 关闭已展开工具。
- 浮层展示与隐藏不改变输入框及其原生窗口的布局尺寸，避免抖动；原生窗口预留工具层空间。
- 预留空间不参与拖动或鼠标命中。只保留可见输入框、回复卡片、悬浮球和工具栏及其约 4 px 边缘余量；圆角外侧、顶部大块透明留白和卡片间隙穿透到底下的应用，即使助手已获取输入焦点也一样。
- 工具栏展开时仅增加工具栏本身和通向右侧主按钮的狭窄连接区域。输入框空白边缘与生命球可拖动；文字、输入框和按钮保持原本操作，助手内开始拖动或选字后，按住期间不切出助手的鼠标区域；从外部拖图进入可见输入框仍可接收。
- 图片选择、截图取消不清空原有输入和附件；图片添加后由用户主动发送。
- 思考、流式回答时停止按钮始终可点，包括发送请求尚未返回和服务器尚未返回首个响应头的阶段；停止只取消当前轮次，保留对话与下一句草稿。网络传输等待期间也必须检查取消信号。
- 上方回复的关闭按钮仅隐藏回复卡片；收起助手通过横排工具中的“收起小伴”执行。

正式实现：`src/assistant/AssistantApp.vue`、`src/assistant/assistant-store.ts`、`src-tauri/src/float_assistant.rs`。

## 语音开关同步

超级小伴设置页、声音设置页和悬浮助手使用同一个持久化语音识别开关。宿主保存后立即广播 `asr-state`，各窗口同步开启状态与引擎状态。关闭时立即释放麦克风，丢弃尚未完成的识别结果，取消语音自动发送，保留输入草稿；旧下载或加载回调不得把开关重新打开。开启开关只启用语音能力，不因跨窗口广播自动录音；按现有呼出偏好或点击生命球开始聆听。

## 会话延续与选中文字复制

助手记住最后使用的助手会话，关闭、收起、长时间未使用或重新启动应用均不主动新建。会话编号保存在助手窗口自己的本机存储，消息历史仍由宿主管理；完整聊天页另选会话不改变助手使用的会话。记录指向已删除的会话时清除失效指针，下一次提问再创建；列表加载失败时保留记录，提示重试。

点击“新会话”才主动切换：停止旧轮次、停止朗读与录音，创建新的会话并将其设为后续默认，清空旧草稿和附件。旧会话保留在历史中；创建失败时保留原会话与草稿。恢复历史会话沿用其权限模式，新建会话使用助手既有的完全信任模式。

悬浮助手回复卡片和完整聊天页的消息区支持选中文字后右键打开“复制”，只写入选中部分。无选中文本时不弹出菜单；点击其他位置或按 Esc 收起，复制失败可重试。此自定义菜单不恢复 Reload、Inspect Element 等浏览器菜单，也不影响现有整条回复复制按钮。菜单出现在助手窗口内时参与精确鼠标命中。

## 截图蒙层与选区

用户点击截图后，先隐藏助手并冻结桌面画面，再显示截图编辑窗口。每个显示器显示各自的冻结画面，当前选区限定在单块屏幕内。

- 未框选时整屏压暗，顶部显示框选提示与 Esc / Enter 快捷键说明。
- 拖动任意方向框选；选区内保持画面清晰，外侧使用半透明深色蒙层，边缘使用细亮线。
- 选区左上方显示真实截图像素尺寸，靠近屏幕顶部时移至选区内，避免被裁切。
- 拖动选区移动，拖动四角或四边调整尺寸，选区受屏幕边界约束。
- 工具栏靠近选区下方并右对齐；下方空间不足时向上避让，保证操作按钮可见。

## 截图工具栏

| 操作 | 行为 |
| --- | --- |
| 调整选区 | 移动或调整选区；双击选区完成 |
| 矩形 / 箭头 / 画笔 | 在选区内拖动添加标注 |
| 文字 | 点击选区输入，Enter 确认，Shift+Enter 换行；输入法组词时不触发完成 |
| 马赛克 | 用连续笔刷对冻结画面做像素化遮盖 |
| 撤销 | 撤销最后一条标注，支持 Cmd/Ctrl+Z |
| 重新选择 | 清空选区和标注，重新框选 |
| 取消 | 关闭全部截图窗口，回到助手并保留草稿 |
| 完成 | 合成选区和标注，加入当前对话的待发送附件 |

矩形、箭头、画笔、文字提供颜色和线宽选择；马赛克与选区调整不展示该面板。文字编辑时 Esc 先取消当前文字，其他状态 Esc 取消整次截图。工具栏保持紧凑，颜色面板按需出现。

## 正式实现与演示差异

| 项目 | HTML 设计稿 | 客户端 |
| --- | --- | --- |
| 桌面内容 | Canvas 绘制的模拟桌面 | 用户主动截图时冻结真实桌面 |
| 初始选区 | 预设选区，便于直接审阅工具栏 | 初始不选区，等待用户框选 |
| 系统权限 | 无需权限 | macOS 按需申请屏幕录制权限 |
| 图片输出 | PNG 演示预览 | JPEG，最长边不超过 2048 px，限制 3 MiB |
| 完成后的界面 | 模拟输入框和大图预览 | 回填原助手草稿，不自动发送 |
| 支持环境 | 普通现代桌面浏览器 | 原生截图支持 Windows / macOS |

实现位置：

- `src/capture/`：独立截图场景、样式、选区几何与标注导出。
- `src-tauri/src/assistant_capture.rs`、`assistant_capture_windows.ps1`：系统桌面快照、权限与临时文件处理。
- `src-tauri/src/capture_editor.rs`：截图窗口、会话结果、取消及关闭清理；窗口仅允许截图所需命令。
- `src-tauri/src/float_assistant.rs`：隐藏助手、启动截图、恢复原对话。

截图与助手相关前端测试、类型检查按各次变更针对性运行；鼠标区域另有几何和透明留白拖动回归用例。Windows/macOS 原生截图及鼠标穿透仍需实机验证，此记录不代表完成原生构建验收。
