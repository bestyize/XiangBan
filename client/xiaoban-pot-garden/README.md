# 表情盆栽（xiaoban-pot-garden）

小伴"表情盆栽"的 3D 质感原型，也是后续花盆养成游戏的起点：一个白瓷花盆，盆身正中嵌着会发光表情的圆角屏幕，盆里长出一株两叶的幼苗，叶子随表情舒展或耷拉。

当前只做质感和表情，**没有养成玩法**（没有浇水、成长、存档）。

## 状态

- 可运行原型：Vite + TypeScript + three.js，没有任何外部模型或图片，花盆、泥土、叶片、叶脉纹理都由代码生成。
- 8 种表情：平静、开心、兴奋、困倦、难过、惊讶、好奇、喜欢。每种表情同时决定屏幕上的脸、两片叶子的角度和卷边、花盆的跳动与倾斜，开心类表情旁边会出现橙色的小火花线。
- 交互：鼠标移动时脸和茎会轻轻看向指针；点击画面会短暂变成开心（已经开心则变兴奋）。尊重系统的"减少动态效果"设置。
- 只在 macOS 上用 Chrome 的软件渲染（SwiftShader）看过画面。没有测过真机 GPU 的帧率和功耗，没有测过 Windows，也没有测过移动端浏览器。

## 运行

```sh
npm --prefix client/xiaoban-pot-garden ci
npm --prefix client/xiaoban-pot-garden run dev     # http://127.0.0.1:1430
npm --prefix client/xiaoban-pot-garden test
npm --prefix client/xiaoban-pot-garden run build
```

页面底部有表情按钮。地址参数：`?clean` 隐藏按钮；`?expr=happy` 选择表情；`?t=1.4` 把动画时钟固定在某一刻，用于截图对比。

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `src/pot.ts` | 花盆本体（超椭圆截面逐层放样，烘焙了盆沿下和盆底的环境遮蔽）、泥土、颗粒和小石子、贴合盆壁弧度的边框与玻璃屏幕 |
| `src/leaf.ts` | 叶片曲面：卵形轮廓、中脉弯曲、折角、边缘卷起翻过叶面、波纹。可逐帧原地更新 |
| `src/leaf-texture.ts` | 叶面、叶背和凹凸纹理（画布生成，叶脉向叶尖汇聚） |
| `src/plant.ts` | 茎（逐渐变细的管）、叶柄、两片叶子、随姿势摆动 |
| `src/poses.ts` | 每种表情对应的叶子、花盆姿势，姿势之间的混合 |
| `src/face.ts` | 画在屏幕上的脸（发光描边），作为发光贴图 |
| `src/character.ts` | 把以上组合成角色：表情状态、眨眼、视线、火花、逐帧更新 |
| `src/scene.ts` | 渲染器、相机（长焦、略俯视）、灯光、棚拍环境反射、地面软阴影 |
| `src/main.ts` | 页面、按钮、指针和动画循环 |

## 与其他项目的关系

- 独立项目，不引用 `client/xiaoban-desktop-wallpaper` 的源码（`tools/check-layout.py` 禁止客户端之间互相导入）。桌面宠物的表情系统是 SVG 机器人脸，这里的脸是另外画在画布上的，两边的 25 种表情并不一一对应，目前只有 8 种。
- 以后可以按网页游戏包的约定（manifest、版本 1 消息格式、存档上限）打包后放进桌面的游戏空间，或做成桌面组件。这一步还没有做，也没有核对过协议细节。

## 和参考图的差距

画面是按一张 3D 渲染图（白瓷花盆、屏幕脸、两叶幼苗）做的，构图、盆沿、泥土颗粒、叶片光泽和卷边都已接近，但不是同一张图：

- 质感是实时渲染的物理材质，没有离线渲染的次表面散射（叶片透光）、细腻的陶瓷釉面和泥土颗粒细节。
- 两片叶子用同一套曲面生成，形状相近但不是手雕；叶子只能整片摆动和卷边，不会像参考图那样自由折叠。
- 阴影用的是 VSM 软阴影，边缘偏软，没有环境光遮蔽（只在盆身上烘焙了近似遮蔽）。

想要完全一致，需要建模师在 Blender 里做 glTF 模型，用本项目的灯光和表情屏替换现有几何体。
