# 口袋精灵：初芽庭院

手机竖屏三消，设计基准 375 × 800 dp。用户选择 A「口袋精灵」方向；[原始概念稿](concept-a.png)保留作美术参照，不是运行界面截图。

源代码与正式素材：[资源基准包](../../../../../assets/game-packs/pocket-sprites/README.md)。本机预览：仓库根执行 `python tools/preview-pocket-sprites.py`，打开 [可玩预览](http://127.0.0.1:1473/assets/game-packs/pocket-sprites/index.html)。后续沿用此链接。

## 美术与布局

深青庭院、青瓷棋盘、温润软陶角色。六种棋子依次为珊瑚红团团雀、蜜黄星角兽、薄荷绿芽芽团、蓝色水母啵、紫色耳耳狐、奶白云绵羊。颜色与剪影双重区分，表情只作点缀。

`assets/sprites.png` 是 1536 × 1024 的 3 列 2 行透明图集，每格 512 × 512；禁止当作无透明背景的照片显示。角色色号从左到右、从上到下为 0～5。背景、图标、封面均为生成的独立 PNG，不依赖在线图片。

8 × 8 是最大逻辑网格，空缺位置不绘制格子；小棋盘在网格内居中。保留宿主安全区与胶囊避让，运行页不另加退出按钮。面板主控件至少 44 px。正常交换、无效回弹、清除和下落分阶段反馈，减少动态模式应缩短动画。

## 第一章规则

每次有效交换扣一步；自动连锁不扣步。四连生成直线精灵，T/L 五连生成范围精灵，直线五连生成虹彩精灵。特殊状态不改变角色身份。冰在底层，上方被消除或特效命中时减层，归零才计为一格完成；蜂蜜占格，相邻消除或特效命中时受击，每波只受击一次。空缺分隔的垂直段独立补充。死局自动重排，不移动障碍。

每关结构固定，普通棋子随机；教学关固定合法开局。4～6 种精灵同盘，第 5 关引入狐狸，第 11 关引入云羊，第 18 关首次六种同场。目标与步数属于初调值，自动模拟不等于真实玩家通关率。

## 美术来源与提示词

使用内置 imagegen 生成，未使用外部 API/CLI。提示词核心：原创软陶精灵，温润体积与柔和左上光，轮廓在 42 dp 下清晰；图集精确 3×2 排列，透明背景，六角色顺序固定，无外部光晕；背景为深青微缩庭院，中央安静，花草灯笼限于边缘；图标为红鸟特写；封面为六伙伴围绕棋盘。

生成输出保存进资源包，桌面副本同步分发；此处只保留已选方案的原始概念图。关卡开发按 1–3、4–6、7–9、10–12、13–15、16–18、19–20 分批。

## 首版实现与验收

20 关已实现；[第 20 关实际浏览器截图](implemented-level-20.png)。原始概念图与实现截图分开保留。运行页提供提示一步，尚未制作概念稿中的三种消耗道具。

规则测试、20 关结构/教学检查、每关 12 个固定种子的策略试玩通过；策略达成率不能视作玩家通关率，第 18 关仍需重点试玩调平衡。Edge 验证 375 × 800 全部棋盘、320 × 568 触摸滑动、胜败重试与下一关，以及存档、历史返回和模拟宿主生命周期。资源目录校验、桌面前端构建和 Android `syncMobileGameAssets` 通过。尚未构建 APK 安装到手机验收。

### 1.1 真机反馈调整

按反馈将步数预算减半向上取整；64 种子策略检查每关均有通关样本。增加棋子轻摆、选中蓄势、交换挤压、错峰落地回弹、目标飞入和不同特殊组合光效。五连使用独立透明虹彩鸟资产。新增约 70 秒原创合成循环音乐，支持总静音和独立音乐开关；首次手势加载、暂停/后台挂起、单音乐源检查通过。

修复 Android 原生状态栏遮罩导致的顶部白条，游戏就绪后使用透明系统栏和浅色图标；仍保留真实安全区。1.1 调试包已覆盖安装至小米 17，真机看到完整深青背景、新预算与能量精灵；浏览器验证常规/减少动态、背景乐解码和暂停恢复。真机主观音质与手感由用户继续体验。

### 1.2 目标驱动难度

根据后续反馈，取消 1.1 的步数减半：20 关统一保持 20～30 步，每关设计不同精灵收集种类及数量，部分关卡组合冰层/蜂蜜目标。最多三个目标，窄屏可换行。32 种子验证每关均有达成目标的局；具体数值见资源包 `levels.mjs`，后续按实际游玩反馈调目标，不再以持续缩减步数提高难度。

### 1.3 局部避让与棋盘面积

用户提供开心消消乐手机截图作为布局和方向动效参考。运行页改为紧凑顶部信息，标题在真实宿主胶囊左侧使用空闲区域；暂停移到底部，仅系统安全区全宽预留。棋盘薄边框、减小左右外边距，长方盘取消按行列比缩窄，按宽度/可用高度限制取较大可用正方格。底部工具贴近手指区域，棋盘在 HUD 与底部工具之间居中，长屏不拉伸格子。保留原创精灵与美术素材。

[1.3 局部避让布局截图](layout-1.3.png)（375×800，模拟真实安全区与右上 48×48 宿主控件）。横向采用暖金、纵向采用青绿双向箭头与拖尾，命中闪光按距离依次触发；不复用参考游戏的角色或图像素材。

### 1.4 独立高能造型

横翼（宽而扁）、纵羽（窄而长）、爆花（放射状圆形）采用新透明图集，虹彩鸟保留彩冠鸟形。高能角色不再以普通棋子加光带为主；小型原精灵标记用于表示仍可参与匹配的颜色。图集位于资源包 `assets/power-sprites.png`，2172×724，3 格等宽，使用内置 imagegen 生成。

关卡支持 8×8 / 9×9，固定教学开局保持原状，多数其他关卡扩充行列；棋子尺寸按九列密度上限控制，较小教学盘居中展示，避免把精灵越放越大。

[9×9 棋盘实现截图](board-9x9.png)。14 关扩盘后保留原目标、颜色、步数与障碍数量；32 种子检查每关均有通关样本。专项检查覆盖 9 列边界、末行末列特效、分段掉落、8/9 尺寸切换及存档恢复，浏览器已验证实际 81 格存档及切回 8 格教学。
