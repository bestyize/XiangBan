# 小伴手机 App 设计稿

| 设计稿 | 内容与预览 |
| --- | --- |
| [遥控器](prototypes/universal-remote.html) | 小伴协议 2 的竖屏工具设计稿。电视和空调面板按小米参考图使用浅灰底和白色按键。电视采用四点方向盘、双段音量和独立返回键，空调采用大字温度、风速和风向状态与四行全宽按键。可点按设备类型、搜索品牌、试码换码、保存以及电视和空调控制，含深浅色、空列表和无红外预览。首页「添加」与标题同行靠右，使用 28px 高的白底、黑字和轻阴影。已保存的遥控器可点卡片右上角的铅笔修改备注名。子页标题为 16px，与两侧的返回箭头、竖三点同高，可逐页返回，保存后从遥控面板返回列表。品牌、匹配和红外发射均为演示。品牌选择列出 19 个电视品牌和 21 个空调品牌，按 2026 年 9 月中国市场的公开份额排序，电视按整机出货、空调按全渠道零售额，其余单列。默认使用无底色的竖三点宿主按钮，图标靠近右上角并带轻微阴影，触控区 48 × 48px，点击打开按 Android 宿主样式绘制的底部菜单，包含应用信息、重新开始、收藏、分享和退出，可切回旧版双按钮对照。[在线预览（本机）](http://127.0.0.1:1421/prototypes/universal-remote.html) |
| [万磁搜](prototypes/torrent-search.html) | 协议 2 独立应用包的竖屏搜索界面；展示首屏、搜索结果、无结果、服务失败及磁力操作弹层；视觉参考 search.xiangban.xyz。使用 TorrentSpiderRust API 字段作示例，按钮仅模拟交互，未接入正式服务。手机画板使用通用竖三点宿主样式。[在线预览（本机）](http://127.0.0.1:1421/prototypes/torrent-search.html) |
| [开源精选详情页](prototypes/open-source-detail.html) | 独立图文详情原型：顶部项目卡片（含 Star 数与更新日期）、默认中文 README / English 语言切换、上游英文正文与中文译文、官方配图、目录及安装命令复制、图片放大、收藏、点赞、小红书风格评论与回复、贴边互动栏、分享、深浅色与手机 / 桌面预览。正文使用 Excalidraw 采编样稿；仅原型交互，未接生产接口。[在线预览（本机）](http://127.0.0.1:1423/prototypes/open-source-detail.html) |
| [应用广场](prototypes/app-plaza.html) | 底栏「创造」改为「应用」：广场（最近用过、每期小伴选、官方游戏、精选工具、创作者精选、社区作品瀑布流）与我的作品；精选游戏方形封面完整显示，来源和横竖屏信息在封面下方，广场与「全部」页共用卡片；创作者精选并入社区作品「推荐」的帖子卡，万磁搜示例同时展示在精选工具和社区作品；MBTI 支持 16 型主题与角色切换，提供提交后的分析过渡、六章完整报告、可展开图表、工作情境表格、一周行动与 16 人格原创角色图鉴；3:4 精简分享卡含测试日期，可切换纸色、显隐维度并导出 PNG，补充图片/链接分享到朋友圈的交互示意，内容为示例数据；社区作品就是普通帖子（帖子页带评论、点赞、收藏、做一个我的版本），官方游戏和工具轻点直接打开，长按显示详情弹层；启动过渡、竖屏 / 横屏全屏运行，右上角通用竖三点宿主菜单（48 × 48 px 触控区），返回一次展开菜单、再次退出，可显示安全区；小伴AI 首页下拉打开最近用过和收藏、问候语推荐、对话里递上应用卡片。配色、底栏、字号按 `docs/product/手机端设计规范.md`；仅原型交互，未接接口。预览：`python3 -m http.server 1424 --bind 127.0.0.1 --directory client/xiaoban-multiplatform/docs/design-specs`，打开 [本机链接](http://127.0.0.1:1424/prototypes/app-plaza.html)。 |
| [创造中心](prototypes/create-center.html) | 统一游戏、动画壁纸、小组件、特效、伙伴的手机入口；发现 / 我的作品 / 作品预览三画面，我的作品支持二次确认删除；卡片点击展开底部操作面板：预览 / 游玩、继续修改、发送到电脑、分享到社区及其他渠道；发现页保留创作提示入口，我的作品页保留右上角新建；支持分类、创作输入、360 / 390px 与明暗模式。发现页游戏优先；已接入 Android，桌面装扮走电脑创作，直传暂用系统分享作品包。[在线预览](http://127.0.0.1:1421/prototypes/create-center.html) |
| [游戏中心 A / B](prototypes/game-center.html) | A 轻量游戏库与 B 沉浸游乐场并排比较；390 / 360px、明暗模式、玩法筛选、我的游戏 / 空状态、游戏详情、创作与启动过渡。[在线预览](http://127.0.0.1:1421/prototypes/game-center.html) |
| [社区与小伴 AI 原型](mobile-prototype/README.md) | 现有多画板设计与在线画布说明。 |
