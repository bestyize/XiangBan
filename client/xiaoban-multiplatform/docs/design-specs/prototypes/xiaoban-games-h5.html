game.xiaban.xyz 移动端设计决策速览

1. 少而精的「卡带展厅」定位

小伴现役 8+1 款均为高完成度原创作品，拒绝传统小游戏站杂乱广告位。纯中性画布（浅 #FAFAFA / 深 #111111）把视觉焦点留给每款游戏的真实图标与 16:9 封面。

2. 「单手竖屏」与「横屏沉浸」显式分流

筛选栏特设「单手竖屏」满足通勤单手即玩（倒杯快乐、方块爆破、2048）；6 款横屏游戏配备旋转动效引导层 + 横屏右侧窄宿主抽屉，彻底解决 iOS/微信锁横屏限制。

3. 零登录秒开 + 本机续玩留存

香港 Nginx 纯静态托管，全部 8+1 款游戏合计仅 ~4 MB。通过前端 Web xb.storage 桥接 localStorage，首屏顶部浮现「继续上次」，无须登录即可沉淀进度与最高分。

单游戏直达路由 /#/play/:id 支持微信强传播；战绩页底部温和互导姐妹站「人格贩卖机」与小伴客户端下载，同属 xiaban.xyz 轻量静态阵营。
