小伴手机 App · 模型配置全链路 重设计稿

90% 中性黑白灰控色 · 协议独立选择自动切换预置端点 · 自定义思考等级多选 BottomSheet · 模型列表左对齐

01 · 模型配置主页

零浅色/次主题色底块：「小伴 AI」官方图标保留实心主题色底配白色星标，「兑换点数」用无底色主题色文字链接；其余回归黑白灰层级（中性「使用」胶囊、第三方灰图标与「+ 添加」），仅以 6px 绿点轻标「使用中」。

02 · 小伴 AI 官方配置

精简余额区与一体化圆角兑换输入条（有输入时「兑换」亮实心主题色白字，零浅粉底）；默认模型列表彻底去掉每行右侧笨重方盒，思考强度独立为当前选中模型的圆润分段滑块，一键直切无需二次弹窗。

03 · 添加第三方服务

补齐服务商中性图标与完整「自定义模型服务」入口；目录拉取失败用底部轻量化琥珀条原地重试，不再把巨型灰按钮插进列表中间。

04 · 第三方服务商配置

协议改为独立选择行（点开底部弹层展示完整协议与端点路径，切换后自动更新对应预置 API 地址）；高级设置新增「支持的思考等级」底部多选弹层（默认勾选 低 / 中 / 高 / 极高 / 最高）。

05 · 选择对话模型 + 思考等级

修复 Auto 左侧多余留白：模型名严格左对齐；思考强度触发器去掉模糊大脑图标与厚重灰方盒，改用「3 格动态强度阶梯条 + 档位字」（未选中行无底轻文字、选中行纯白细描边圆胶囊），点击弹出贴底 BottomSheet。

本轮细化与结构修正

01 · 主页零浅色底块

撤掉所有浅红/浅黄/浅绿次主题色底块：仅「小伴 AI」保留实心主题色底 + 白色星标，「兑换点数」改用无底色主题色文字链接，其余全部黑白灰层级，以无底 6px 绿点标示「使用中」。

02 · 官方配置重构

额度与兑换码收为一体化圆角输入条（输入后「兑换」变为实心主题色白字）；模型行彻底去杂，思考强度抽成独立圆润分段滑块，随当前选中模型实时切换档位。

04 · 协议独立选择 + 联动地址

取消窄小三列并排协议条，改用清晰单行选择器 + 底部协议弹层；切 Chat / Responses / Anthropic 时自动切到对应预置地址并预览完整端点。

04 · 自定义思考等级多选

高级设置内新增「支持的思考等级」，点击弹出底部多选 BottomSheet，默认勾选「低 / 中 / 高 / 极高 / 最高」五档，由用户自由增删。

05 · 消除 Auto 左侧空档

移除左侧占位勾选槽，所有模型名与分组标题一条直线左对齐；选中对号统一放在最右侧，视觉干净利落。

05 · 轻量化思考强度按钮

放弃糊掉的大脑图标与厚重灰方盒，改用「3 格动态强度阶梯条 + 档位」：未选中行透明轻态不抢戏，选中行升级为白底细描边圆胶囊，点开贴底 BottomSheet 五档统一切换。
