90% 中性黑白灰控色 · 协议独立选择自动切换预置端点 · 自定义思考等级多选 BottomSheet · 模型列表左对齐

01 · 模型配置主页

消灭满屏红粉：第三方图标与添加入口全回归中性灰黑；「使用中」改用冷静绿点；「0 点」用克制琥珀胶囊并点整行直达兑换。

02 · 小伴 AI 官方配置

官方模型列表补齐右侧「思考等级」胶囊，点选即弹出底部 BottomSheet 切换思考档位；列表齐左无空档，去掉底部实心大红「完成」键。

03 · 添加第三方服务

补齐服务商中性图标与完整「自定义模型服务」入口；目录拉取失败用底部轻量化琥珀条原地重试，不再把巨型灰按钮插进列表中间。

04 · 第三方服务商配置

协议改为独立选择行（点开底部弹层展示完整协议与端点路径，切换后自动更新对应预置 API 地址）；高级设置新增「支持的思考等级」底部多选弹层（默认勾选 低 / 中 / 高 / 极高 / 最高）。

05 · 选择对话模型 + 思考等级

修复 Auto 左侧多余留白：全部模型名与分组标题严格左对齐，对号统一放最右侧；点击右侧中性思考胶囊弹出贴底 BottomSheet（告别悬浮白框遮挡）。

04 · 自定义思考等级多选

05 · 消除 Auto 左侧空档

移除左侧占位勾选槽，所有模型名与分组标题一条直线左对齐；选中对号统一放在最右侧，视觉干净利落。

05 · 统一贴底 BottomSheet

思考等级统一改用贴底 BottomSheet（替代悬浮白弹窗与行内缩进条），五档选项行高一致，彻底告别遮挡与视觉割裂。
