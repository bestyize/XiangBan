发帖页 · 手机端 & 网页版 UI 设计稿

写作优先层级 · 消灭白底隐身胶囊与输入框硬边框 · 统一附件/作品/投票卡片 · 支持双端明暗与 6 套主题色

真实板块来源与设计对照： 板块清单同步自 services/server-forum/editorial/channels.json、communityStructure.ts、postingStructure.ts 与 ForumCategories.kt（一级栏目：创意 / 讨论 / 资源）。 手机端（对应 ComposeScreens.kt / ForumUploadControls.kt / ForumCoverEditor.kt）：① 创意含 14 项细分板块、讨论含 16 项、资源含 2 项（默认、影视），采用「一级分段槽 + 3 列紧凑网格 + 底部规则说明」收纳；② 去除顶栏底线，禁用「发布」改用浅灰底配次要文字；③ 用单行元信息条替代堆叠 OutlinedTextField，话题胶囊收进正文下方；④ 统一「作品」为每帖限 1 个可运行 V2 作品（支持上传 V2 ZIP、上传 .html/.htm 自动转为 V2 容器，或关联我的创作，并与普通可下载附件卡片区隔），底栏收紧为固定 48px 单行图标条；⑤ 投票芯片置于 --fill 卡片内避免白底隐身。
网页版（对应 TopicComposer.vue / MarkdownEditor.vue）：① 按 postingStructure.ts 规则展示真实板块（创意「默认」、讨论 16 项含「设计 / 3D」自动附带必选话题、资源 2 项）；② 级联板块菜单采用左栏分节 + 右侧 3 列网格与规则条；③ 精简编辑器工具条并接入双标签「添加作品」弹窗/H5 抽屉（统一 .zip V2 / .html/.htm 自动转 V2 / 我的创作），H5 窄屏接入真实底部板块选择面板与 16px 防缩放字号。
双端现状差异备注：当前线上代码中，网页端创意发帖只开放「默认」、讨论已隐藏 6 个旧休闲子栏并加入「设计 / 3D」话题虚拟板块，且新传作品包目前在「分享已有作品」弹窗（PackPublishDialog.vue）单独发起；本设计稿在发帖页内把「上传 V2 ZIP / HTML·HTM 转 V2 / 关联创作」合入同一单选「作品」入口，手机端 ForumCategories.kt 板块差异亦保留真实对照，后续落地代码时按此统一。
