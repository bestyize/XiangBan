小伴手机 App · 「我的」页定稿 + 个人主页设计稿

统一通栏精修语言（方案 1） · 「我的」直达个人主页 · 覆盖本人视角与社区他人视角

01 · 「我的」页 方案 1 定稿

通栏白底一体化顶区（齿轮设置 + 极简头像名片 + 收藏/作品/通知三宫格），移除重复的「创作」「关注与粉丝」「屏蔽的用户」及外露积分，下方仅留 2 组 4 项核心入口。

02 · 个人主页 · 本人视角

从「我的 → 主页 ›」进入：极简名片（头像 + 昵称 + ID 一键复制 + 换头像）、四列等宽数据条（可点选直达对应 Tab）、吸顶「帖子 / 关注 / 粉丝」三栏，承接全部社交关系。

03 · 个人主页 · 他人视角

社区点击任意作者头像进入：头部只放单个克制的「关注 / 已关注」药丸，把「屏蔽该用户」收入右上角「···」底部菜单，页面干净不具攻击性。

「我的」与「个人主页」联动设计要点（画板内所有 Tab、按钮、头像与「···」菜单均可真实点击）

1. 「我的」极致精简

采用方案 1 通栏白底：名片区只留头像、昵称、可复制 ID 与「主页 ›」，不再外露积分；快捷三宫格收敛为 我的收藏 / 我的作品 / 通知。

2. 列表去重，仅留 2 组

去掉「屏蔽的用户」、重复的「创作」及已归入主页的「关注与粉丝」，列表仅留 模型配置 / 我的设备 与 帮助与反馈 / 交流群 两组 4 行。

3. 个人主页承接社交

展示 68px 头像与四列等宽 帖子 / 回复 / 关注 / 粉丝 指标；帖子升级为左文右图/纯文混排阅读卡，关注/粉丝补齐 40px 头像与快捷关注。

4. 弱化屏蔽 · 突出关注

他人主页头部只留「关注」浅品牌色药丸；屏蔽入口收进右上角「···」弹层，屏蔽后展示轻提示条并支持一键取消屏蔽。
