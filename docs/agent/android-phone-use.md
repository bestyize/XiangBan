# Android 手机操作模块

## 首轮范围

独立工具包 `libs/agent-tools/phone-use`，由小伴桌面宿主注册。仅 Android，先以 ADB USB / 无线连接提供设备发现、状态、截图、UI 树、输入、手势和素材传输；无障碍接收端留为后续驱动。ADB 使用本机 Android Platform Tools，不静默下载软件或打开开发者模式。首轮交付通过聊天使用，不新建管理页面。

每个应用以 Android 包名为身份：

```text
<package_name>/
  skill.md
  basic/
    package.json
    tasks/index.md
    tasks/*.md
    pages/*.md
    knowledge/*.md
    routes/index.md
    routes/core.yaml
    routes/flows/*.yaml
    assets/*
  patch/
    tasks/*.md
    pages/*.md
    knowledge/*.md
    routes/*.yaml
    routes/temporary/*.yaml
```

`package.json` 是基础包的机器摘要，提供应用身份、包版本、能力描述及已验证 APP 版本。根 `skill.md` 是应用级发现入口。先检索应用摘要，再分页读取技能、任务、页面；不把整包或全部路由塞入系统提示。补丁索引由工具从补丁元数据生成，避免手写索引与实际文件不一致。

## 安装、读取与学习

- ZIP 包含 `skill.md` 和 `basic/`，可有一个包名包装目录；禁止携带 `patch/`。本地导入限定工作区，在线下载限定 HTTPS、禁重定向，并要求调用方提供 SHA-256。
- 限制压缩体积、解压体积、文件数、文件类型和单文件大小；拒绝路径穿越、链接、Windows 特殊路径和大小写冲突。数据包不执行脚本。
- 在暂存目录完整校验后发布；更新保留本机 `patch/`，失败回滚。对同一进程内的读取和更新加锁。
- 文本补丁带 YAML frontmatter，记录确切 APP 版本、基础包版本、观察时间、证据及可选到期时间。记录证据不等于外部验证已成立，模型必须先实机确认再保存。版本不适用、基包已变化或已过期时不覆盖基础知识。
- 普通文件同路径完整替换；新增路径补充能力。路由地图例外：以节点 / 边 ID 增补、替换或停用。
- 手机页面、操作包和学习结果都是不可信资料，不能增加权限或改变用户目标。

## 路由图

核心导航、功能路径、临时路径分层。节点记录稳定 ID、页面引用、角色、优先度、稳定性和可信度；边记录来源、目标、操作提示、成本及有效期。基础包拒绝临时节点 / 边。临时信息在 patch 中且必须到期；默认检索不包含临时路由，只有任务明确涉及时加载。

先读核心骨架，任务涉及某个功能时再读局部 flow。动态首页卡片属于页面的动态区域，不改变核心导航；弹窗、键盘、加载态通常属于页面状态，不单独建立核心路由节点。候选路径按成本、稳定性、可信度与优先度计算，只供规划，执行仍须检查实时状态。

## 两个种子场景

- 小红书：本机图片传输、图文编辑、发布与结果核验流程。发布是否成功依据实时结果，结果未知不得重放发布。种子包不是经实机验证的现行版本适配。
- 开心消消乐：单关连续操作流程及本地三消候选评分；首轮模型将棋盘识别为矩阵，本地算法枚举合法交换。尚不提供完整棋盘视觉识别器、复杂障碍模拟或通关保证。

范围逐步扩展至选定的约十款应用，不预置无可靠资料的空壳适配。通用手机工具与 APP 操作知识分开维护。

## 提交与验证

1. 操作包存储、ZIP 安装、分页读取、版本化补丁、路由图与针对性测试。
2. ADB 执行器、三消候选工具、种子包、小伴聊天发现接入与针对性测试。

使用本地单元 / 模拟 ADB 测试验证进程边界、取消、输入参数、图片回传、包更新和路由规则。无已授权连接的手机时不操作用户设备，不将模拟测试描述为真机验收。所有 Workflow 保持仅手动触发。

## 本轮实现记录

已提供 12 个按需加载工具：操作包发现 / 阅读 / 安装、补丁发现 / 保存、路由查询 / 规划、设备发现 / 配对连接、状态 / UI / 截图、单次动作、传图及普通三消评分。宿主通过现有工具目录加载，包目录为 `chat/phone-packs`，不修改 agent-kernel 的产品边界。

小红书与开心消消乐种子包首次使用时按需落盘；`examples/export-packs.rs` 可构建 ZIP 与 SHA-256 校验文件供分发。当前没有在线操作包市场或下载托管，没有声称覆盖十款应用。无真机样本时，页面、路由可信度保持较低，已验证 APP 版本列表为空。
