# open-claude-design：首版实施与验证

更新：2026-10-26。开发分支：`dev/open-claude-design`。不自动合入主分支，不自动触发打包。

## 产品流程

用户消息含“设计稿” → 内置工具读取格式并创建多画板项目 → 聊天右侧打开画布，同时在资料库「我的文档」出现一条设计文档。后续对话、手动编辑和资料库编辑都保存到该 id。

画布默认收起属性栏，顶部保留选择、抓手、Play、新增、批注、撤销/重做、缩放；左侧为画板列表。标题栏负责历史、属性开关、导出和全屏。聊天分栏支持拖动和方向键调整。

选中元素可调整静态文字和样式；动态表达式通过批注交给 Agent 修改。元素批注先将稳定标识写回源模板，再保存批注，最后发送修改请求。当前任务执行中时，聊天页将请求放入输入框等待发送；资料库保留已记录的请求并提示等待。

## 存储与并发

| 内容 | 行为 |
| --- | --- |
| 项目 | project.json 保存原始 canvas、源文件、项目 id、版本和会话关联 |
| 文档 | 一项目一记录，分组与标签属于资料库索引 |
| 保存 | 比较 expected_revision 后替换完整项目，不允许静默覆盖新版本 |
| 手动修改 | 修改源模板；其他画板、脚本和未知索引字段保留 |
| 恢复草稿 | 先备份再保存；失败后可重试或导出，冲突时必须读取新版 |
| 历史 | 最近 30 个完整历史版本；恢复产生新版本，不回退版本号 |
| 撤销 | 本地操作形成新版本；AI 外部更新后清空旧撤销栈 |
| 源码编辑 | 缓冲区记录打开时版本；版本变化后拒绝覆盖 |
| 创建重试 | 同会话相同 request_id 返回已有作品 |
| 原会话删除 | 新会话读取项目时关联同一个 id，资料库仍只有一条记录 |
| 文档删除 | 与保存使用同一个存储锁，旧写入不能复活作品 |

## 兼容与隔离

参考实际 Claude Artifact：[小伴桌面 UI 升级设计稿](https://claude.ai/artifact/GzhNp5y7ehkzSrWWExkqzg#page-dcb81aee8d83)。适配源文件为 `.dc.html`，不把普通的多标签页 HTML 冒充 Claude Design 格式。

支持新旧画布索引；保留原始源码与未知字段。实现 `x-dc / helmet / {{表达式}} / sc-if / sc-for / DCLogic / renderVals / props / setState` 等已记录的语法子集。该运行时由本项目独立实现，未打包 Anthropic 的 support.js。

预览使用专用响应 + opaque sandbox iframe。控制页面不增加 unsafe-eval；设计预览的 CSP 单独生效，禁止 fetch、本机文件和外部脚本。父窗口校验消息来源及 token；设计命令只对主窗口开放。

首版不支持外部 React / dc-import / 未记录的专有编辑器扩展；不加载本地外链 CSS、JS 和 SVG。ZIP 仅支持 UTF-8 文本素材，二进制图片需先内嵌成 data URL。遇到不支持的导入给出错误，不生成残缺文档。不同 WebView 平台的原生协议、文件对话框和字体效果尚需实机验收；同线程的无限脚本循环无法靠 iframe 自动中止。

## 阶段提交

1. 独立项目模型、DC 格式说明与运行时。
2. 原子版本存储、创建去重、源包导入导出。
3. 注册内置工具、资料库索引、预览命令、恢复草稿。
4. 紧凑画布、聊天与资料库入口、编辑/批注/历史。
5. 新会话续改、旧编辑缓冲区保护、导入边界与验证记录。
