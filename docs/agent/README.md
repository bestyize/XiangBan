## 一句话共识

> 第一阶段使 Agent 能可靠执行；第二阶段使 Agent 可以扩展能力、验证结果、沉淀经验并在后续任务中持续改进；第三阶段使 Agent 知道何时应该主动行动；第四阶段在可验证的专业化基础上形成持续进化的专家与专家组织（AOE）。

本版规划以第二阶段为主线，同时补齐第一阶段妨碍可靠执行的缺口。第三阶段和第四阶段是两个可并行验证的后续方向，不必机械地按顺序启动。

## 阅读与使用约定

- **[已有]**：根据此前仓库检查或既有讨论可确认存在的基础能力，具体状态实施前需以最新代码复核。
- **[部分]**：有接口或单点实现，但尚未构成端到端能力。
- **[待建]**：规划目标，不能在产品或文档中宣称已实现。
- 所有指标属于**建议验收口径**，须用实际测试记录支撑，而非现有产品数据。
- 本文约束新增模块的职责，不强制要求一次性拆出所有 crate。
- 本手册是研发规划，并非产品代码改动授权。具体任务应经明确需求、测试和审查后实施。

## 关键实施原则

- **结果优先于架构**：先验证有用户价值的可复用任务，再扩展抽象层。
- **运行完成不等于任务成功**：Agent 结束响应，需要单独的任务验收证据。
- **改进必须可度量**：比较相同基础模型和工具条件下，启用/关闭经验资产后的真实表现。
- **学习不等于自动执行**：知识写入、Skill 安装、危险操作、主动任务各自有独立权限。
- **不提前宣称专家能力**：只有独立评测和真实任务证据支持的能力才能进入专家画像。
