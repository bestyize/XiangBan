# 小米 17 Android 真机联调

环境：小米 17，型号 25113PN0EC，Android 16 / API 36，1220×2656，无线 ADB。设备序列号、账号信息、完整 UI 树与相册截图仅留本机临时调试目录，不提交仓库。另一台连接的设备未操作。

## 已验证

- 直接调用与桌面注册相同的 Rust 工具，验证设备显式选择、状态、PNG 图片回传、UI 树读取、动作、图片传输和中文输入。
- 小米 17 的 `uiautomator dump /dev/tty` 只返回成功提示，不输出 XML。改为唯一私有临时文件、读取后清理；UI 分页固定 snapshot_id，动作派发前失效旧快照。
- 小红书 9.51.0 的资源 ID 大量重复。新增精确 text / description / resource_id / class 组合选择器，匹配不唯一不输入；坐标操作可用 guard_selector 检查当前页。
- 小红书：传入专用测试图片，刷新相册后选一张 → 图片编辑 → 正文编辑；中文标题和含换行正文经 UI 回读及截图核对。随后逐级返回并关闭测试编辑，没有提交发布。两个“发笔记”控件仍需后续最终提交定位验收。
- 经用户批准安装官方 ADB Keyboard v2.5-dev（上游 README 标注 A16 fix），核对包名和 APK 签名后临时启用。测试完成已恢复原搜狗输入法并停用调试输入法。未改默认浏览器、权限策略或系统版本。
- 开心消消乐 1.162：按用户指定进入第 4181 关，取消默认勾选的补星瓶，未用道具、未购买步数。模型识别右下角普通棋子局部矩阵，本地 phone_match3 给出候选，ADB 单步执行两次；剩余步数 27→26→25，稳定后得分 251705，海豹目标 3→2。之后暂停，未宣称通关。
- 游戏 UI 只有 5 个节点且无棋子标签；连锁可能持续到 UI dump 返回之后，必须重新观察稳定画面。
- 在隔离调试包目录保存实机学习补丁并回读，确认 source=patch/pages/home.md。渠道优惠路由以有有效期的 temporary 补丁记录，默认查询只返回核心节点，显式 include_temporary 时才包含该节点和边。
