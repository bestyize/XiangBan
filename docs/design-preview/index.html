此桌面设计稿依赖 Vite 实时编译

该设计稿直接引入了小伴桌面的真实 Vue / TypeScript 组件（如 AiGatewayCard.vue、特效引擎、组件模型），无法纯静态打开。请先在终端启动桌面前端开发服务，再点击重新检测即可内嵌预览。

npm --prefix client/xiaoban-desktop run dev

本地预览与使用说明

1. 一键启动统一预览服务（推荐）

在仓库根目录运行下方命令，即可在 http://127.0.0.1:1455/ 浏览全部静态设计稿与桌面画布模块，并自动映射桌面 UI 升级画布的 /_blob/ 图片资源：

python3 docs/design-preview/serve.py --open

2. 预览 4 份桌面 Vite 编译稿

桌面端「设置与多模型」「组件与伙伴」「游戏库」「特效页」4 份设计稿直接复用真实 Vue/TS 模块，需要另开终端启动 Vite（默认 1420 端口）：

npm --prefix client/xiaoban-desktop run dev
