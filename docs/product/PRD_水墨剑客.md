## 1. 概述

### 1.1 一句话定位
一卷山水，一人一剑。横屏水墨动作游戏：每卷分成六幅，一幅一关，逐幅解锁，最后与 Boss 决战；每幅可集三枚印、评墨品，通关一卷后可一气呵成打「长卷」。

### 1.2 设计支柱
1. **画即是卷**：一卷就是一幅从左往右展开的长卷，画面全部由代码现场绘制。打通一幅，那一幅就被「画满」。
2. **朱光一闪，出剑为反**：核心乐趣是读懂预警、在对的瞬间出剑。弹反是主要手段，乱砍会被惩罚。成长线可以让人变强，但不能让弹反变得可有可无（见 5.3 的护栏）。
3. **一剑有分量**：每次命中都有顿帧、墨溅、声音；越关键的动作反馈越强。
4. **短局、可重玩、可分享**：一幅一两分钟，三印和墨品给出重玩的理由，结算可以分享战绩、向朋友下切磋帖。

### 1.3 不做
- 不使用任何图片、字体、音频文件，所有素材由代码生成。
- 不加入与「下班」「小伴」相关的主题内容（产品要求，游戏独立成作）；小伴只出现在网站的战绩海报上。
- 不做联网对战。
- 不做内购，不卖数值；成长只来自游玩（见第 5 章）。
- 不做体力值，不限制每天能玩几次。
- 不因为「分享」这个动作本身发奖励（见 5.5）。

### 1.4 参考坐标
世界坐标以「单位」计：地面高度 `y = 300`，画卷全长 `0–6120`。画面始终显示 360 单位高、至少 560 单位宽；手机竖持时自动转为横屏。

## 2. 美术风格

### 2.1 原则
- **墨分五色**：同一种墨，靠浓淡区分远近。远山最淡、偏青灰；越近越浓、越黑。主角和敌人是最浓的剪影。
- **留白**：天空、地面以纸色为主，不铺满。雾带用来分隔层次，不用来填空。
- **朱砂只点睛**：画面里的红色只用于需要玩家注意的信息和身份标识（见 2.3），不作装饰色大面积使用。
- **剪影可读**：任何角色只看黑色轮廓也要能认出是谁、在做什么。
- **飞白与晕染**：线条用干笔（飞白），面用晕染渐变；硬边、纯几何形只出现在建筑上。

### 2.6 角色造型
所有人形角色用同一套骨骼（大腿、小腿、躯干、上臂、前臂、头），靠比例、服装和兵器区分。

| 角色 | 识别特征 |
| --- | --- |
| 主角 · 剑客 | 斗笠、黑袍、红腰带、随风飘的红围巾、细长剑 |
| 墨傀 | 刺状乱发、破布衣摆、宽刀、朱色眼 |
| 盾傀 | 更宽更壮、竖长木盾（盾面有符纸）、短刀 |
| 弓手 | 兜帽、弓，拉弓时箭头为朱砂 |
| 墨鸦 | 乌鸦剪影、朱色眼，预警时双翼张开 |
| 草人 | 稻草身、十字横杆、符纸，挨打会摇晃 |
| Boss · 无常 | 比主角高约三分之一、宽斗笠垂纱、白面具朱纹、长袍大袖、长刀 |

**握持规则**：单手兵器（剑）握在持兵器的手里，剑柄长出拳外，护手在拳前，剑身与前臂之间保留手腕角，待机时剑尖斜指前下方，不从手臂延长线上伸出。双手兵器（长枪、大锤、钓竿）两只手都握在杆上：前手靠近兵器头，后手靠近尾端，握处缠一段白布；出招时后手随前手一起运动，不允许副手悬在身侧。盾和弓由副手持。

所有角色脚下有落地阴影；离地越高阴影越小越淡。

### 2.8 界面
- 字体：楷体优先（`Kaiti SC`、`STKaiti`、`KaiTi`），没有楷体时退到宋体；说明性小字用系统无衬线。
- 卡片与按钮：纸色底，四角不等的圆角（如 `4px 18px 6px 16px`），像手裁的纸片。
- 主按钮是墨底纸字；分享按钮是朱底纸字。
- HUD：左上墨滴血量和墨意条；正中积分、当前区域名和本幅「技」的进度（达成后变朱色）；右上图标按钮；右侧连击；Boss 战时正中出现 Boss 血条，下方是从中间往两边扩的朱色架势条。
- 区域标题：进入新区域时正中淡入「第几幅」和区域名（最后一幅是「终幅」），约 3 秒后淡出。
- 触屏按键：右手扇形排布 斩（最大）、跳、闪、一笔；左手是可在左侧任意位置按下的滑动移动条。触控目标不小于 44px。

### 2.10 声音
全部用 Web Audio 实时合成，默认静音，玩家手动打开。
- 配乐：D 宫五声音阶的拨弦（接近古琴），随机游走；进入战斗加快并加鼓点，Boss 战鼓点更密。
- 环境：夜雨段有持续雨声；雪江卷有随飞雪和阵风强弱变化的风声底噪，偶尔一声冰铃。
- 音效：钢刃（斩、弹反的钟鸣）、墨（命中、击杀）、风（跳、闪）、锣（锁屏、Boss 登场）；雪江卷另有踏雪、冰面滑行、冰凌断裂与碎裂、冰层呻吟、裂口崩开、隐身窸窣、伏击和阵风涌起。

## 3. 玩法设计

### 3.1 核心循环
选一幅入画 → 墨幕合围（锁屏）→ 读预警、弹反或闪避 → 失衡处决、攒墨意 → 斩尽所有波次，本幅通关 → 结算盖印、评墨品，展开下一幅。前五幅之后是终幅 Boss 战；终幅通关后展开长卷。没集齐的印、不够高的墨品，是回头重玩的理由。

### 3.2 操作
| 动作 | 触屏 | 键盘 / 鼠标 |
| --- | --- | --- |
| 移动 | 左侧滑动条 | A / D 或 ← / → |
| 斩 | 斩 | J、X 或鼠标左键 |
| 跳 | 跳（按住跳得更高） | K、W、↑ 或空格 |
| 闪 | 闪 | L、Shift 或 C |
| 一笔 | 一笔（墨意满时亮起） | I、Q 或 U |
| 暂停 | 暂停按钮 | P 或 Esc |

离开页面、窗口失焦、旋转屏幕、退出全屏都会自动暂停。

### 3.3 主角能力
| 项 | 数值 |
| --- | --- |
| 跑速 | 240 / 秒 |
| 跳跃 | 起跳速度 660；提前松手截断到 280，形成短跳 |
| 二段跳 | 空中 1 次，起跳速度 585，伴随空翻 |
| 土狼时间 | 离开平台边缘后 0.1 秒内仍可起跳 |
| 输入缓冲 | 跳、闪、一笔 0.13 秒；斩 0.17 秒 |
| 闪身 | 0.19 秒，速度 640，无敌 0.25 秒，冷却 0.46 秒；空中 1 次 |
| 受伤 | -1 墨血，无敌 1 秒，硬直 0.3 秒，被击退，连击清零 |

### 3.4 三段连斩
| 段 | 时长 | 生效 | 可接下一段 | 前冲 | 伤害 | 判定 |
| --- | --- | --- | --- | --- | --- | --- |
| 一 | 0.30 秒 | 0.035–0.12 秒 | 0.15 秒后 | 130 | 1 | 78 |
| 二 | 0.30 秒 | 0.035–0.12 秒 | 0.15 秒后 | 130 | 1 | 78 |
| 三（重斩） | 0.44 秒 | 0.08–0.19 秒 | 0.40 秒后 | 310 | 2 | 90 |

- 收招后 0.3 秒内再按，接着下一段；否则从第一段开始。
- 空中只能用前两段，出剑时下落变慢，便于空中连斩。
- 生效段结束后，可以用跳或闪取消收招。

### 3.5 弹反
- 按下斩之后，有一段时间算作弹反窗口：江湖 0.16 秒，入门 0.24 秒。敌方攻击在窗口内到达、且主角面朝攻击方向，即为弹反。
- 弹反奖励：+50 分、+20 墨意、连击 +1、0.22 秒无敌，伴随顿帧和慢镜。
- 结果因敌而异：墨傀失衡 1.3 秒，盾傀失衡 1.8 秒，墨鸦直接死亡，Boss 架势 +22。
- 箭和墨浪也能弹：箭被斩回、可以射死弓手；墨浪被斩碎。
- 预警后期（剩余不到 55%）敌人的出招已经「承诺」：此时砍中它不会打断出招，所以早一点出剑也能接住刀。

### 3.6 失衡与处决
- 敌人失衡时，头上悬「斩」印；用**一次新的出剑**命中即为处决（弹反用的那一剑不算）。
- 普通敌人：处决即击杀，+150 分、+15 墨意。
- Boss：架势被破后僵直 2.7 秒，处决扣 10 血、+300 分、+15 墨意，架势清零。

### 3.7 墨意与一笔
| 获取方式 | 墨意 |
| --- | --- |
| 命中（Boss 为 5） | +6 |
| 击杀 | +8 |
| 斩破墨浪 | +12 |
| 处决 | +15 |
| 斩回箭 | +16 |
| 弹反 | +20 |

墨意满 100 后可放「一笔」：1.4 秒无敌，0.55 秒后命中 470 单位内所有敌人（普通敌人 4 伤，Boss 6 伤并 +30 架势），同时清除敌方所有箭和墨浪。盾傀挡不住一笔。

### 3.8 反馈强度分级
越关键的动作反馈越强，新增动作要放进这个梯度里，不要越级。

| 事件 | 顿帧 | 慢镜 | 其他 |
| --- | --- | --- | --- |
| 普通命中 | 0.05 秒 | — | 墨溅、墨滴、轻震 |
| 重斩命中 | 0.085 秒 | — | 更大墨溅、中震 |

### 3.12 计分
- 每次得分乘以连击倍率：`1 + min(连击, 40) × 5%`，最高 ×3。命中、弹反、处决都会让连击 +1；2.6 秒内没有新的连击就清零，受伤也清零。
- 命中 10 × 伤害；弹反、斩回箭、斩破墨浪各 50；处决 150；Boss 处决 300；用斩回的箭射死敌人额外 +80。
- 击杀：草人 20、墨鸦 60、墨傀 100、弓手 120、盾傀 200、无常 2000。
- 清完本幅第 N 场遭遇 +100 × N（单幅只有一场遭遇，长卷有六场）。
- 通关奖励：用时奖励 `(本幅标准用时 − 用时) × 6`，余血 × 150，无伤奖励普通幅 600、终幅 1000、长卷 1500。各幅标准用时见 4.2。
- 积分只增不减。

### 3.13 一局的结束与分享
- 墨血归零时进入慢镜，约 1.2 秒后弹出结算；通关后约 2.2 秒弹出结算。
- 结算显示：三枚印（本局得到的印会盖章落下，第一次得到的标「新」）、墨品、积分、击败数、最高连击、弹反次数、用时、通关奖励明细，以及本幅最佳。
- 按钮：分享战绩、下一幅（通关且有下一幅时）、再来一次、返回画卷、返回游戏广场。
- 分享字段（已在外部链接中使用，**含义不得更改**）：
  - `game.result`：`score`、`lines` = 击败数、`maxTile` = 最高连击
  - `game.share`：在上面基础上加 `level` = 是否通关（1/0）、`steps` = 弹反次数、`stage` = 幅编号（卷 × 100 + 第几幅，长卷为卷 × 100，如 103 = 竹林卷第三幅）、`seals` = 印（1 过、2 全、4 技，按位相加）、`grade` = 墨品（0 未通关，1–4 能、妙、神、逸品）
  - 分享链接的片段格式是第 2 版；第 1 版（只有前五个字段）的旧链接仍能打开，按长卷显示。
- 切磋帖：分享页的「我也来玩一局」会带上 `stage` 和对方分数 `target`，朋友打开后直接进入同一幅（不需要先解锁），超过分数时结算显示「破帖」。

| 夜雪 | 阵风 | 无，按时间循环 | 3.2 秒平静 → 1.0 秒预警（雪线开始倾斜、提示风向、风声涌起）→ 2.4 秒吹风（0.4 秒渐强渐弱）；风向每轮交替，第一轮向右；吹风时主角的目标速度偏移 150 × 0.55（地面）或 × 1.0（空中），未出招的敌人被推动（力士 15%、校尉 40%、盾傀 30%、其余 50%），敌方的箭和飞镖被推偏；冲刺和地面出剑的前冲不受影响 | 预警期内调整位置；借顺风拉开距离，逆风时少起跳 |

**设计取舍**
- 地形都有明确预警，触发后的伤害一律不可弹反；能躲开的方式只有起跳、闪身或走位。
- 古渡的裂口与寒峰的冰凌都是「环境武器」：玩家可以把敌人引进去，这是对应「技」的做法。
- 芦荡的隐身不是无敌：它只推迟敌人出招，不会让战斗无限拖下去（4 秒上限、近身暴露、锁屏里的敌人仍会靠近）。

## 4. 关卡设计

### 4.1 结构：卷与幅
- **卷**（大关）是一整幅画：一个世界、一条天色线、一个 Boss。目前包含第一卷《竹林卷》与第二卷《雪江卷》。
- **幅**（小关）是卷中的一段，单独开局：只能在本幅的范围内走动，只打本幅的遭遇，清完即通关。一卷六幅，前五幅各引入一个新要素，终幅是 Boss。节奏是：教学 → 加压 → 换口气 → 高潮。
- **解锁**：第一幅一开始就开放；之后每幅在上一幅通关后展开；终幅通关后展开「长卷」。
- **长卷**：同一卷六幅一气呵成，全部遭遇连打，有自己的三印和墨品。
- **选卷界面**：顶部支持「竹林卷」「雪江卷」卷轴切换。横向排列六幅加长卷。已通关的幅画面完整；已展开未通关的是淡墨草稿；未展开的是空白宣纸，写「未展」。每张卡显示三印、最佳墨品和分数、本幅「全」与「技」的条件。

## 5. 长线设计

### 5.1 阶段
| 阶段 | 内容 | 状态 |
| --- | --- | --- |
| P1 骨架 | 卷与幅、逐幅解锁、三印、墨品、长卷、存档（登录用户存服务端）、分享第 2 版、切磋帖 | 已实现 |
| P2-A 第二卷 | 《雪江卷》六幅、雪霁视觉、风雪粒子、冰面惯性、长枪/浪人/力士、Boss 苏寒江 | 已实现 |
| P2-B 成长与经济 | 修为与境界、心法、兵器谱、墨锭与材料、奖励邮箱、同门邀请与切磋奖励 | 设计已定，未实现 |
| P3 运营 | 每日一幅、墨池、图鉴与成就、长卷图 | 设计已定，未实现 |

### 5.2 存档（P1）
- 内容：每幅的通关次数、最高分、最高墨品、已得的印、最快用时；看过的教学提示；难度。格式见 `progress.js`，网站不解读存档内容。
- 存放：游客存在本机浏览器；登录用户存在账号里（服务端 `game_saves` 表），换设备不丢。游客登录后，如果账号里还没有存档，本机进度会自动带进账号。
- 读不到存档时不开局，以免用空存档覆盖进度；两个标签页同时玩时，较旧的写入不会覆盖较新的。
- 存档与积分一样是玩家自己上报的数据，服务端只校验大小和时间，不防作弊。排行榜、奖励这类需要可信数据的功能，上线前要另做服务端校验（见 5.5）。

### 5.3 成长线（P2）
方向：养成感要强，但成长只来自游玩，并且受 5.3.4 的护栏约束。

**5.3.1 修为与境界**
- 修为是经验值。每次通关获得；首次通关、新得的印、新的墨品另有加成；失败也按击败数给少量。
- 等级 1–60，每十级一个境界：初窥、入门、小成、大成、化境、宗师。初值：第 n 级升级所需修为 = 100 + 40 × n。
- 每升一级得 1 点心法点。每破一个境界：墨血上限 +1，并开放一层新的心法。
- 破境试炼：到 10、20、30……级时，要先通过一幅试炼（已有的幅加一条词条，例如「敌人更快」），才能进入下一个境界。这样成长也有技术门槛。

**5.3.2 心法**：三系，每个节点 1–5 层，可以花墨锭重置。
| 系 | 节点 |
| --- | --- |
| 剑 | 剑锋（普通斩伤害）、重斩（第三段伤害与击退）、破势（对 Boss 的架势）、回风斩（新动作：空中旋斩）、剑气（第三段斩放出短程剑气） |
| 身 | 墨血（上限）、身法（闪身冷却缩短、空中闪身 +1 次）、护体（每幅第一次受伤减免）、回墨（处决回 1 墨血，每幅有次数上限）、残影（闪身留下残影，替你挡一次攻击） |
| 墨 | 墨意（获取更多）、一笔（伤害与范围）、蓄墨（开局自带墨意）、返照（斩回的箭伤害更高）、墨盾（弹反后短暂护身） |

**5.3.3 兵器**
- 每把剑有三项属性：锋（伤害）、势（架势）、韵（墨意），再加一个特性。不同的剑剑痕笔触不同，颜色仍守 2.3 的朱砂白名单。
- 获得：每卷 Boss 首通掉落、成就、同门里程碑。现有「青竹」（初始）、「无常」（击败无常获得，特性：破势后处决伤害 +30%）、「寒江」（击败苏寒江获得，特性：冰上滑行距离 +20%，闪身带轻微破浪）。
- 强化 +1 到 +10，消耗墨锭和材料。

**5.3.4 护栏**（保证弹反始终是核心）
- 弹反判定窗口不随成长变宽。成长只能给弹反加收益（如「墨盾」），不能放宽判定。
- Boss 只能靠弹反和破势稳定打出处决；所有成长对架势的加成合计不超过 +50%。
- 每卷敌人的墨血、伤害、出招速度按推荐境界整体提高（初值：卷二约为卷一的 1.6 倍），新卷总要技术加成长才打得过；回到旧卷，玩家能直接感受到自己变强了。
- 选卷界面显示每幅的推荐境界。境界不够时会提示，但不阻止开局。
- 入门 / 江湖两种难度都能拿印和墨品；从 P2 起，入门难度的修为和墨锭收益 × 0.7。

### 5.4 经济（P2）
- 货币：修为（只用于升级，不能花）、墨锭（通用货币）。材料：松烟（常见）、朱砂（稀有）、金箔（Boss 掉落）。
- 来源（初值，待校准）：首次通关某幅 墨锭 100 × 幅序号；重复通关 20–40，每幅每天前 5 次全额、之后 × 0.2，防止刷；每个新印 +50；每个新墨品 +30；每日一幅 +150；墨池按波次结算；成就；同门（见 5.5）。
- 消耗：兵器强化、心法重置、外观。
- 奖励邮箱「飞鸽传书」：服务端发的奖励（同门、活动、补偿）先进邮箱。宿主在 `host.init` 里把待领奖励交给游戏，游戏领取后回执，服务端记账，防止重复领取。

### 5.5 分享激励
**原则**：只奖励「朋友真的来玩了」，不奖励「点了分享」。奖励在游戏里领取；分享面板和分享文案里不写「分享得奖励」；不做「分享才能解锁」。原因是微信等平台禁止用利益诱导分享，违规可能导致域名在微信里被拦截。

**已实现（P1）**
- 切磋帖：分享页带上幅和分数，朋友点「我也来玩一局」直接进入同一幅比分，超过就显示「破帖」。

**设计（P2）**
1. **同门**：朋友通过你的链接第一次进来，并通过第一幅之后，双方各得奖励。你得墨锭 200 和朱砂 1，朋友得入门礼（墨锭 300 和一件初始外观）。每人每天最多计 3 位同门，累计最多 20 位。服务端核验三件事：被邀请的是新账号；来源是你的邀请码（服务端已记录 `users.referred_by`）；确实有通关记录。奖励通过奖励邮箱发放。
2. **同门里程碑**：累计 1、3、5、10 位同门，解锁专属外观（同门剑穗、朱砂斗笠、金箔剑痕等）。只给外观，不给数值。
3. **切磋奖励**：朋友破了你的帖，你下次进游戏会收到「某某破了你的帖」，并得墨锭 30（每周最多 10 次）；朋友得到「破帖」成就印。
4. **长卷图**（P3）：通关一卷后可以导出整卷长图，带每幅的印。它本身就是很好的分享内容，不附奖励。

**防滥用**：奖励只发给登录用户；同一设备或账号只计一次；全部由服务端记账；上限如上。分享链接里只放战绩和公开邀请码，这条规则不变。

**风险**：即使不奖励分享动作本身，「邀请得奖励」仍可能被平台认定为诱导。上线前要对照微信外部链接内容管理规范复核文案，必要时只保留外观类奖励。

### 5.6 运营（P3）
- **每日一幅**：每天固定一个幅加一条词条（如「夜雨 · 敌人更快」「只能靠弹反伤敌」），随机种子按日期固定，同一天所有人打的是同一局。每天第一局计入记录并给墨锭。
- **墨池**：无尽波次的生存模式，越往后敌人越多越快，按波次和分数结算，适合比分。
- **图鉴与成就**：每种敌人一页（击败次数、一段短文）；成就印章册（如「片墨不沾身」「百弹」）。
- **第二卷《雪江卷》**（已实现）：新敌人长枪校尉（长距刺扫）、蓑衣浪人（暗器飞镖）、持槌力士（震地波），新机制冰面（急停打滑与长滑行），新 Boss 苏寒江（竹竿甩钩顿冰浪）；天色线从霁雪走到雪月。
- **后续卷规划**：第三卷《烽火卷》（火箭阵、骑兵冲锋、荒漠残垣）、第四卷《幽冥卷》（幻影分身、彼岸花）。
- **节奏**：每卷约六幅；按月推出新卷或新幅；每周轮换每日一幅的词条池。

### 5.7 时长
- 当前卷一：脚本玩家每幅 16–25 秒；真人估计每幅 40–90 秒，卷一首次通关约 10–15 分钟（含失败重来），集齐 21 枚印约 1 小时。这些都是估算，要用真人试玩校准。
- 加上 P2 的成长线和卷二、P3 的每日一幅与墨池以后，每天都有回来玩的理由。

## 6. 一致性规则（新增内容前逐条对照）

### 6.1 美术
- 只用代码绘制，不引入图片、字体、音频文件。
- 不新增主色；朱砂只用于 2.3 白名单里的场景。
- 新元素放进 2.4 的某一层，遵守「远淡近浓」；前景层必须半透明，不能挡住战斗。
- 新角色只看剪影也要能认出来；敌人统一用朱色眼睛，主角始终是唯一戴红围巾的人。
- 新印章先查 2.7 字表，同一含义只用一个字。

### 6.2 玩法
- 每个敌方攻击都必须有可读预警：刃尖朱光，或「危」印。普通敌人预警不短于 0.45 秒（乘难度系数之前）；Boss 可以更短来体现压力，当前最短是二阶段三连斩第二刀的 0.28 秒。
- 不可弹反的招式必须标「危」，并且一定能靠跳或闪躲开。
- 新敌人必须定义被弹反后的结果（失衡、死亡、架势……），并给出收招窗口。
- 同时出招受 3.9 的上限约束；新敌人默认计入上限。
- 新动作的反馈强度放进 3.8 的梯度，不越级。
- 墨意获取、分数按 3.7、3.12 的量级定，避免某种打法收益明显压过弹反。

### 6.3 关卡
- 新增一幅需要：两字名称、天色关键帧（2.5）、至少一个标志性道具、一场遭遇、一个新要素，以及 4.2 的四项评价参数：标准用时、「全」的受伤上限、对准新要素的「技」、三条分数线。
- 遭遇锁屏宽度不超过约 680，并且整个落在本幅的走动范围内；触发点放在玩家已经能看到敌人出场位置的地方。测试会检查这两点。
- 新要素第一次出现时配一条教学提示（4.3），并且第一波要温和。
- 地形类新要素放进 3.15 的表：写清触发、预警、数值、躲避方式；伤害一律不可弹反，并且一定能靠跳、闪或走位躲开。
- 地形类提示只在本幅范围内触发，不要从后面的幅起手时弹出前面幅的提示。
- 单幅时长目标 1–2 分钟（真人）；长卷目标 7 分钟以内。加内容时同步调整标准用时。
- 分数线先用脚本玩家定初值，再用真人试玩校准；改动后更新 4.2 的表。

### 6.4 成长与奖励
- 新的成长项先对照 5.3.4 的护栏：不放宽弹反判定、不让处决绕开破势、架势加成合计不超过上限。
- 新的奖励来源先放进 5.4 的来源表，写明数额和上限。
- 和分享有关的奖励先对照 5.5 的原则：只奖励朋友真的来玩，不奖励分享动作，不把内容锁在分享后面。

### 6.5 数值与协议
- 改数值时同步更新本文对应表格和桌面游戏包实现。
- 3.13 的分享字段含义不得更改；需要新指标时新增字段并升级片段版本，同时改网站侧解析，并保留旧版本链接的读取。
- 存档格式变化时提升 `progress.js` 的版本号，并让 `normalize` 能读旧版本。

## 7. 技术约束
- `levels.js` 只放数据；`rules.js` 是确定性的纯规则：不访问 DOM，固定 1/60 秒步长，随机数用种子。测试直接运行这两份发布文件。
- 游戏包运行在沙箱 iframe 里，没有自己的存储，进度只能通过宿主存档协议保存（`host.init.save` / `game.save`，单个存档不超过 32 KB）。
- 画面目标约 240 万像素的绘制缓冲，设备像素比最高 2；帧耗时持续超过 14 毫秒时自动降一次画质（去掉纸纹、降分辨率）。
- 长条视差层切成不超过 2048 像素的块，兼容手机画布上限。
- 粒子上限：墨滴与烟 420、墨溅 30、地面墨渍 150、剑痕 14。新特效要设上限。
- 新增文件要在 `index.html` 里按依赖顺序引入，并更新游戏包 README 的文件说明。
