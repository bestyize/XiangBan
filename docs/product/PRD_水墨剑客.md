# PRD：水墨剑客（ink-blade）

> 版本 v1.0 · 2026-10-07 · 状态：与线上实现一致（PR #16、#23）
>
> 本文是这款游戏的设计基准：风格、玩法、关卡和数值都以这里为准。改动设计时先改本文，再改代码；只改数值时，同步更新本文中对应的表格。实现细节见游戏包 [README](../../client/xiaban-web/public/game-packs/ink-blade/README.md)，规则代码在 `rules.js`。

## 1. 概述

### 1.1 一句话定位
一卷山水，一人一剑。横屏水墨动作游戏，一局约三分钟，从山门一路打到月下，最后与 Boss「无常」决战。

### 1.2 设计支柱
1. **画即是卷**：整局就是一幅从左往右展开的长卷，画面全部由代码现场绘制。
2. **朱光一闪，出剑为反**：核心乐趣是读懂预警、在对的瞬间出剑。弹反是主要手段，乱砍会被惩罚。
3. **一剑有分量**：每次命中都有顿帧、墨溅、声音；越关键的动作反馈越强。
4. **短局可分享**：三分钟一局，结算有分数、击败、连击、弹反，可以分享战绩海报。

### 1.3 不做
- 不使用任何图片、字体、音频文件，所有素材由代码生成。
- 不加入与「下班」「小伴」相关的主题内容（产品要求，游戏独立成作）；小伴只出现在网站的战绩海报上。
- 不做联网对战、内购、装备养成。
- 不做跨局存档；「直面无常」只在本次游玩内解锁。

### 1.4 参考坐标
世界坐标以「单位」计：地面高度 `y = 300`，画卷全长 `0–6120`。画面始终显示 360 单位高、至少 560 单位宽；手机竖持时自动转为横屏。

## 2. 美术风格

### 2.1 原则
- **墨分五色**：同一种墨，靠浓淡区分远近。远山最淡、偏青灰；越近越浓、越黑。主角和敌人是最浓的剪影。
- **留白**：天空、地面以纸色为主，不铺满。雾带用来分隔层次，不用来填空。
- **朱砂只点睛**：画面里的红色只用于需要玩家注意的信息和身份标识（见 2.3），不作装饰色大面积使用。
- **剪影可读**：任何角色只看黑色轮廓也要能认出是谁、在做什么。
- **飞白与晕染**：线条用干笔（飞白），面用晕染渐变；硬边、纯几何形只出现在建筑上。

### 2.8 界面
- 字体：楷体优先（`Kaiti SC`、`STKaiti`、`KaiTi`），没有楷体时退到宋体；说明性小字用系统无衬线。
- 卡片与按钮：纸色底，四角不等的圆角（如 `4px 18px 6px 16px`），像手裁的纸片。
- 主按钮是墨底纸字；分享按钮是朱底纸字。
- HUD：左上墨滴血量和墨意条；正中积分和当前区域名；右上图标按钮；右侧连击；Boss 战时正中出现 Boss 血条，下方是从中间往两边扩的朱色架势条。
- 区域标题：进入新区域时正中淡入「第几幅」和区域名（最后一幅是「终幅」），约 3 秒后淡出。
- 触屏按键：右手扇形排布 斩（最大）、跳、闪、一笔；左手是可在左侧任意位置按下的滑动移动条。触控目标不小于 44px。

### 2.9 镜头与节奏手段
| 手段 | 用在 |
| --- | --- |
| 顿帧（hitstop） | 所有命中；越重越长 |
| 慢镜 | 弹反、处决、Boss 破势、Boss 倒下、主角死亡 |
| 画面反色一闪 | 处决、一笔命中、Boss 进入二阶段、Boss 倒下 |
| 上下黑边 | 处决、Boss 登场、Boss 倒下、死亡、一笔 |
| 震屏 | 命中、受伤、重击落地；系统开启「减少动态效果」时关闭 |

### 2.10 声音
全部用 Web Audio 实时合成，默认静音，玩家手动打开。
- 配乐：D 宫五声音阶的拨弦（接近古琴），随机游走；进入战斗加快并加鼓点，Boss 战鼓点更密。
- 环境：夜雨段有持续雨声。
- 音效：钢刃（斩、弹反的钟鸣）、墨（命中、击杀）、风（跳、闪）、锣（锁屏、Boss 登场）。

## 3. 玩法设计

### 3.1 核心循环
走进一幅 → 墨幕合围（锁屏）→ 读预警、弹反或闪避 → 失衡处决、攒墨意 → 斩尽所有波次，墨幕散去 → 进入下一幅。五幅之后是 Boss 战，击败无常即一卷终了。

### 3.2 操作
| 动作 | 触屏 | 键盘 / 鼠标 |
| --- | --- | --- |
| 移动 | 左侧滑动条 | A / D 或 ← / → |
| 斩 | 斩 | J、X 或鼠标左键 |
| 跳 | 跳（按住跳得更高） | K、W、↑ 或空格 |
| 闪 | 闪 | L、Shift 或 C |
| 一笔 | 一笔（墨意满时亮起） | I、Q 或 U |
| 暂停 | 暂停按钮 | P 或 Esc |

离开页面、窗口失焦、旋转屏幕、退出全屏都会自动暂停。

### 3.3 主角能力
| 项 | 数值 |
| --- | --- |
| 跑速 | 240 / 秒 |
| 跳跃 | 起跳速度 660；提前松手截断到 280，形成短跳 |
| 二段跳 | 空中 1 次，起跳速度 585，伴随空翻 |
| 土狼时间 | 离开平台边缘后 0.1 秒内仍可起跳 |
| 输入缓冲 | 跳、闪、一笔 0.13 秒；斩 0.17 秒 |
| 闪身 | 0.19 秒，速度 640，无敌 0.25 秒，冷却 0.46 秒；空中 1 次 |
| 受伤 | -1 墨血，无敌 1 秒，硬直 0.3 秒，被击退，连击清零 |

### 3.4 三段连斩
| 段 | 时长 | 生效 | 可接下一段 | 前冲 | 伤害 | 判定 |
| --- | --- | --- | --- | --- | --- | --- |
| 一 | 0.30 秒 | 0.035–0.12 秒 | 0.15 秒后 | 130 | 1 | 78 |
| 二 | 0.30 秒 | 0.035–0.12 秒 | 0.15 秒后 | 130 | 1 | 78 |
| 三（重斩） | 0.44 秒 | 0.08–0.19 秒 | 0.40 秒后 | 310 | 2 | 90 |

- 收招后 0.3 秒内再按，接着下一段；否则从第一段开始。
- 空中只能用前两段，出剑时下落变慢，便于空中连斩。
- 生效段结束后，可以用跳或闪取消收招。

### 3.5 弹反
- 按下斩之后，有一段时间算作弹反窗口：江湖 0.16 秒，入门 0.24 秒。敌方攻击在窗口内到达、且主角面朝攻击方向，即为弹反。
- 弹反奖励：+50 分、+20 墨意、连击 +1、0.22 秒无敌，伴随顿帧和慢镜。
- 结果因敌而异：墨傀失衡 1.3 秒，盾傀失衡 1.8 秒，墨鸦直接死亡，Boss 架势 +22。
- 箭和墨浪也能弹：箭被斩回、可以射死弓手；墨浪被斩碎。
- 预警后期（剩余不到 55%）敌人的出招已经「承诺」：此时砍中它不会打断出招，所以早一点出剑也能接住刀。

### 3.6 失衡与处决
- 敌人失衡时，头上悬「斩」印；用**一次新的出剑**命中即为处决（弹反用的那一剑不算）。
- 普通敌人：处决即击杀，+150 分、+15 墨意。
- Boss：架势被破后僵直 2.7 秒，处决扣 10 血、+300 分、+15 墨意，架势清零。

### 3.7 墨意与一笔
| 获取方式 | 墨意 |
| --- | --- |
| 命中（Boss 为 5） | +6 |
| 击杀 | +8 |
| 斩破墨浪 | +12 |
| 处决 | +15 |
| 斩回箭 | +16 |
| 弹反 | +20 |

墨意满 100 后可放「一笔」：1.4 秒无敌，0.55 秒后命中 470 单位内所有敌人（普通敌人 4 伤，Boss 6 伤并 +30 架势），同时清除敌方所有箭和墨浪。盾傀挡不住一笔。

### 3.8 反馈强度分级
越关键的动作反馈越强，新增动作要放进这个梯度里，不要越级。

| 事件 | 顿帧 | 慢镜 | 其他 |
| --- | --- | --- | --- |
| 普通命中 | 0.05 秒 | — | 墨溅、墨滴、轻震 |
| 重斩命中 | 0.085 秒 | — | 更大墨溅、中震 |
| 主角受伤 | 0.10 秒 | — | 朱色闪屏、朱色墨溅、重震 |
| 弹反 | 0.09 秒 | 0.42 秒 × 0.28 | 白、朱双环，火花，「弹」印，纸色闪屏 |
| 处决 | 0.13 秒 | 0.45 秒 × 0.30 | 反色、黑边、「斩」印、大墨溅 |
| Boss 处决 | 0.16 秒 | 0.70 秒 × 0.25 | 同上，更大 |
| Boss 倒下 | — | 1.6 秒 × 0.22 | 反色、长黑边、「胜」印 |
| 主角死亡 | — | 1.1 秒 × 0.32 | 黑边、半反色 |

### 3.9 敌人
| 敌人 | 墨血 | 行为 | 预警 | 弹反结果 | 分数 |
| --- | --- | --- | --- | --- | --- |
| 草人 | 2 | 不动，教学用 | — | — | 20 |
| 墨傀 | 3 | 走近后挥刀前冲 330（攻击距离 80） | 0.5 秒刃尖朱光 | 失衡 1.3 秒 | 100 |
| 盾傀 | 5 | 走得慢（70）；正面格挡斩击和箭；转身要 0.5 秒 | 0.7 秒 | 失衡 1.8 秒 | 200 |
| 弓手 | 2 | 640 内拉弓射箭（箭速 470，抛物线）；被贴近到 120 内会后跳；可站在平台上 | 0.8 秒拉弓 | 箭被斩回，可射死自己 | 120 |
| 墨鸦 | 1 | 在主角斜上方（水平约 135、高约 150）盘旋，然后俯冲（450） | 0.48 秒张翼 | 直接死亡 | 60 |

- 没进入「承诺」的敌人被砍中会短暂硬直并被击退（重斩击退更远）。
- 同一时间最多有 N 个敌人在出招（江湖 2、入门 1，Boss 不计），避免围殴时无从读招。
- 敌人出招后有一段收招，这是主角主动进攻的窗口。

### 3.10 Boss · 无常
墨血 46（入门 34），身高 72。登场有 2.2 秒亮相，期间不出手。

**招式**
| 招式 | 预警 | 说明 | 可弹反 |
| --- | --- | --- | --- |
| 三连斩 | 0.44 / 0.34 / 0.50 秒 | 每刀前冲 300，判定 100；三刀后收招 0.8 秒 | 是 |
| 跃击 | 0.48 秒蹲伏，「危」 | 跃起 0.72 秒落在主角位置；落地 82 范围冲击，再向两侧放出墨浪（速度 360） | 冲击不可，墨浪可 |
| 墨浪 | 0.58 秒 | 贴地向前推出墨浪（速度 430，持续 2.2 秒）；二阶段连放两道 | 是 |
| 后撤 | — | 近身时偶尔后跳，接墨浪 | — |
| 瞬身斩（二阶段） | 0.95 秒，「危」 | 消失后出现在场地另一端，以 1150 的速度横穿全场 | 否，跳或闪躲开 |

**出招逻辑**：距离超过 230 时，42% 墨浪、36% 跃击、其余走近；近身时 62% 三连斩、20% 跃击、18% 后撤。二阶段每第 4 招必定是瞬身斩。

**架势**：上限 100。弹反 +22（5 次弹反破势），重斩 +6，普通斩 +3，一笔 +30；2 秒没有新增就以每秒 7 回落。

**反制乱砍**：Boss 站定或走动时累计被砍中 2 次，会立刻反击三连斩（预警缩短 20%）。所以对 Boss 的有效打法是弹反和抓收招，而不是贴身连按。

**二阶段**：墨血降到一半时怒吼 1.25 秒，把近身的主角震开。之后三连斩预警变为 0.36 / 0.28 / 0.41 秒，墨浪变为两道，收招变短，身上不断冒出墨烟。

### 3.12 计分
- 每次得分乘以连击倍率：`1 + min(连击, 40) × 5%`，最高 ×3。命中、弹反、处决都会让连击 +1；2.6 秒内没有新的连击就清零，受伤也清零。
- 命中 10 × 伤害；弹反、斩回箭、斩破墨浪各 50；处决 150；Boss 处决 300；用斩回的箭射死敌人额外 +80。
- 击杀：草人 20、墨鸦 60、墨傀 100、弓手 120、盾傀 200、无常 2000。
- 清完第 N 场遭遇 +100 × N。
- 通关奖励：用时奖励 `(330 秒 − 用时) × 6`（「直面无常」按 150 秒算），余血 × 150，无伤 +1000。
- 积分只增不减。

### 3.13 一局的结束与分享
- 墨血归零时进入慢镜，约 1.2 秒后弹出结算；击败无常后约 2.2 秒弹出结算。
- 结算显示：积分、击败数、最高连击、弹反次数、用时，以及通关奖励明细。称号根据结果变化，例如无伤通关是「片墨不沾身」，弹反 12 次以上通关是「剑下无常」。
- 「直面无常」：本次游玩中到达过 Boss 场地后，结算页出现这个按钮，可以直接从 Boss 战开始，积分从零计。
- 分享字段（已在外部链接中使用，**含义不得更改**）：
  - `game.result`：`score`、`lines` = 击败数、`maxTile` = 最高连击
  - `game.share`：在上面基础上加 `level` = 是否通关（1/0）、`steps` = 弹反次数
  - 网站侧标签和小伴台词在 `client/xiaban-web/src/games/ink-blade/index.ts`

## 5. 一致性规则（新增内容前逐条对照）

### 5.1 美术
- 只用代码绘制，不引入图片、字体、音频文件。
- 不新增主色；朱砂只用于 2.3 白名单里的场景。
- 新元素放进 2.4 的某一层，遵守「远淡近浓」；前景层必须半透明，不能挡住战斗。
- 新角色只看剪影也要能认出来；敌人统一用朱色眼睛，主角始终是唯一戴红围巾的人。
- 新印章先查 2.7 字表，同一含义只用一个字。

### 5.2 玩法
- 每个敌方攻击都必须有可读预警：刃尖朱光，或「危」印。普通敌人预警不短于 0.45 秒（乘难度系数之前）；Boss 可以更短来体现压力，当前最短是二阶段三连斩第二刀的 0.28 秒。
- 不可弹反的招式必须标「危」，并且一定能靠跳或闪躲开。
- 新敌人必须定义被弹反后的结果（失衡、死亡、架势……），并给出收招窗口。
- 同时出招受 3.9 的上限约束；新敌人默认计入上限。
- 新动作的反馈强度放进 3.8 的梯度，不越级。
- 墨意获取、分数按 3.7、3.12 的量级定，避免某种打法收益明显压过弹反。

### 5.3 关卡
- 新增一幅需要：两字名称、天色关键帧（2.5）、至少一个标志性道具、一场遭遇、一个新要素。
- 遭遇锁屏宽度不超过约 680，触发点放在玩家已经能看到敌人出场位置的地方。
- 新要素第一次出现时配一条教学提示（4.3），并且第一波要温和。
- 整卷时长保持在约 3 分钟；加内容时同步调整用时奖励的基准（330 秒）。

### 5.4 数值与协议
- 改数值时同步更新本文对应表格和 `client/xiaban-web/src/games/ink-blade/` 里的测试。
- 3.13 的分享字段含义不得更改；需要新指标时新增字段，并同时改网站侧解析。

## 6. 技术约束
- `rules.js` 是确定性的纯规则：不访问 DOM，固定 1/60 秒步长，随机数用种子。测试直接运行这份发布文件。
- 画面目标约 240 万像素的绘制缓冲，设备像素比最高 2；帧耗时持续超过 14 毫秒时自动降一次画质（去掉纸纹、降分辨率）。
- 长条视差层切成不超过 2048 像素的块，兼容手机画布上限。
- 粒子上限：墨滴与烟 420、墨溅 30、地面墨渍 150、剑痕 14。新特效要设上限。
- 新增文件要在 `index.html` 里按依赖顺序引入，并更新游戏包 README 的文件说明。
