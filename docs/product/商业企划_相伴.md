# 商业企划：相伴 / 下班了么

> 版本 v0.1 · 2026-10-06 · 状态：讨论稿（数字为经验估算，上线后用真实数据校准）

## 1. 概述

### 1.1 核心判断
- 主线变现：小伴换装 + 虚拟消耗品，验证付费意愿后再上“相伴会员”（长期记忆、实时对话）。
- 广告只做补充，硬件和定制出包先做小实验，桌宠只负责引流、不指望赚钱。
- 产品以 App 为主，网页是拉新入口，二者共用账号、小伴和记忆。

### 1.2 变现原则
- 卖情感价值（记忆、纪念日、专属互动、形象），不卖“更多 token”。
- 首次付费门槛要低（1 到 6 元），先让用户完成第一次付费。
- 不破坏陪伴调性：不上开屏广告，不打断对话。
- 先验证付费意愿，再投入重资产。

### 1.3 与 PRD 的关系
本文保留早期商业规划背景；原下班打卡网页已停用，本文件中的阶段、指标和变现假设不代表当前产品路线。

## 2. 方案总览

| 方案 | 可行度 | 优先级 | 一句话判断 |
|---|---|---|---|
| 小伴换装与消耗品 | 中到高 | P0 | 边际成本接近零，程序化配件美术成本低，前提是先做出情感绑定 |
| AI 会员（记忆、实时对话） | 高 | P1 | 付费意愿最强，但有 token 成本和备案合规要求 |
| 桌宠（引流） | 高 | P0 | 曝光频次高、适合传播，不负责赚钱 |
| 广告（激励视频） | 低到中 | P2 | 需要几千以上 DAU 才有意义，开屏与调性冲突 |
| 专属礼物定制版 | 低到中 | P3 | 自动出包技术可行，卡点在收款主体、安装门槛和版号 |
| 智能硬件 | 中（需验证） | P3 | 需求真实，门槛在供应链和资金，先预售验证 |
| CPS 联盟、打赏 | 中 | P0 | 几乎零成本，适合早期验证 |

## 3. 各方案详述

### 3.1 小伴换装与消耗品（P0）
- 陪伴养成类产品靠装扮和道具变现已被验证，前提是用户对小伴有情感绑定，所以留存优先于变现。
- 小伴是程序化绘制的，帽子、围巾、表情、背景可以用代码生成，不依赖外包美术。
- 定价分层：
  - 会员免费装扮。
  - 单件 1 到 6 元的小额购买。
  - 节日限定款，制造稀缺。
- 虚拟消耗品：给小伴买蛋糕、咖啡、小玩具，一次几毛到几块，比会员更容易冲动消费。
- iOS 用户付费意愿更高，可作为付费主力端。

### 3.2 AI 会员（P1）
- 情感陪伴类产品以订阅制为主，“更长的记忆”和“实时对话”是天然付费点。
- 免费版给短期记忆，会员版给长期记忆、语音和实时对话。
- 月卡参考价 9.9 到 19.9 元。
- 每个用户都有真实的 token 成本，必须做额度和限流，上线前先算清单用户成本。
- 国内提供生成式 AI 服务有备案要求，稳妥做法是接已备案的模型厂商 API。
- 国内用户对“工具、信息”付费习惯弱，对“情感绑定、虚拟形象”付费意愿强。所以不把 AI 会员放第一个付费点，先用换装和消耗品验证付费意愿。

### 3.3 桌宠（P0，引流）
- 定位：免费，目的是拉新和品牌，不是变现。
- 优势：常驻屏幕，曝光频次远高于 App；适合在 B 站、小红书、抖音传播。
- 与产品场景吻合：待在上班电脑上，倒计时下班，到点提醒。
- 技术：机器人引擎是程序化绘制，用 Tauri 或 Electron 可直接复用。
- 转化链路：免费桌宠，登录账号同步小伴，引导到 App 使用记忆、换装、会员。
- 平台顺序：桌面端（Windows 或 Mac，待定）优先。安卓悬浮窗要 `SYSTEM_ALERT_WINDOW` 权限且国内厂商会杀后台，放后面。

### 3.4 广告（P2）
- App 内接穿山甲，只做激励视频：用户主动看一条，换一件装扮或一次额外对话。广告成为付费体系的一部分，不打扰人。
- 不做开屏广告，和陪伴调性冲突，会伤留存。
- 开屏 eCPM 经验值约 10 到 40 元，1000 DAU 一天只有几十元收入，DAU 过几千再做。
- 接入前提：软著、备案、开发者主体。
- 网页联盟广告收入更低，不优先。

### 3.5 专属礼物定制版（P3，小实验）
- 思路：把“只改名字”升级为“送给对象的专属小伴”，定制名字、纪念日、祝福语、形象，买的人是送礼，付费理由比买游戏充分。
- 自动化流程：用户付款，回调触发 GitHub Actions（`workflow_dispatch` 带名字、图标参数），改包名和应用名、签名、上传产物、发下载链接，全程无人工。
- 卡点：
  - 自动收款需要支付主体，个人只能依赖发卡平台或爱发电 webhook。
  - 安卓 APK 直发会触发手机厂商“未知来源”警告，转化会掉。
  - 付费游戏在国内严格说需要版号，自己分发属灰色地带，规模变大有风险。
- 结论：低成本试水，不投入大量开发。

### 3.6 智能硬件（P3，预售验证）
- 需求信号：淘宝天猫上类似产品，300 到 600 元、1000 到 2500 元两档出货量较大（用户观察，未独立核实）。
- 差异化：不只是情感陪伴，还可做家庭智能控制中枢。
- 竞争：控制能力上与小米、天猫精灵正面竞争，对手靠补贴硬件、设备生态更大。能赢的是小伴这个角色和陪伴体验。
- 策略：控制能力作为附加功能（接入 Home Assistant 或米家），核心卖点仍是“有小伴的陪伴机器人”。
- 轻资产路径：基于开源小智（ESP32）方案，找 ODM 做小批量外壳和形象定制，用预售或众筹验证，不先备库存。
- 门槛：供应链、备货资金、3C 认证、售后、电商退货率。
- 现在能做的准备：账号、记忆、形象全部云端化，硬件只是小伴的另一个容器，软件资产可复用。

### 3.7 其他思路
- CPS 联盟：和场景贴合，下班后吃什么、喝什么，接美团、饿了么、淘宝联盟，不打扰用户，成本几乎为零。
- 爱发电、面包多打赏：零门槛，不需要公司主体，适合早期验证付费意愿。
- B2B 员工关怀或团建版：客单价高，但销售周期长，暂缓。
- 表情包与周边：直接收入少，但能带流量，是裂变渠道。

## 4. 阶段路线

| 阶段 | 内容 | 验证指标 |
|---|---|---|
| 现在 | 开爱发电打赏、加 CPS 入口；桌宠立项 | 打赏转化、CPS 点击率 |
| 留存稳定后 | 换装与消耗品上线，账号与云端记忆打通 | 付费率、ARPPU、首次付费转化 |
| 有付费用户后 | 相伴会员（长期记忆、实时对话、专属装扮） | 会员转化、单用户 token 成本、续费率 |
| DAU 过几千 | 激励视频广告 | 广告填充率、对留存的影响 |
| 并行小实验 | 礼物定制版、硬件预售 | 预售量、客单价 |

## 5. 风险与前置条件

| 风险 | 影响 | 应对 |
|---|---|---|
| 没有收款主体 | 无法接微信、支付宝等正式支付 | 早期走爱发电、面包多；之后注册个体户或公司 |
| 软著、备案缺失 | 无法接穿山甲、无法上架应用商店 | 与 PRD 阶段二的备案同步推进 |
| AI 服务备案与内容合规 | 上线被下架或限流 | 接已备案的模型 API，做内容过滤 |
| token 成本失控 | 会员亏本 | 额度、限流、分档定价，先算单用户成本 |
| 国内付费习惯弱 | 转化低 | 低价首单，卖情感价值，iOS 优先 |
| 硬件重资产 | 资金链风险 | 预售验证，不先备货 |
| 桌宠拉来的用户不转化 | 引流无效 | 账号同步与 App 引导做在桌宠里，监控转化漏斗 |
