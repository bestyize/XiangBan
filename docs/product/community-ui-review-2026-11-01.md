# 社区移动端逐页整理（2026-11-01）

基于主分支合并点 `b10e3c1b` 和移除官方挑战入口的 `e0fd0563`，在独立 worktree 修改。按用户最终偏好：不参考 Material 视觉规范；沿用小伴品牌与主题色，以标题、真实图片和少量必要元信息组织内容。没有改写生产内容或接口。

## 页面清单与处理

| 页面 | 发现的问题 | 本轮处理 |
| --- | --- | --- |
| 首页 / 推荐 | 无配图新闻占用大块假封面；预览跨日期却标单日条数 | 无图只显示标题与来源日期；有图才显示缩略图；去掉容易混淆的条数 |
| 首页 / 开源热榜 | 巨大的基线状态、每行重复说明、贴边红色名次角标 | 紧凑数据概览，口径与时间可展开；仓库名、真实 Star、语言；轻量序号与收藏 |
| 首页 / 排行榜 | 卡片文字紧贴边缘、卡片之间拥挤 | 8dp 内边距和卡片间距；保留小字号、真实模型标志、五项用量预览、点按看全名 |
| 排行榜 / 能力、调用量详情 | 同上 | 使用同一小边距；指标和日期筛选保留，数值口径不变 |
| 排行榜 / 横屏散点图 | 用户已确认紧凑布局 | 保留无大标题、横屏隐藏厂商和模型详情，沿用现有坐标与标签逻辑 |
| 首页 / 追踪 | 五篇长说明把优惠入口挤到屏幕末端 | 发布记录、优惠与试用可直接切换；发布说明默认收起；官方来源、优惠资格与期限仍可见 |
| 首页 / 导航 | 每个入口一张大卡，重复厂商占高度 | 按海外/国产分组，图标加名称的双列入口 |
| 讨论 / 创作 | 牌面拥挤；游戏截图裁切；应用数被画成点赞；无试玩入口却显示可试玩 | 自适应列宽，游戏/组件完整封面；移除错误试玩提示与零次应用装饰；能力卡只留标题、类型及作者 |
| 讨论 / 学习和教程 | 作者、摘要、投票占满列表 | 标题、真实图片和轻量作者/日期；正文与投票在详情查看 |
| 讨论 / 休闲 | 同一信息流问题 | 同上；分类筛选和空态保留 |
| 资源 / AI 工具 | 重复开发者信息；稀疏版本占位 | 名称加必要许可证/版本；详情缺少发布产物时不画三格破折号，提供官网入口 |
| 资源 / 资料 | 每条资料都有图标、简介和重复标签 | 按来源分组；列表只保留文档标题与外链标志 |
| 资源 / 影音娱乐 | 无图条目画假封面，摘要密集 | 只在有真实图片时显示封面；标题加少量元信息 |
| 资源 / 求助悬赏 | 标题加摘要重复占位 | 去摘要；保留求助状态、悬赏、期限、回答数 |
| 资源 / 开源精选 | 假缩略图与摘要争夺标题空间 | 有图才显示；保留标题和必要元信息 |
| 作品详情 | 游戏/组件预览被裁切；缺作者时冒称匿名/官方 | 完整预览，缺作者显示“社区作品”；保留正文和真实应用数 |
| 能力详情 | 手动模板身份不突出，完整提示词占满首屏 | 手动模板标签；提示词可展开/复制；权限与限制完整保留 |
| 方案详情及列表 | 信息简短，操作明确 | 保留内容、版本和可用性；统一卡片基础样式 |
| 帖子详情 / 回复 | 需要全文阅读与交互 | 保留全文、配图、投票、回复、收藏与举报；不把列表精简应用到正文 |
| 往期日报 | 与首页重复的假缩略图 | 复用新的新闻行 |
| 搜索及结果 | 关键词可能命中正文而非标题 | 保留匹配摘要作为搜索例外；不删关键词上下文 |
| 用户页 / 收藏 | 列表摘要冗长 | 去掉帖子/作品摘要；保留管理操作与状态 |
| 发帖 / 求助发布 | 筛选样式与阅读页不一致 | 复用同一筛选项；输入、校验、权限、发布流程不变 |
| 分享、举报、通知、屏蔽、方案备份 | 表单和状态内容需要完整可见 | 检查代码路径；仅受统一卡片/空态影响，不变更业务操作 |

## 保留的用户约定

- 二级 TAB 居中；官方挑战入口保持移除。
- 模型榜保留少量左右留白、小一号模型字体；能力与调用量不新增两个顶层 TAB。
- 横屏散点图仍不展示厂商筛选和底部模型详情，不增加顶部标题区。
- 列表以标题为主；数值、时间、许可证、求助状态及领取资格等影响决策的信息不伪造、不删除。
- 没有制造点赞、作者、试玩能力或历史增长数据。
