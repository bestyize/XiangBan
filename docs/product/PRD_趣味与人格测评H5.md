状态：设计评审中（纯前端 H5 优先，暂不商业化，聚焦低门槛拉新与高传播裂变）

## 1. 产品定位与前期目标

### 1.1 一句话定位
面向国内年轻人的**纯免费、免登录、强社交传播**移动端 H5 测评集合站：用 **2–3 分钟的高网感创意测试**拉新，用 **零门槛双人合盘** 1 带 1 裂变，用 **多维灵魂总档案** 把一次性访客留存下来。

### 1.2 前期核心策略（暂不商业化）
1. **反套路口碑切入**：当前国内测评站普遍存在“做完 50 题最后弹 9.9 元解锁”的强反感体验。一期坚持 **0 付费墙、0 强制登录、免费导出高清无水印海报**，以“良心宝藏网站”建立自然转发率。
2. **顺手版权合规**：所有题目与结果文案 **100% 原创或基于公有领域开源量表**，不使用 `MBTI®`、`CliftonStrengths®` 等商业商标作为测试标题，不搬运任何受版权保护的原卷。后续如需商业化或上架小程序/应用商店，零迁移成本。
3. **轻量化纯前端冷启动**：一期采用 **Vue 3 + Vite 纯前端静态 H5**，题库配置、算分引擎、双人合盘（URL 参数编码）、高清海报导出（Canvas）、本地档案（`localStorage`）全在端内完成。CDN 静态托管即可承受突发刷屏流量；二期跑出自然流量后再按需接入 Rust 后端与统一账号中心（`server-account`）实现云端同步与全站分布统计。

## 3. 核心漏斗与裂变机制设计

### 3.1 零摩擦转化漏斗
```text
好友海报/链接 → 直达单测评落地页（跳过复杂首页）
             → 0 登录直接开测（拇指热区单选自动翻页，2 分钟完成）
             → 0.9s 解析动效拉满期待
             → 首屏即高颜值专属海报（主标签 + 稀有度 + 搭子/宿敌 + 二维码）
             → 一键保存（9:16 朋友圈 / 3:4 小红书）或「发给 TA 测同款合盘」
             → 底部「点亮 3/6 解锁综合灵魂总卡」引导连测下一套
```

### 3.2 纯前端“零门槛双人合盘”协议
为了在一期无后端条件下跑通最强裂变链路，双人对比采用 **URL 轻量编码协议**：
* 发起方在结果页点击「邀请 TA 测同款看默契」，输入可选昵称（默认“你的好友”），前端生成分享链接：
  `https://<domain>/#/t/<testId>?peer=<typeCode>&pn=<uriEncodedName>&v=<compactVector>`
* 受邀方点开链接后顶部展示轻提示条：`「林小满」邀请你测同款，测完立即查看你们的合拍度`。
* 受邀方作答完毕后，前端直接基于双方的结果码与维度向量计算出：
  1. **合拍度总分（60%–99%）与关系称号**（如 `灵魂松弛搭子`、`欢喜互怼冤家`）；
  2. **双人 4 维同轴对比条**（一眼看清两人在哪几个维度互补或拉扯）；
  3. **3 条精准默契点 + 2 条相处避雷提醒**；
  4. **可保存的双人合照海报**。

### 3.3 个人多维灵魂档案（留存抓手）
* 每次测完自动写入本地存储（`localStorage`），无需注册即可在「灵魂档案」页查看全部历史结果。
* 当用户完成 **≥ 3 个测评** 时，自动合成一张**《个人多维灵魂总卡》**，将不同测评的主标签横向串联（例如：`体面伪人 · 雾杏/暮海 · 松弛水豚 · INFJ`），并生成一段跨测试的共性洞察总结，激发二次转发。

## 4. 移动端 H5 视觉与交互规范

整体壳层严格遵守仓库 [手机端设计规范](手机端设计规范.md)，同时兼顾测评海报的创意表现力：

### 4.1 视觉方向：方案 A · 潮玩盲盒 / 潮流杂志风（已定稿）
由于本产品定位为强情绪价值与社交裂变的拉新 H5，视觉不沿用偏冷静的办公工具白灰风，而是采用**潮玩盲盒 / 新波普杂志风**：
* **底色与触感**：浅色采用暖奶油杂志纸底（`#FBF6EE` + 细腻复古微点阵），深色采用暗夜潮玩黑胶底（`#15141A`）；卡片与按钮采用 `1.8px` 精致墨线描边 + `3px 3px 0` 实体硬阴影，按压时阴影收缩，形成“撕盲盒 / 贴贴纸”的强互动反馈。
* **多巴胺撞色盲盒封面**：6 个首发测评在首页即以高辨识度彩色封面卡 + 原创波普插画呈现（荧光酸橙黄 `#E4F857`、桃杏×暮靛渐变、焦糖奶橘 `#FFD89B`、草莓粉 `#FFB5C8`、冰川天蓝 `#8DD3FF`、电光香芋紫 `#CBB8FF`），避免同质化文字列表。
* **6 套专属出片海报皮肤**：每项测试拥有独立高饱和海报视觉（SBTI 荧光黄大字报、Pantone 双色渐变、暖橘波普水豚画框、警示带避雷说明书、冰蓝体检化验单、电光紫 16 型几何卡），底部灵魂档案采用**黑金潮玩集卡册**强化收集与晒图欲。

### 4.2 移动端 H5 专项适配清单
1. **视口与安全区**：统一使用 `100dvh` 防止 iOS Safari / 微信内置浏览器工具栏遮挡底部主按钮；顶部与底部均适配 `env(safe-area-inset-top / bottom)`。
2. **宽度基准与响应式**：手机端以 `390px` 为基准、向下完整兼容 `360px` 小屏；PC 桌面浏览器访问时自动居中渲染 `430px` 精致手机画布（带柔和背景与二维码扫码提示），一套代码通吃 H5、PC 网页与未来 App WebView。
3. **单手拇指热区答题**：答题选项固定在中下部，单个选项高度 `≥ 56px`、触控区充足；点击选项后给予 `260ms` 选中高亮反馈并自动平滑切换至下一题，支持左上角或底部回退修改上一题，同时实时落盘支持断点续答。
4. **微信浏览器存图兼容**：微信内置浏览器限制 `<a download>` 自动触发下载，因此海报导出弹层统一在前端 Canvas 渲染 `2x/3x` 高清 PNG 后输出为真实 `<img>` 元素，引导用户**长按图片保存至相册**，同时提供 **9:16 朋友圈长图** 与 **3:4 小红书封面** 一键切换。

## 5. 配置化测评引擎 Schema（后续工程开发基准）

为保证后期追热点能“1 天上新一套测评”，前端核心抽象为**配置驱动的通用测评引擎**：

```ts
export interface TestDefinition {
  id: string;                        // 如 'real-mask' | 'dual-color' | 'animal-persona'
  title: string;
  subtitle: string;
  category: 'viral' | 'aesthetic' | 'relation' | 'classic';
  skin: 'sbti' | 'pantone' | 'animal' | 'manual' | 'checkup' | 'classic16';
  questionCount: number;
  estimatedMinutes: number;
  badge?: string;                    // 如 '含隐藏彩蛋' | '支持双人合盘'
  dimensions: DimensionSpec[];       // 4~8 个心理/行为底层维度
  questions: QuestionSpec[];         // 生活场景题 + 维度权重映射
  scoringMode: 'nearest-profile' | 'axis-code' | 'weighted-tier';
  profiles: ResultProfile[];         // 结果类型库（含稀有度、金句、搭子/宿敌、彩蛋条件）
}
```

* **算分透明可校验**：创意测试也采用**“科学骨 + 整活皮”**——底层映射 4–8 个稳定维度（如社交电量、边界感、情绪钝感、控制倾向、理想主义等），保证用户重复测试结果稳定、解读精准而非随机抽签。
* **后端演进预留**：接口层预留 `StorageAdapter`（一期实现 `LocalStorageAdapter`，二期可无缝切换为 `CloudStorageAdapter` 对接 `server-account` JWT 与 Rust 后端）。
