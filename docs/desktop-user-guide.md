## 二、 核心亮点：桌面 AI 伴侣（Agent）玩法详解

小伴桌面的 AI 不是一个仅供文字聊天的网页窗口，而是**深度接入了客户端底层控制协议与渲染引擎的桌面 Agent**。

### 1. 现场写代码造挂件（杀手级能力）
告诉小伴你的需求，它会在后台编写符合小伴组件规范的 HTML5 / JavaScript 代码，几秒钟内自动将专属小组件挂载到你的桌面上：
- 💡 **示例咒语**：
  - *“帮我写一个极简赛博朋克风格的时钟挂件，放在桌面上”*
  - *“帮我写一个下班倒计时便签挂件，写上‘下班不慌，慢慢来’，放到桌面”*
  - *“做一个复古像素风格的每日一句诗词挂件贴在桌面上”*

### 2. 现场编写动态壁纸与特效
- 💡 **示例咒语**：
  - *“帮我写一个暗黑流动星轨的动态壁纸，带上微光粒子，做完直接应用到桌面”*
  - *“写一个深海微光的动态 Canvas 壁纸并设为壁纸”*
  - *“做一个春日微风带着粉色樱花瓣飘落的桌面特效，并切换到它”*

### 3. 一句话联动桌面氛围
告别繁琐的设置菜单，直接告诉小伴你的心情与使用场景：
- 💡 **示例咒语**：
  - *“我想安静写代码，换一张雪山风景壁纸，并开启落雪特效”*
  - *“换成雨夜风景，特效换成细雨淅淅沥沥”*
  - *“把小伴换成毛绒小猫皮肤，做一个开心的表情”*
  - *“打开水墨剑客小游戏，我想放松一下”*

### 4. 贴身生活作息管家
通过自然语言直接在系统底层录入定时规则：
- 💡 **示例咒语**：
  - *“每天下午三点半提醒我喝水吃点水果”*
  - *“工作每隔 45 分钟提醒我闭眼休息，活动活动颈椎”*
  - *“每天下午六点半提醒我：准备下班，今天辛苦啦”*
  - *“今天天气怎么样，明天降温吗，需要带伞吗”*

### 5. 本地工作区与识图多模态
- **读写工作区**：在聊天页右上角选择工作目录后，可让小伴读取、统计或整理文档：
  - *“帮我看看当前工作目录里有什么文件，整理一份清晰的清单”*
  - *“分析一下目录里这篇笔记的核心大纲”*
- **多模态视觉识图**：直接在输入框中通过 `Ctrl+V`（macOS 上为 `Cmd+V`）粘贴截图，支持同时添加最多 8 张图片：
  - *“看下我刚粘贴的截图，分析一下报错的原因和解决办法”*
  - *“帮我看下这个 UI 设计稿有什么排版和配色上的改进建议”*
- **Edge-TTS 拟真语音朗读**：
  - 小伴每次回答内容下方均配有「朗读」按钮，采用微软高品质神经网络音色，带来如真人耳畔私语般的自然听感。

## 三、 大模型配置与推荐

小伴桌面支持主流公有云大模型与完全离线的本地私有大模型。在客户端点击「设置 → AI 模型」即可配置：

### 1. 推荐配置方案
1. **性价比与综合推理首选：DeepSeek**
   - 接口地址：`https://api.deepseek.com/v1`
   - 常用模型：`deepseek-chat`（日常对话、桌面操控与写代码）、`deepseek-reasoner`（复杂逻辑思考）
   - 优势：极其实惠的成本，出色的中文理解与代码生成能力。
2. **大厂官方服务商：智谱 GLM / 月之暗面 Kimi / MiniMax**
   - 客户端内置了一键切换预设，支持快速填入 API Key 使用。
3. **完全离线隐私首选：本地 Ollama**
   - 适合对数据安全性要求极高或无网络环境的用户。
   - 安装 Ollama 后，在自定义端点填写：
     - 接口地址：`http://localhost:11434/v1`
     - 密钥：留空
     - 模型：`qwen2.5:7b` / `llama3.1:8b` 等
   - 优势：零网络依赖，数据 100% 留存在你的电脑上。

## 四、 安全控制与权限机制

小伴在设计上遵循**最小权限与透明授权**原则，确保桌面环境安全：

1. **默认权限模式（Ask 模式）**：
   - 读取工作区文件、查看当前壁纸状态等读操作自动执行；
   - **修改本地文件、执行系统 Shell 命令、修改系统关键设置**时，小伴会停下来，并在聊天窗口中弹出清晰的授权卡片：
     - **允许一次**：仅放行本次操作；
     - **这段对话都允许**：在当前对话上下文内信任此类操作；
     - **拒绝**：阻止操作，小伴会寻找替代方案。
2. **高风险操作二次确认**：
   - 即使切换到“完全信任（Auto）”模式，涉及清空数据、关键目录删除等高危操作依然强制提示确认。

## 五、 常用快捷键与操作技巧

- **呼出 / 隐藏控制面板**：点击系统托盘图标，或通过快捷键随时唤起。
- **快速看壁纸（Windows）**：按 `Win + D` 返回桌面，小组件与动态壁纸清爽呈现。
- **拖动小组件**：在桌面组件页面点击【在桌面上摆放】即可进入拖拽模式，调整后点【完成摆放】锁定。
- **退出动态壁纸**：在壁纸库首页第一张卡片点击【使用原生壁纸】，即可秒级切回系统默认壁纸。
- **网页版完整指南**：可在系统浏览器访问官方源站 `https://wallpaper.xiangban.xyz/guide` 随时查阅最新手册。
