## 3. 本地环境准备

| 需要 | 说明 |
| --- | --- |
| Rust stable | 全部 Rust 部分；Windows/macOS 上还要能编译 Tauri（`client/xiaoban-desktop-wallpaper/src-tauri`） |
| Node 18+（建议 22） | 论坛前端、桌面前端、`tools/p0-verify` |
| PostgreSQL 14+ | 集成测试和服务运行。云端用 16，建一个能建库建 schema 的账号即可 |
| JDK 17+ 与 Android SDK | 手机端 Gradle 工程（`client/xiaoban-multiplatform`）；`local.properties` 的 `sdk.dir` 为空时设 `ANDROID_HOME` |
| Claude Code、Codex CLI | 跑 `tools/p0-verify`，并登录 |

集成测试都靠环境变量 `TEST_DATABASE_URL`（形如 `postgres://用户:密码@localhost:5432/postgres`）：没设就**自动跳过**，注意别把“跳过”当成“通过”。每个测试用独立 schema，不会污染库，也不会自动清理，可以定期 `DROP SCHEMA ... CASCADE`。

云端沙箱里装依赖的特殊做法（`npm ci --replace-registry-host=always --registry=…`）只是为了绕沙箱代理，本地直接 `npm ci` 即可，见 `AGENTS.md`。

## 8. 易踩的坑

- **集成测试被跳过**：没设 `TEST_DATABASE_URL` 就跳过并显示 ok。
- **论坛前端改完要重启服务**：服务启动时读一次 `index.html`，重建前端后不重启会白屏。
- **路由嵌套**：论坛路由已在 `/api` 下，写路由时用相对路径，写成 `/api/...` 会 405。
- **axum 0.8 的 `Option<Json>`**：空正文会 4xx，需要空正文的接口要自己解析 `Bytes`。
- **协议向量**：改协议任何一处（编码、密钥派生、AAD、补齐）都要先改 `docs/agent/设备互联协议.md`，再 `gen_vectors` 重新生成 `vectors/v1.json`，Rust 与 Kotlin 两边测试同时通过才算数。
- **重放防护状态必须持久化**：不落盘的话接收端重启后旧信封可以被重放。桌面端每秒落盘一次（崩溃最多丢最近一秒），手机端同理。
- **`ep` 的启动计数必须“加一再落盘再使用”**：计数没落盘会让对端报“计数相同、ep 不同”并要求重新配对。
- **从 Claude Code 里面跑脚本**：子进程会继承 `CLAUDE_CODE_SESSION_ID` 等变量而复用会话编号；`tools/p0-verify/lib.mjs` 的 `cleanEnv` 已处理，小伴将来拉起外部 Agent 子进程时也要清掉。
- **hooks**：`http` 类型的 hook 收不到 `SessionStart`；只读命令（如 `echo`）被自动放行，不触发 `PermissionRequest`；`Stop` hook 拦截后要在第二次放行，否则死循环。
- **Windows 上的 npm 命令是 `.cmd` 垫片**：用 Node 的 `spawn` 要经 shell 并手动加引号，见 `tools/p0-verify/lib.mjs`。
- **Android 的 EC 密钥**：minSdk 24 上 Keystore 里的 EC 密钥做不了 ECDH，所以私钥用软件密钥、由 Keystore 的 AES 密钥包起来。
- **Maven Central 偶尔 429**：重试即可；云端拿不到 Google Maven（androidx），所以 Compose/Android 无法在云端编译。
