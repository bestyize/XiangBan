# 单关操作

1. 确认显式设备、实际包名、版本及用户要求的目标/时长。由用户进入目标关卡，避免擅自消耗开始关卡所需资源。
2. 读 pages/board.md 与 knowledge/match3.md。截图，检查是否存在说明、结果弹窗，或尚未结束的动画。
3. 可靠识别棋盘边界、行列、普通颜色与空洞。将其表示为矩形矩阵；不能可靠判断的格子设为 0。若未知格子会影响当前决策，先重新观察，不能猜测。
4. 调用 phone_match3 获取局部候选。若已有匹配则等待动画后重新观察；若无候选，不擅自使用道具，检查识别和当前状态。
5. 将候选行列换算为最新截图上的格子中心坐标，调用 phone_action(swipe) 执行一手。
6. 重新截图确认棋盘变化，等待稳定后重复。棋盘随机补充，绝不能预先排队执行多步旧棋盘动作。
7. 读 pages/result.md 判断胜负；达到目标、用户停止、时间结束、识别持续不可靠或出现未知机关时结束并说明实际状态。

候选评分只代表即时匹配格子数；不要据此声称最优策略或必胜。只有实际结果页面能够证明通关。

准备面板可能默认勾选补星瓶等道具。用户只授权正常体力试玩时，必须先检查并取消这类选择，再开始。已实测第 4181 关的两次合法交换，不代表完整关卡策略，详见 knowledge/level-4181.md。
