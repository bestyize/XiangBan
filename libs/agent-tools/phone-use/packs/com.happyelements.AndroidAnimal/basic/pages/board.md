棋盘动画、掉落、特效期间不能据旧矩阵继续行动。截图间棋子位置仍变化时继续观察；稳定后再评分。横竖屏、缩放、棋盘形状变化后重新校准中心坐标。不能只用颜色忽略特殊棋子的标记。
