# 关卡地图（map）

参考特征为关卡节点、地图和活动入口；具体版本需实机确认。首版由用户进入目标关卡。主关卡入口属于核心结构，限时赛事、促销和活动角标属于临时区域。

小米 17 / Android 16 / 1.162 已观察：地图滚动有惯性，短距离、较慢的滑动更适合定位指定旧关卡。底部固定“闯当前关”不随地图位置改变，不能把它当成已选中的历史关卡。必须点击地图目标节点，再在关卡准备面板核对关卡号后开始。

启动可能出现渠道 SDK 的优惠遮罩、签到、限时奖励等多层状态。渠道 SDK 前台包名可能变成 `com.xiaomi.gamecenter.sdk.service`；先观察并核对，不能为了绕过前台保护自动把它当成游戏包。具体活动入口只适合带到期时间的临时补丁，不进入核心路由。
