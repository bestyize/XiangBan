# 相册选择（album）

参考特征：照片缩略图、相册选择、选中序号或选中数量、进入下一步的按钮。具体布局以实时页面为准。

定位 phone_push_image 返回的 XiaoBan 目录素材；必要时切换相册、等待媒体索引。核对缩略图内容和选中序号，不能仅以最新几张推断就是目标文件。权限选择界面属于前置状态，用户必须决定允许访问的范围。

选中后核对数量及顺序，再进入编辑。进入图片修饰界面时按当前页面推进，不把中间态误认为编辑正文页面。

小米 17 / Android 16 / 9.51.0 已验证：顶栏有“草稿箱”和描述“关闭”；“全部”在顶栏和分类栏重复，精确文字匹配会歧义。缩略图通常没有图片名称或内容描述，需要用截图核对素材；坐标选图时可加 `guard_selector={text: "草稿箱"}` 防止页面变化后误点。

选中一张后，本次出现文字“下一步(1)”及描述“下一步”，可用 description 选择，并以 text=下一步(1) 作为当前状态条件。进入的是 pages/image-editor.md。

实机曾在相册已打开时传入测试图片，MediaStore 已索引，但当前列表没有立即刷新；关闭相册、重新进入后显示。媒体索引成功不等于当前列表已更新。图片名、索引 ID、用户相册内容不写入共享知识。
