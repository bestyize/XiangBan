# 编辑笔记（editor）

参考特征：已选素材预览、标题/正文输入区域、发布相关按钮。先通过当前树和截图分别识别两个字段；不能把正文填进标题。

输入后检查实际文字及图片，页面可能需要滚动才能看到完整正文。话题、地点、可见范围等仅按用户意图设置；不擅自附加地理位置或更改可见范围。输入法、键盘、弹窗是当前页面状态，不建立独立核心路由。

小米 17 / Android 16 / 9.51.0 已验证：初始标题和正文分别是 `android.widget.EditText`，文字为“添加标题”“添加正文”。使用 text + class 组合聚焦，再用 phone_action(text) 输入中文；读回两个 EditText 并用截图确认换行，不能只看广播返回 result=0。

本次观察到“存草稿”及“发笔记”按钮。部分编辑状态的树中“发笔记”出现两次，因此不能用有歧义的文字选择器猜测提交目标。最终发布未测试，也没有点击“发日常”或改变可见范围。退出路径实测为编辑页返回 → 图片编辑返回 → 相册关闭，回到首页。
