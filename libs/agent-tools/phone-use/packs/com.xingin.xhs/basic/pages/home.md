# 首页（home）

小米 17 / Android 16 / 小红书 9.51.0 实机观察：底部导航的无障碍描述为“首页”“市集”“发布”“消息，未读”（随未读状态变化）和“我”。顶部有关注、发现、地区等切换；地区名称属于动态内容。资源 ID 大量混淆为同一个 `0_resource_name_obfuscated`，不能单独定位。

本次已验证发布入口可用 `phone_action(action=tap_element, selector={description: "发布"})`，随后出现发布方式面板，按需读 pages/creation-methods.md。控件描述和布局跨版本仍需检查。

区分底部主导航和推荐流里的动态卡片。活动卡片不属于核心导航骨架。广告/引导先观察其性质，关闭后重新检查当前页面。进入发布流程后核对是否确实到了相册或创作选择界面。

实机启动曾出现升级弹窗，可观察到“立即安装”“稍后再说”。它属于临时遮罩，关闭后回到原页面；不可为继续任务自动升级应用，不将该遮罩加入核心地图。
