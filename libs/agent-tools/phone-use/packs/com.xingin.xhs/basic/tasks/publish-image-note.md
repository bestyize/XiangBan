# 发布图文

前置条件：目标 Android 设备已授权 ADB、账号由用户登录；核实目标账号及用户提供的素材和发布意图。只操作一篇笔记。

1. phone_observe(status) 获取包名与版本；读 phone_routes(scope=flows/publishing)。
2. 逐张调用 phone_push_image，保留返回的设备路径和图片顺序；媒体索引有延迟，不能据 push 成功就声称相册已显示。
3. phone_action(launch) 后观察 UI / 截图，按 pages/home.md 找当前发布入口。
4. 进入相册后读 pages/album-picker.md，找到本次传入的实际缩略图，按用户顺序选择并核对张数。不要选中相邻的用户私人照片。
5. 按当前界面推进到编辑页，读 pages/note-editor.md；需要中文输入时读 knowledge/text-input.md。逐字段聚焦、填入、回读核对；若输入前已有内容，先确认应替换还是保留，不能盲目追加。
6. 在编辑预览中核对账号、图片顺序、标题与正文。素材缺失、登录/验证码或发布权限问题交给用户处理；没有明确内容或发布授权时不能自行补全并发布。
7. 对当前页面识别出的发布按钮执行一次点击。随后读 pages/publish-result.md，观察发布反馈或目标笔记。
8. 若反馈是上传中则继续观察；若超时/断连/结果未知，检查笔记或草稿状态后再决定。不得因没收到成功响应而直接重放发布。

成功条件：手机实际显示发布成功，或在对应账号笔记详情确认本次标题及素材。仅填写完成、ADB 返回零或出现上传动画都不算发布成功。
